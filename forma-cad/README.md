# FORMA CAD

ブラウザ内で形状を計算する簡易CAD。Fusionに近い「作図 → スケッチ終了 → 閉領域選択 → 押し出し」の操作を採用しています。

## 基本操作
1. 「スケッチを作成」でXY/XZ/YZ平面を選びます。
2. 「線分」「長方形」「円」を選ぶと作図を開始します。線分はLキーでも開始できます。
3. 線分は始点のあと、クリックするたびに次の線がつながります。Escで作図コマンドを終了します。最初の点に戻れば輪郭が閉じます。「連続線」をオフにすれば1本ずつ作図できます。
4. 「スケッチを終了」を押します。閉じた領域は青く塗られます。
5. 領域の内側をクリックし、「押し出し」（E）を選びます。押し出しを先に押してから領域を選ぶこともできます。
6. 距離と新規ボディ／結合／切り取りを指定してOK。負の距離は反対方向です。

線をクリックした場合はその線の長さ・角度を確認できます。領域を選ぶには線の内側をクリックしてください。閉じていない線には通常の押し出しはできません。薄い押し出しでは、閉じた領域の周囲や選択した1本の開いた線に壁厚を付けられます。

## 画像の明暗から円柱の凹凸
1. 円柱の外側の側面をクリックし、左下の情報パネルにある「この円柱に画像の凹凸を作成」を押します。上部の「画像の凹凸」や「作成・修正」のコマンド一覧からも開けます。
2. PNG・JPEGを読み込み、浮き彫り／彫り込み、凹凸の高さ、模様の範囲を指定します。白が最大、黒が元の高さで、灰色はその中間です。白黒反転・明暗の強さ・滑らかさ・細かさも調整できます。白い背景の絵は、背景が平らになるよう初期設定を自動調整します。「絵柄をくっきり」で白黒・滑らかさ・細かさをまとめて調整できます。
3. 1枚を1周、繰り返し、左右反転した2枚から配置を選べます。繰り返しの幅は円周に合わせて調整します。
4. 立体のプレビューを確認して「作成」。作成後は履歴の「画像の凹凸」をクリックして再編集できます。画像の明暗データはモデル内へ保存するため、元画像がなくても再編集できます。

写真の明暗を高さとして使う機能です。写真に写った物体の奥行きを推定する機能ではありません。細かい写真は滑らかな形へ近似します。上下端は元の円柱へつなぎます。繰り返し1枚ごとの解像度を確保し、細かい設定でも計算量に上限を設けています。凹凸の色分けはプレビューだけで、明るい色が元の面、濃い色が大きな凹凸です。

## 領域と保存
- 同一基準平面・同一高さのスケッチ線から閉領域を認識します。独立に描いた線も端点が一致すれば領域になります。
- 凹形状、交差線で分割された領域、入れ子の輪郭と穴に対応。円は128分割したポリゴンで近似します。
- 現在は一度に1領域を押し出します。押し出し時の領域形状を記録する方式で、元スケッチの後編集との自動連動は未対応です。
- 描いた各線はその場で作業データに確定します。Escで既に描いた線は消えません。Ctrl+Z／Ctrl+Yで戻す・やり直し。
- 右上の保存でJSON作業ファイルを端末にダウンロード。「開く」で再編集できます。自動ファイル保存はありません。
- 旧版の作業ファイルも読み込めます。STL出力は非表示を含む全ボディ、単位mmです。

## 吸着と寸法
グリッド交点と既存の線の端点に吸着します。グリッド間隔は1/5/10/20/50mm。数値指定した端点にもつなげられます。
作図中の画面内で長さ・角度を入力でき、Enterで線を追加できます。次の線では寸法固定を解除します。固定寸法は吸着より優先されます。

## 対応範囲と制限
メッシュ方式の試作版です。Fusion互換のB-rep、STEP、寸法拘束、自由曲線、フィレット、アセンブリ、複数領域の同時押し出しには未対応です。
スケッチは現状、各線・図形を独立した履歴項目として保持し、同一平面で領域を計算します。Fusionのスケッチグループ構造とは異なります。
複雑な接触・重なりでブーリアン計算が乱れる場合があります。寸法0.1〜10000mm、最大150工程です。

## 開発と検証
Node.jsで `npm install`、`npm run build`、`npm start`。プレビューは http://127.0.0.1:5188 。
`npm test` は27件の形状・閉領域・穴・薄い押し出しテスト。
サーバー起動中に `node tests/workflow-browser.mjs`、`node tests/browser.mjs`、`node tests/sketch-browser.mjs`、`node tests/snap-browser.mjs`、`node tests/line-preservation.mjs` でEdgeによる操作検証。
WebMCPは対応ブラウザでcreate_cad_featureを提供します。検証用ブラウザではネイティブWebMCP APIの検証は利用できません。

参考: Autodesk Fusion公式ヘルプ（押し出し） https://help.autodesk.com/cloudhelp/ENU/Fusion-Model/files/SLD-EXTRUDE-SOLID.htm

## GitHubで公開

この版はアカウント登録・ログインなしで利用できます。形状計算はブラウザ内で行い、モデルは利用者が自分の端末へJSONファイルとして保存します。共有サーバーへのモデル保存はありません。

### FORMA CAD専用のリポジトリ

1. ソース一式をリポジトリのルートへアップロードします。
2. GitHubの Settings → Pages → Build and deployment → Source で GitHub Actions を選びます。
3. mainへの更新またはActionsの手動実行で、テスト・ビルド後にdistを公開します。

ワークフローは .github/workflows/pages.yml です。GitHub Pagesのサブフォルダでも、CADエンジンのWorkerとWASMは相対URLで読み込まれます。

### 既存のmenteリポジトリへ追加

既存アプリを保持して forma-cad フォルダへこのプロジェクトを配置し、その入口からdistへ移動します。GitHub Pagesがmainブランチのルートを公開する設定なら、公開先は https://supa2006jp-lang.github.io/mente/forma-cad/ です。既存リポジトリの公開設定を使うため、forma-cad/.github のワークフローは自動実行されません。更新時はこのプロジェクトで npm run build を実行し、更新したdistも一緒にアップロードします。

### アップロード用ZIP

開発フォルダで npm run package:github を実行すると、.sites-runtime/forma-cad-github.zip を作成します。解凍して中のファイルをアップロードしてください。ZIPそのものをGitHubに置いてもサイトにはなりません。node_modules、ローカルのGit履歴、実行中の作業ファイルは含みません。

Sitesの既存公開先は .openai/hosting.json に保持しています。GitHubへの追加で既存のSitesを作り直す必要はありません。

ブラウザからmenteへ追加する場合は npm run package:github:site を実行すると、10個の公開用ファイルだけを forma-cad フォルダにまとめた .sites-runtime/forma-cad-github-site.zip を作成します。解凍したforma-cadフォルダをリポジトリのルートへアップロードすれば、既存アプリを保持できます。

### 押し出しのテーパー角度

押し出しの小ウィンドウ、または右側の設定で「テーパー角度」を入力します。初期値は0°。プラスは押し出し方向の先端が広がり、マイナスは細くなります。負の押し出し距離でも同じ規則です。「0°」ボタンで直線の押し出しに戻せます。保存後は履歴の押し出し工程を選択して再編集します。新規・結合・切り取り、円形・四角・薄い押し出しに対応し、CAD形状として保存します。形状が潰れる角度は確定しません。入力範囲は−80°〜80°です。

検証: `node tests/extrusion-taper.mjs`、`node tests/extrusion-taper-browser.mjs`。

押し出し中は画面上の矢印をクリックすると確定し、ドラッグすると距離を調整できます。ドラッグの終了では確定しません。履歴からの再編集でも同じ操作です。

押し出しのテーパーは図形の横の円弧ハンドルでも調整できます。ドラッグは1°刻み、Shiftを押しながらは0.1°刻み。ハンドルの左右・上下キーでも調整でき、Homeで0°に戻ります。小ウィンドウには先端の幅・奥行き、円では外径を表示します。確定・再編集後は右下に距離と角度を通知し、「元に戻す」でその変更を取り消せます。通知は9秒で閉じ、その後も上部の「戻す」を使えます。

検証: `node tests/extrusion-feedback.mjs`、`node tests/extrusion-feedback-browser.mjs`。

### ボスと棒で接合

「ソリッド → ボス接合」、または「作成・修正 → ボスと棒で接合」で、印刷後に差し込んで組み立てられる2つのパーツを作成できます。1つのソリッドをXY・XZ・YZ平面で分割する方法と、平らな分割面で接している既存の2パーツに追加する方法があります。分割済みの場合は、印刷用に移動する前の組み立て位置で実行します。

接合数は1・2・4組。棒の直径、差し込み長さ、片側のすき間、ボスの肉厚・最低高さ、接合の間隔・位置を変更できます。中空パーツでは壁や底まで根元を伸ばして各パーツに結合し、受け穴は底を残した盲穴、棒は先端に傾斜を付けた形状になります。新規作成の初期すき間は標準の片側0.15 mm（穴の直径は棒より0.3 mm大きい）です。保存済みのすき間は維持します。

プレビューは水色がボス側、橙色が棒側。「印刷用に並べる」は穴と棒を上向きにし、Z=0に接地して10 mm離します。「組み立て位置で確認」で干渉を確認できます。保存・読み込み、元に戻す／やり直す、履歴またはボディの「再編集」に対応します。自動配置で必要な広さ・厚さを確保できない寸法は確定しません。

検証: `node tests/boss-joint.mjs`、`node tests/boss-joint-browser.mjs`。

ボス接合の「根元の補強」は、なし／丸み／三角リブ（4方向）から選択し、サイズを調整できます。内部に露出した根元だけに追加し、差し込み部の寸法は変えません。根元から分割面までの空間が小さい場合は補強サイズを収め、露出した根元がない場合はその旨を表示します。

プレビューの番号付き点は、ボス側・棒側のどちらからでもドラッグできます。0.1 mm刻みで移動し、離した時に形状を再計算します。「対称配置を維持」は2組で左右対称、4組で縦横対称。オフにすると1組ずつ移動できます。矢印キーで1 mm、Shift＋矢印で0.1 mm、ドラッグ中のEscで移動を取り消します。「接合位置を自動配置に戻す」で初期配置へ戻せます。壁や外周との余裕が小さい位置には警告を表示し、外にはみ出す・他の接合と重なる位置は確定しません。補強と位置は保存・再編集できます。

追加検証: `node tests/boss-joint-layout.mjs`、`node tests/boss-joint-edit-browser.mjs`。

ボス接合の「2パーツを中空にしてからボスを付ける」をオンにすると、分割面を開口にして両方を内側へシェル加工し、その後でボスと棒を作ります。シェルの壁厚は初期値2 mm、オプションは初期状態でオフです。1ソリッドの分割と分割済み2パーツの両方に対応し、外寸を保ちます。既に分割面へ開口した中空パーツは現在の壁厚を維持し、その旨を表示します。壁厚・中空化の有無は保存して再編集できます。

追加検証: `node tests/boss-joint-shell-browser.mjs`（中空化、壁厚変更、補強・位置変更、キャンセル、保存・読み込み・再編集、元に戻す／やり直す）。

ボス接合の「断面で内部を確認」は実際のプレビュー形状を組み立て位置へ戻して表示します。接合番号で断面位置を選び、全体／ボスと棒／位置決めを拡大できます。3Dプレビューも半分を隠して切り口を表示し、「3Dの表示側を反転」で反対側を確認できます。視点と保存するソリッドは変更せず、断面を閉じると通常表示へ戻ります。寸法を変えたときは断面も更新し、無効な寸法では古い断面を消します。

「合わせ面に位置決めの縁・受け溝を付ける」は初期状態でオフ。ボス側に縁、棒側に受け溝を作り、外寸を保ちます。新規作成の初期値は深さ1.5 mm、縁の幅1.2 mm、片側・底のすき間0.25 mmです。中実／シェル加工後／分割済みパーツに対応します。補強オンでは後述の1.2 mm厚を確保します。補強オフの従来形状では外周に0.4 mm、溝の内側に0.25 mm、溝の底に0.4 mmの材料を確保できない場合は確定しません。壁厚を増やすか、縁の幅・深さ・すき間を小さくします。位置決めの設定は保存・再編集できます。

追加検証: `node tests/boss-joint-alignment.mjs`、`node tests/boss-joint-section-browser.mjs`。

### ボス接合の分割面をドラッグ

1ソリッドの分割では「分割面を画面で動かす」で元のソリッドと紫の分割面を表示します。紫のハンドルをドラッグし、離すと接合形状を更新します。分割位置の数値入力と連動し、ボス側・棒側の深さを表示します。移動中は視点と倍率を維持し、矢印キーで1 mm、Shift＋矢印で0.1 mm、Escで移動を取り消せます。「接合プレビューに戻る」で通常のプレビューに戻ります。XY・XZ・YZの各平面、印刷配置・組み立て位置に対応し、位置は保存・再編集できます。

### 締め付け式ボールジョイント

「ソリッド → ボール接合」または「作成・修正 → 締め付け式ボールジョイント」で、中実の円柱を球側・切り込み付き受け側・専用ナットの3つのソリッドに変換します。移動・回転済みの円柱も軸を自動判定します。穴・シェル・段差などがある円柱には対応しません。元の円柱の両端を保ち、ジョイントを収められない長さ・寸法は確定しません。

球径、首の径・長さ、球のすき間、受け厚さ、切り込み幅・4/6本、ねじピッチ・すき間、ナット厚さを指定できます。受けとナットは実形状のねじでかみ合い、ナットの内側の傾斜が受けの傾斜を押して球を保持する構造です。ねじが2巻き以上かみ合い、球のすき間を詰める締め代を確保できる寸法に限定します。ナット外周には指で回すための溝を付けます。

初期寸法は円柱の大きさに合わせます。印刷配置／組み立て位置／分解表示を切り替え、受け・ナットを透かして内部を確認できます。印刷配置は3パーツを離してZ=0に接地します。球側へナットを通し、球を受けへ押し込んでからナットをねじ込みます。締め付けは受けの弾性変形を使うため、保持力は印刷精度・材料で変わります。保存・読み込み・再編集・元に戻す／やり直すに対応します。

オプション「土台の側面に取付ねじを付ける」で、球側／受け側／両方の土台の自由端を実形状の右ねじにできます。取付ねじのピッチ（相手の穴用ねじと共通の選択肢）・長さ・片側すき間（初期0.15 mm）は締め付けナットとは独立します。元の円柱外径を呼び径とし、すき間の2倍だけねじの外径を細くします。相手の部品には同じ呼び径の円筒穴と同じピッチの60°三角ねじを別途作成します。ねじ入口には斜面を付け、土台根元に1.2 mm以上、ねじに2巻き以上を確保します。土台が短い場合は確定せず、長さ・ピッチ・分割位置の調整を案内します。初期はオフで、旧保存データの形状も変えません。

検証: `node tests/ball-joint.mjs`、`node tests/ball-joint-browser.mjs`、`node tests/ball-joint-mount.mjs`、`node tests/ball-joint-mount-browser.mjs`。

### ボール接合の固定用ねじ穴

「端面中央の固定用ねじ穴 → 反対側の中心に固定用ねじ穴を作る」をオンにすると、球側・受け側のジョイントと反対の端面中央に、60°簡易形状の右ねじの止まり穴を作成します。両方／球側だけ／受け側だけを選び、球側と受け側でそれぞれM3〜M16のサイズ例、または呼び径3〜40 mm・ピッチ0.5〜5 mmの数値指定と穴の深さを設定できます。初期値はオフ、M6 × 1、深さは両端の土台に収まる範囲で最大6 mmです。

通常のねじ機能の「自動プル」と同じ処理を−0.2 mmで適用します。両側面・山頂面・円筒内壁を調整し、円筒内壁の直径は呼び径＋0.4 mmになります。呼び径だけを大きくしたねじとは異なります。穴底と外周に1.2 mm以上を残し、2巻き以上・20巻き以内に制限します。側面の取付ねじと併用する場合は、外ねじの谷から穴までの材料厚さも確認します。深すぎる穴・薄すぎる外周は確定しません。

印刷配置・組み立て位置・分解表示、移動・回転した円柱、保存・再編集・元に戻す／やり直すに対応します。固定ねじ穴の設定がない旧データは穴なしを維持します。従来の共通寸法は両側へ引き継ぎ、再編集・保存後は個別の設定として記録します。片側のみを選ぶと、その側の寸法だけを検証します。検証: `node tests/ball-joint-fix-hole.mjs`、`node tests/ball-joint-fix-hole-browser.mjs`。通常のねじを作ってから全ねじ面を−0.2 mmプルした実形状との一致、穴底・形状・メッシュ、指定側・寸法・保存操作を確認します。

固定ねじ穴の球側・受け側それぞれに「入口に面取りを付ける（45°）」オプションを追加しています。面取り幅 C は円筒内壁から入口を外側へ広げる幅で、0.1〜5 mmを個別に指定できます。初期値はオフ、幅 C0.3 mmです。入口のねじ山も45°で削り、面取りの奥に1巻き以上の完全なねじを残し、入口外周の材料厚さ1.2 mmも確認します。穴の底や奥のねじ、自動プル−0.2 mmは保持します。面取り設定のない既存ファイルは面取りなしで引き継ぎます。検証: `node tests/ball-joint-fix-chamfer.mjs`、`node tests/ball-joint-fix-chamfer-browser.mjs`。

### ボール接合の印刷向け締め付けねじ

「印刷向けの太いねじを使う」を追加しました。新規はオン、ノズル径0.6 mmです。0.4／0.6／0.8 mmから選び、「ノズルに合わせる」でピッチを設定できます。0.6 mmではピッチ4.5 mm、雄側の山頂幅0.9 mm、ナットの山幅は断面上1.32 mm、斜面は約47.7°です。幅・斜面・入口の斜面を実形状に反映し、締め込んだときにねじ山が先に当たらないよう、ねじ始点・長さ・締め代も再計算します。入口の斜面を除いて2巻き以上を残します。必要な長さがない円柱や、大きすぎるすき間は確定しません。

旧保存データは従来の形状・ピッチを維持します。「再編集」で太いねじを有効にし、ノズル径を合わせて再適用してください。受け側（雄ねじ）と専用ナットをセットでSTLに出し直し、両方を再印刷します。従来形状との混用には対応しません。土台の取付ねじは別設定です。印刷精度・材料による実際の締まり具合は試し刷りで確認してください。

検証: `node tests/ball-joint-print-thread.mjs`、`node tests/ball-joint-print-thread-browser.mjs`。実BRepの線分交差で雄ねじ・ナットの山幅を測り、0.4／0.6／0.8 mmの形状・完全なメッシュ、回転だけでは山がかみ合うこと、正しい回転と送りでは締め代全域でねじ山が干渉しないこと、傾斜面による締め付けを確認しています。

### 0.6 mmノズル用の位置決め補強

ボス接合の位置決めには「0.6 mmノズル用に位置決めを補強する」を追加しました。新規作成ではオン。縁の幅と受け溝の内外の壁・底に1.2 mm以上を確保し、合わせ面付近だけ内側へ補強します。内部の移行部は45度の斜面です。外寸と指定の片側・底すき間は保ち、収納空間は縁付近だけ狭くなります。溝と底厚を収める深さが足りない場合は作成しません。

既存ファイルの0.4 mm／0.25 mmの薄い壁は自動変更しません。「再編集」で補強をオンにして適用し、STLを出し直してください。補強オフでは従来の寸法を維持します。形状の厚さは確認していますが、実際の押出幅・スライサー設定に合わせた確認も必要です。

### ボスのはめ合いプリセット・試し刷り

ボス接合の「はめ合いのプリセット」は緩め0.25 mm／標準0.15 mm／きつめ0.10 mm（すべて片側）です。新規は標準、既存データは保存済みの数値を維持し、プリセットにない値は「数値で指定」と表示します。数値入力とプリセットは連動し、穴径は棒径＋すき間×2です。位置決めの縁・溝のすき間は変更しません。

「4種類のテストピースをSTL出力」は現在の棒径・差し込み長さ・ボス肉厚・最低高さを使い、0.10／0.15／0.20／0.25 mmのボスと棒を各1個、計8部品にします。ボスには1.2 mm以上の底厚、棒には本番と同じ先端の傾斜、台座にはすき間の浮き文字を付けます。8部品を離してZ=0に配置し、180 mm四方に収まらない大きさは出力しません。元のモデルや編集中の寸法は変更しません。印刷して合う組を選び、その数値を本番の片側すき間に指定します。はめ合いは材料・押出条件で変わるため、プリセット名は目安です。

検証: `node tests/boss-fit-test.mjs`、`node tests/boss-fit-browser.mjs`。
