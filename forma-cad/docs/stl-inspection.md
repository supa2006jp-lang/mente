# STL出力時の検査

通常のSTL保存に加え、BOX印刷姿勢、コイル接合試片、ボスはめ合い試片、円柱ホルダー試着リングにも共通の検査を通す。

ファイル名・保存先の指定を取り消した場合は計算しない。保存対象の精密メッシュをワーカーで作り、実際に書き込むFloat32座標でボディ別に調べる。閉じていない辺、3枚以上が共有する辺、隣接面の向きの不一致、重複三角形、不正な座標と参照、空・逆向き・ゼロ体積のメッシュを確認する。CAD形状がある場合はネイティブソリッドの妥当性とCAD各面に対応する三角形の存在も確認する。

以前からSTL保存時に除外していた厳密な面積ゼロの三角形は、検査段階で除外し、除外後に閉じていることを検証する。近い頂点を寄せる、穴を塞ぐ、別ボディを融合する、CAD面を動かす修復は行わない。CAD形状は毎回独立して読み、キャッシュを消して再メッシュする。問題が残る場合は異なる細かさで2回まで再生成・再検査する。修復できた出力メッシュだけをSTLへ使い、作業中の表示メッシュ、BREP、寸法、履歴、Undoは変えない。

未解決・未検査の結果は保存しない。「STL出力の検査」パネルでボディ名と内容を示す。「問題箇所を強調」で問題の辺を赤線、辺の位置を特定できないときは対象ボディを赤枠で示す。視点・選択・表示状態は変えない。線は最大300本、件数は検査した全体の値。1ボディ40万三角形を超える場合は未検査として扱い、問題なしとは表示しない。中止、パネルを閉じる、モデル・表示対象の変更でワーカーと古い結果を無効にする。

離れた部品や意図して接触した独立ボディは、それぞれを閉じた形状として検査する。別ボディ間の干渉、面同士の自己交差、壁厚、印刷姿勢、強度やねじ規格の適合を保証する検査ではない。

ボスはめ合い試片の7セグメント数字は、従来は角同士が辺だけで接触し、CADソリッドの検査を通ってもSTLでは1本の辺に4枚の面が集まることがあった。新規に作る試片は線端を0.1 mm重ねてまとめて結合し、面で連続した数字にする。保存済みの試片は書き換えず、問題があれば検査パネルに表示する。

検証: `tests/stl-inspection.mjs`、`tests/stl-cad-inspection.mjs`、`tests/stl-inspection-export.mjs`、`tests/stl-inspection-browser.mjs`。既存のねじの表示品質・STL出力と保存ダイアログの回帰も確認する。
