# 同じボディの表面まで押し出す

「ソリッドの表面まで」は、新規・結合の操作で、押し出し元と同じボディの反対側の面にも到達できます。コの字形の内側を埋める場合などが対象です。開始面そのものや、開始位置で側面に触れるだけの部分は到達先にしません。切り取りの対象自身を障害物から除く従来の動作は維持します。

接触先を見つけられないときも「ソリッドの表面まで」をONのまま保ち、計算のエラーを表示します。距離指定に自動で切り替えて確定できる状態には戻しません。向きや開始面を変更するか、明示的にOFFにして距離指定に戻してください。

元の面と到達先にわずかな高さの差がある場合、到達する部分と到達しない部分が分かれます。「接触する部分だけ押し出す」をONにすると、到達しない薄い部分を省けます。OFFでは従来通り、非接触部分も最後の接触位置まで延長します。既存ファイルの設定や寸法を勝手に変更しません。

接触計算には独立したCAD形状を使用します。面を押し出すネイティブ処理によって元の辺の内部データが変更されることを防ぎます。

## 検証

- `node tests/extrude-until-self.mjs`：同一ボディの正逆方向、斜面、手動で途中停止、高さの差、接触しない形状、プレビューと確定、単一ソリッド、元形状の保存、閉じたSTL。
- `node tests/extrude-until-self-browser.mjs`：先にネイティブテストを実行して生成した公開可能な試験片を読み込み、再編集、設定の切り替え、確定、STL出力、Undo/Redo、保存・再読込、失敗時の設定保持を検証。
- ユーザーモデルによる検証結果と修正版データは `.sites-runtime` にのみ保存し、公開ファイルには含めません。
