# 補助線と寸法測定

線分を作図している途中に、右クリックで通常線と補助線を切り替える。始点を置く前でも、終点を指定する途中でも使える。上部の「通常線／補助線」ボタンでも切替可能。補助線は紫の破線で表示し、連続作図中は選んだ種類を保つ。新しく作図を始めると通常線に戻る。右ドラッグによる視点の平行移動はそのまま使える。直線と曲線を切り替える場合は作図中の専用ボタンを使う。

補助線は端点吸着・拘束・ミラーの基準・測定には使える。閉じた領域の作成や区切りには含めず、そのまま押し出しの対象にはしない。保存・再読み込み、選択部品の保存・貼り付けでも種類を保持する。

「寸法」は線分ボタンの隣にある。形状を変えない測定コマンドで、次の方法に対応する。

- **2点間**：スケッチやソリッドの頂点・辺の中点・円の中心・面上の点、作図平面上の任意点を順に選ぶ。「表示する距離」で直線距離・X方向の幅・Y方向の奥行き・Z方向の高さを選ぶ。2点の位置を保ったまま測定後も切替可能。方向別の寸法線は該当するワールド軸へ投影し、元の測定点から引出線を表示する。方向差がない場合は0 mmを表示する。Altを押すと吸着を外す。
- **線・辺を直接選択**：1本目をクリックすると長さを表示する。続けて別の線・辺をクリックすると、有限の2本の最短距離と直線同士の角度に切り替える。同じ辺を2度選んだ場合は変更せず、別の辺を案内する。「測定を追加」で別の長さを測れる。最初の辺は青、2本目は橙、カーソル上の候補は緑で強調する。直線の角度は辺の向きを区別しない0〜90°。交差する2本の距離は0 mmでも角度とともに表示する。円は円周全体、曲線は表示された曲線全体を測り、表示形状から求める近似値には「約」を付ける。曲線同士や曲線と直線の組合せは近似の最短距離を表示し、単一の角度は表示しない。ソリッドの連続した直線辺は表示用に分割されていてもまとめ、離れた区間はつながない。
- **点から指定方向の線・面まで**：始点を選び、X/Y/Zの＋・－、XYZベクトルによる任意方向、または画面で方向を示す点を指定する。前方で最初に当たる有限のスケッチ線・ソリッドの辺や面までを測定する。始点で接している面や線だけを0 mmとして報告しない。対象がなければその旨を表示する。曲面・曲線は表示形状の精度による。

「線・辺を直接選択」で円やソリッドの円形の辺を選ぶと「円の寸法」が現れ、円周長・直径 ⌀・半径 Rを切り替えられる。外周だけでなく円形の穴の内周にも対応する。直径は円の反対側から選択位置まで、半径は中心から選択位置までの寸法線を表示する。円周として認識できない曲線・非一様拡大された楕円には円の選択肢を表示しない。

「測定を追加」で別の寸法を測定できる。最大20個を表示し、「終了」後も画面に残す。「表示を消す」で削除する。視点変更・ズームに追従する。寸法の種類・測定点・表示位置をFORMAファイルへ保存し、通常保存・上書き保存・軽量保存・画像一覧からの再読み込みで復元する。寸法の追加・変更・削除・ドラッグ確定も未保存の変更として扱う。保存処理中に寸法を変更した場合、変更後の内容を保存済みとして扱わない。寸法情報のない旧ファイルを開いた場合は前のファイルの寸法を消す。CAD形状・履歴は測定で変わらないが、形状を編集した場合は古い寸法を消して再測定を案内する。

寸法ラベルまたは寸法線をドラッグすると、数値を変えずに表示位置だけを移動できる。Escでドラッグ開始前の位置へ戻す。「終了」後もドラッグでき、視点変更後も形状を追従しながら指定した画面上のずらし量を保つ。寸法ラベル横の「×」はその寸法だけを削除する。ラベルにフォーカスがあるときはDelete・Backspaceでも削除できる。これらの操作はモデル・履歴を変更しない。

点の指定は、カーソルから10 px以内で線分・辺上とグリッド交点が重なる場合、その交点を最優先し「線分上のグリッド交点」と表示する。線分の延長上や線分から離れた交点には移らない。それ以外は端点・中点・円の中心、スケッチ線分上・ソリッドの辺上、作図平面のグリッド交点の順に吸着する。グリッドのON/OFFと間隔は既存の「グリッド吸着」「間隔」に従う。始点・終点・画面で方向を指定する点で共通に使え、吸着中は緑の丸と対象名を表示する。ソリッドの裏側に隠れた辺や交点には吸着しない。Altで全吸着を一時解除する。

追加検証：node tests/dimension-measure-snap-browser.mjs。線分上の任意点、グリッド交点、端点・中点の優先、Alt解除、グリッドOFF・間隔変更、ソリッドの辺と裏側の除外を確認する。

直接測定・表示編集の検証：node tests/dimension-measure-direct.mjs、node tests/dimension-measure-direct-browser.mjs。有限3D線分の交差・平行・ねじれ・端点間距離、角度、円周全体、ソリッドの辺の結合、ラベル・寸法線のドラッグ、Esc取消、視点変更、個別削除、モデル不変を確認する。

方向別寸法・円寸法・保存の検証：node tests/dimension-measure-components-state.mjs、node tests/dimension-measure-components-state-browser.mjs。X/Y/Zの切替・0 mm・投影、傾いた円の直径と半径、円柱の外周と穴の内周、通常／軽量保存での寸法種類・表示位置の復元、旧ファイル、未保存表示、入力データの検証を確認する。
