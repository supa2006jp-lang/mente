# 補助線と寸法測定

線分を作図している途中に、右クリックで通常線と補助線を切り替える。始点を置く前でも、終点を指定する途中でも使える。上部の「通常線／補助線」ボタンでも切替可能。補助線は紫の破線で表示し、連続作図中は選んだ種類を保つ。新しく作図を始めると通常線に戻る。右ドラッグによる視点の平行移動はそのまま使える。直線と曲線を切り替える場合は作図中の専用ボタンを使う。

補助線は端点吸着・拘束・ミラーの基準・測定には使える。閉じた領域の作成や区切りには含めず、そのまま押し出しの対象にはしない。保存・再読み込み、選択部品の保存・貼り付けでも種類を保持する。

「寸法」は線分ボタンの隣にある。形状を変えない測定コマンドで、次の方法に対応する。

- **2点間**：スケッチやソリッドの頂点・辺の中点・円の中心・面上の点、作図平面上の任意点を順に選ぶ。直線距離を寸法線で表示する。Altを押すと吸着を外す。
- **点から指定方向の線・面まで**：始点を選び、X/Y/Zの＋・－、XYZベクトルによる任意方向、または画面で方向を示す点を指定する。前方で最初に当たる有限のスケッチ線・ソリッドの辺や面までを測定する。始点で接している面や線だけを0 mmとして報告しない。対象がなければその旨を表示する。曲面・曲線は表示形状の精度による。

「測定を追加」で別の寸法を測定できる。最大20個を表示し、「終了」後も画面に残す。「表示を消す」で削除する。視点変更・ズームに追従する。測定値は画面上の確認用で、FORMAの保存データには追加しない。形状を変更・読み込みした場合は古い寸法を消して再測定を案内する。

点の指定は、カーソルから10 px以内の端点・中点・円の中心を優先し、次にスケッチ線分上・ソリッドの辺上、次に作図平面のグリッド交点へ吸着する。グリッドのON/OFFと間隔は既存の「グリッド吸着」「間隔」に従う。始点・終点・画面で方向を指定する点で共通に使え、吸着中は緑の丸と対象名を表示する。ソリッドの裏側に隠れた辺や交点には吸着しない。Altで全吸着を一時解除する。

追加検証：node tests/dimension-measure-snap-browser.mjs。線分上の任意点、グリッド交点、端点・中点の優先、Alt解除、グリッドOFF・間隔変更、ソリッドの辺と裏側の除外を確認する。

検証：node tests/construction-dimensions.mjs、node tests/construction-dimensions-browser.mjs。補助線の区切り除外・破線・保存、右クリック切替・連続作図・右ドラッグ、2点間、指定方向の最初の線、任意方向・画面指定、対象なし、ソリッドの頂点・面・隙間・厚み、視点変更、形状変更時の消去を合成モデルで確認する。
