# 部品の接合・収納・動作確認

## 蟻継ぎ

1. 2つのソリッドの平面を接触させます。「位置合わせ・固定」などで位置を合わせてください。
2. ツールバーの「蟻継ぎ」を開き、凸側と凹側を選びます。ツールバーで省略されている場合は「作成・修正」のコマンドから選べます。
3. 根元の幅・深さ・開き角度・片側のすき間を指定します。差し込み方向の角度と横位置も調整できます。
4. 「精密プレビュー」で確認し、「作成」で確定します。金色が凸側、青が凹側です。「分解して形状を確認する」は表示だけを離します。

接触している平面のうち最大の領域を基準にします。あらかじめ平面を選んで開くと、その面の境界に限定します。凸と溝を一度に加工し、2つのボディは別々に残します。差し込み方向の両端が開いた継ぎ手です。寸法が材料からはみ出す場合や、加工後にボディが分断される場合は確定しません。

片側のすき間0.2 mmは、溝を凸部から各側へ0.2 mm広げる設定です。実際のはめ合いはプリンター・材料・印刷方向に応じて調整してください。

## 座ぐり穴

「穴あけ」で中心点を選び、「座ぐりを付ける」をONにすると、座ぐり径と深さを指定できます。入口側に平らな肩のある円筒状の段を作ります。座ぐり径は主穴より大きく、座ぐり深さは主穴より浅く指定してください。貫通穴にも使えます。

加工は主穴と座ぐりをまとめて実行します。履歴の穴あけ工程を開くと、右側の座ぐり設定を再編集できます。通常の円形穴の深さと座ぐり深さは、それぞれ入口の面から測った値です。座ぐり穴のテーパー角度は0°です。

## 専用収納トレー

「収納トレー」で収納するボディを選び、列数・すき間・外壁厚・底厚・ポケット深さを設定します。現在の向きのXY平面への投影輪郭から、上に開いた一定深さのポケットを作ります。指掛けと部品名の浮き文字を追加できます。

トレーは独立した新規ボディとして、元の部品に重ならない位置へ配置します。元の部品の形状や配置は変えません。「収納した部品を半透明で表示」は収まりを確認するための表示で、部品の移動は保存しません。

## 動作確認

「動作確認」で動かすボディを選び、回転またはスライドを設定します。XYZ軸・任意方向・開く前に選択した直線の辺を軸にできます。回転では軸の位置も設定してください。

画面上のハンドルをドラッグするか、数値・スライダーで位置を調整します。「この位置の干渉を検査」で、実際のCAD形状が重なった部分を赤く表示します。接触だけの場合と、体積が重なる干渉を区別します。

「範囲の13位置を検査」は開始から終了まで等間隔の13位置を調べます。その間の連続的な衝突や、力・荷重を計算する機能ではありません。再生中は位置だけを表示し、干渉は停止時に検査します。

「動きの設定を保存」で履歴に設定を保存できます。表示を動かしても元のモデルの配置は変わらず、閉じると元の位置へ戻ります。STLなどの出力も元の配置を使います。

各機能は履歴・プロジェクト保存・読み込み・元に戻すに対応します。
