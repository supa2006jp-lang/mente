# 押し出しの確認と失敗時の記録

## 加工後のCADプレビュー

押し出し・切り取り・新規作成は、確定と同じCAD処理を先に計算し、加工後の形を水色で表示する。計算中と失敗時は確定できない。履歴の再編集では後続工程の再計算も含めて表示する。

同じモデル・入力条件の計算結果は容量と件数を制限したキャッシュから確定に使用する。モデルや距離、操作、対象などが変わった結果は使用しない。結合対象の確認で対象を変更した場合は、その選択に応じて再計算する。プレビューだけではモデル履歴を変更しない。

## 平面と曲面の選択

選択した面の種類を左下に表示し、輪郭を平面は青緑、曲面はオレンジで表示する。フィレットを含む曲面は押し出せる平面と区別する。

選択モードの横の「境界では平面を優先」を有効にすると、曲面をクリックした際に近くの見えている平面の境界を優先できる。初期状態はオフ。隠れた面や別ボディには選択を移さず、候補から明示的に選ぶ操作も維持する。

## 失敗直前の自動記録

CAD処理が失敗した際に、元モデル、選択面、入力条件、エラーをこのブラウザーのIndexedDBに保存する。キャンセルは記録しない。保存は直近の最大3件、合計80 MiB以内とし、古い記録から削除する。保存容量不足や利用不能の場合は記録画面に理由を表示し、メモリーに残った最新記録をファイル保存できる。

ツールバーの「失敗時の記録」から復元、ファイル保存、削除ができる。押し出しは入力条件も編集状態に復元するが、失敗した計算を自動で再実行しない。他のCAD操作は元モデルを復元し、処理要求と入力条件は保存ファイルのfailure項目で確認できる。復元直前のモデルには「元に戻す」で戻れる。ブラウザーのサイトデータを削除すると記録も消える。

## 検証

- tests/exact-extrusion-preview.mjs：結合・切り取り・新規の形状と体積、表示メッシュ、キャッシュの無効化、後続履歴の再計算、全体切り取り、面分類、不変の失敗記録。
- tests/extrusion-reliability-browser.mjs：曲面と平面の選択、計算済みプレビューと確定の一致、モデルを変更しないプレビュー、3件保持、ファイル保存、再読込後の復元、再実行の抑止、修正後の確定とUndo/Redo。
- tests/extrusion-join-confirm-browser.mjs：個別の結合対象選択、接続の確認、キャンセル、再編集、同じ選択の計算結果再利用。
