# 選択したスケッチ・ソリッドの保存と貼り付け

1. 画面をドラッグして、保存する範囲を選ぶ。自動選択ではスケッチの線とソリッドの面を同時に選べる。Ctrl＋範囲選択で追加できる。
2. 左下の「選択を部品として保存」、または上部の「選択部品」を押す。
3. 「スケッチ」「ソリッド」のタブで保存先を選び、名前を付けて一覧へ保存する。両方選択した場合も、種類別に保存する。面や辺の選択では、そのソリッド全体が対象になる。
4. 別の作業ファイルで「選択部品」を開き、種類別の一覧から「呼び出して配置」を押す。
5. 水色のプレビューを確認し、座標入力、矢印のドラッグ、または「画面で配置」で位置を調整する。グリッド吸着はAltで一時解除できる。「貼り付けを確定」または矢印の「＋貼付」で確定する。

「元の位置」は保存時の場所へ、「原点に配置」は保存部品の底面中央を原点へ戻す。「空き位置」は既存形状の範囲から離して配置する。「部品を全体表示」でプレビューを画面に収める。貼り付け前のキャンセルはモデルも履歴も変更しない。複数要素の貼り付けはまとめて一度で元に戻せる。

同じ種類の複数要素の位置関係を保持する。スケッチは線・円・曲線・点として保存し、貼り付け後も選択・編集・押し出しができる。一部の直線だけを選んだ場合は選択した線だけ保存する。文字の輪郭なども線として扱い、元モデルへの追従参照や作成履歴は持ち込まない。ソリッドはCAD完成形状として保存し、穴・曲面・フィレットを保持する。貼り付けた形状は毎回新しい識別情報になり、元モデルから独立する。

一覧はこのブラウザーのIndexedDBに保存する（合計最大100件、100 MiB）。サイトデータの削除で一覧も削除される。ファイル保存はスケッチを `.forma-sketch.json`、ソリッドを `.forma-solid.json` として書き出し、別端末でも「部品ファイルを読み込む」から配置できる。ファイルは80 MBまで。一覧への保存失敗は表示し、ファイル保存を選べる。既存の単体ソリッド用「部品テンプレート」も引き続き使用できる。

一覧には320×240のプレビュー画像が付き、画像のクリックでも配置を始められる。スケッチは平面に沿った見やすい向き（複数の向きが混在する場合は斜め）、ソリッドは標準の斜め視点で撮影する。選択した形状だけを撮影し、現在の視点・選択色・断面表示には影響されない。画像は部品ファイルにも含める。画像なしの既存部品は一覧を開いた際に順次生成して保存し、以降は保存画像を再利用する。画像だけの更新は部品データや保存日時を変更しない。画像の保存に失敗しても部品データは保持する。

検証：`tests/selection-library.mjs`、`tests/selection-library-browser.mjs`。穴とフィレット付きボディ、複数平面のスケッチ、部分線分、再読込、種類別一覧、独立したID、配置プレビュー、グリッド吸着、Undo/Redo、不正ファイルを確認する。

画像の検証：`tests/selection-library-thumbnails-browser.mjs`。既存部品の画像生成、画素のある画像、種類別の画像、再読込後の保持、再生成の抑制、画像付きファイル、画像からの配置を確認する。
