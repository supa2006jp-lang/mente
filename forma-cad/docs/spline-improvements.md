# スプラインの接線・点の整理・自己交差表示

## 曲線と直線を滑らかにつなぐ

フィット点スプラインから作図を開始すると、作図バーに「接線を自動で引き継ぐ」が表示されます。初期状態はONです。

- 右クリックで曲線から直線に切り替えると、曲線の終点の接線方向に直線の角度を固定します。
- 直線から曲線に戻すと、直前の直線の方向を曲線の始点接線に設定します。
- チェックを外すと自動設定を解除し、自由な方向で続けられます。角度や接線を手動で変更することもできます。

通常の線分コマンドから開始した場合、右クリックの通常線・補助線切替は従来どおりです。

## フィット点を整理

作図中、または既存のスプラインを選択中に、右側の「フィット点を整理」を押します。3点以上の曲線で利用できます。

1. 許容誤差を指定します（初期値0.25 mm、0.001〜10 mm）。
2. 青い元の曲線に、橙色の破線で整理後の候補を重ねます。点数と比較誤差の目安も表示します。数値を変更したら「プレビュー更新」を押してください。
3. 「整理を確定」で反映します。キャンセルでは元の曲線を変更しません。

開いた曲線の両端と接線方向・ハンドル長を保持します。自動ハンドル長が保存可能な範囲外の場合は隣の点も残します。閉じた曲線では最初の点・閉じた状態・向きを保ちます。既存曲線の確定は元に戻す／やり直しに対応し、依存する押し出しも更新します。

誤差は細かく分割した元の曲線との双方向比較による目安です。新たな自己交差を生む候補は採用しません。元から自己交差している場合は、先に交差を修正してください。計算は候補400回までで区切り、キャンセルできます。許容誤差内で点を減らせない場合は確定できません。

## 自己交差を作図中に表示

作図中と選択中のスプラインに自己交差があると、交差付近を赤い線と丸で表示し、右側に箇所数を表示します。次のフィット点を決める前のカーソル追従部分も対象です。交差を解消すると表示が消えます。

検出は画面の曲線と同じ分割線で行う目安で、形状を自動変更しません。隣り合う分割線や閉じた曲線の継ぎ目は対象外です。表示は最大100箇所です。

## 検証

- `npm test`: 曲線比較、点削減、端点保持、小さい自動ハンドル、閉曲線、交差、計算中止を含む単体テスト。
- `node tests/spline-improvements-browser.mjs`: 接線の引き継ぎ・解除、比較プレビュー、キャンセル、誤入力、元に戻す／やり直し、再読込、依存押し出し、カーソル追従中の交差表示。
- `node tests/spline-improvements-native.mjs`: ブラウザーで保存した整理後の閉曲線をCADで押し出し、体積・有効性・STLの閉じた状態を検証。先にブラウザーテストを実行します。
