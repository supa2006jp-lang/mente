# ソリッド境界で自動的に囲む

線分の作図中、描いた線と同じ平面にあるソリッド境界を組み合わせて閉領域を検出する。画像のような切欠きでは、口を線分で結ぶと残りの境界だけを通常のスケッチ線として追加する。

- 作図中の「ソリッド境界で自動的に囲む」は初期状態ON。OFFで従来の線分作図になる。
- 緑の破線と薄い緑の面が取り込み予定。終点クリックで描いた線と同時に確定し、1回のUndoでまとめて戻せる。プレビュー中の保存は元の形状を保存する。
- 同一スケッチの既存線を利用し、重複する境界は追加しない。既にスケッチだけで閉じた場合、補助線、非表示のボディ、作図平面から離れた見かけの輪郭は対象外。
- 複数の閉領域ができる場合は候補数と面積を表示する。作図中は終点を動かさずにTab／Shift+Tabで候補を切り替え、緑の領域を確認して終点をクリックする。初期候補はソリッド外側の空間を優先し、その中で小さい領域を選ぶ。面上を区切る場合は小さい側が初期候補になる。
- 描画済みの開いた線・折れ線・スプラインを選択すると、左下に「ソリッド境界で囲む」を表示する。専用の領域を確保したパネルで候補を切り替え、「この囲みで確定」で不足した境界だけを追加する。キャンセル／Escでは何も変更しない。モデルを変更した場合は古いプレビューを閉じる。
- コピーした境界は独立した通常スケッチ。元ソリッドの変更には追従しない。円の作成情報と実際の円形境界が一致する場合、連続した部分を円弧として取り込み、押し出しでも円筒面を保つ。円形と確認できない境界や、円からずれた端点は線分のまま取り込む。任意の多角形を円弧に置き換えない。
- 境界とスケッチが合計4,000線分を超える場合は、操作の応答性を保つため自動取り込みを省略する。

境界吸着と取り込みでは、領域表示用の微小な隙間補正を行わず、元の角と断面の座標を保つ。三角形の描画分割線を輪郭として利用しない。

検証：`tests/sketch-solid-boundary-fill.test.js`、`tests/sketch-solid-boundary-fill-browser.mjs`、`tests/sketch-solid-boundary-fill-native.mjs`、`tests/sketch-boundary-tools.test.js`、`tests/sketch-boundary-tools-browser.mjs`、`tests/sketch-boundary-tools-native.mjs`。ブラウザー試験は独立したEdgeで実際に描画・候補切替・保存・Undo/Redo・押し出しを実行する。native試験はその出力の体積・円筒面・閉じたメッシュを検査する。
