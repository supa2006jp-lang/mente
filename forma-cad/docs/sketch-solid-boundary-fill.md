# ソリッド境界で自動的に囲む

線分の作図中、描いた線と同じ平面にあるソリッド境界を組み合わせて閉領域を検出する。画像のような切欠きでは、口を線分で結ぶと残りの境界だけを通常のスケッチ線として追加する。

- 作図中の「ソリッド境界で自動的に囲む」は初期状態ON。OFFで従来の線分作図になる。
- 緑の破線と薄い緑の面が取り込み予定。終点クリックで描いた線と同時に確定し、1回のUndoでまとめて戻せる。プレビュー中の保存は元の形状を保存する。
- 同一スケッチの既存線を利用し、重複する境界は追加しない。既にスケッチだけで閉じた場合、補助線、非表示のボディ、作図平面から離れた見かけの輪郭は対象外。
- 複数の閉領域ができる場合は候補数と面積を表示する。作図中は終点を動かさずにTab／Shift+Tabで候補を切り替え、緑の領域を確認して終点をクリックする。初期候補はソリッド外側の空間を優先し、その中で小さい領域を選ぶ。面上を区切る場合は小さい側が初期候補になる。
- 描画済みの開いた線・折れ線・スプラインを選択すると、左下に「ソリッド境界で囲む」を表示する。専用の領域を確保したパネルを開き、画面の薄い緑の領域を直接クリックすると候補が切り替わる。濃い緑が選択中。「この囲みで確定」で不足した境界だけを追加する。キャンセル／Escでは何も変更しない。モデルを変更した場合は古いプレビューを閉じる。
- 作図中も候補が表示された状態でSpace、または「領域をクリックで選ぶ」で終点を固定して領域選択へ移る。この場合は描画中の線と補完線をまとめて確定し、1回のUndoで戻せる。直接の終点クリックとTab切替も利用できる。
- 円の作成情報、またはCADエンジンがCIRCLEと判定した辺と実際の円形境界が一致する場合、連続した部分を円弧として取り込み、押し出しでも円筒面を保つ。フィレットや回転で作った円弧にも対応する。任意の多角形・楕円・スプラインを円弧に置き換えない。円形と確認できない境界や、円からずれた端点は線分のまま取り込む。
- 新しく取り込む境界は「元の境界に追従」を選べる（初期OFF）。OFFなら取り込んだ形を固定し、ONなら履歴上の元ソリッドの寸法変更に合わせ、囲みの境界と元の線、後続の押し出しを更新する。取り込み済みの追従情報付き境界を選ぶと、左下でもON/OFFを切り替えられる。OFF中に寸法が変わった場合も再度ONで更新する。
- 追従は1つのソリッドの境界で囲む場合が対象。基準は取り込み時点の履歴。複数ボディにまたがる囲みは固定で取り込む。ONの境界の直接編集にはOFFへの切替が必要。元の線が別の追従や拘束を持つ場合、元ボディの面・辺構成や平面の向きが変わった場合、閉領域を一意に特定できない場合は更新を中止し、モデル全体を変更前の状態に保つ。自動で別の候補に飛び移らない。
- 境界とスケッチが合計4,000線分を超える場合は、操作の応答性を保つため自動取り込みを省略する。

境界吸着と取り込みでは、領域表示用の微小な隙間補正を行わず、元の角と断面の座標を保つ。三角形の描画分割線を輪郭として利用しない。

検証：`tests/sketch-solid-boundary-fill.test.js`、`tests/sketch-solid-boundary-fill-browser.mjs`、`tests/sketch-solid-boundary-fill-native.mjs`、`tests/sketch-boundary-tools.test.js`、`tests/sketch-boundary-tools-browser.mjs`、`tests/sketch-boundary-tools-native.mjs`。ブラウザー試験は独立したEdgeで実際に描画・候補切替・保存・Undo/Redo・押し出しを実行する。native試験はその出力の体積・円筒面・閉じたメッシュを検査する。

追従・直接選択の検証：`tests/solid-boundary-links.test.js`、`tests/sketch-boundary-follow-native.mjs`、`tests/sketch-boundary-follow-browser.mjs`。元ボディの幅・高さ・厚さ、接続線、後続押し出しの面積・位置・体積、OFFでの固定と再ON、参照不能時の変更中止、フィレットの円弧押し出し、保存・Undo/Redoを検査する。
