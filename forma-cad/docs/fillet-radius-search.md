# フィレット半径の調査

「全ての辺に掛けられる半径を調べる」は、全対象ボディ・全対象辺に同じ半径を適用した形状を検証します。辺を省いた部分適用は行いません。同一面の分割境界の整理は、形状の妥当性と体積を確認してから使用します。

検査は入力半径と0.1 mmの小さい方から開始します。成功すれば倍々に半径を広げ、失敗した値との間を0.01 mm単位で調べます。最初の値が成立しない場合は、小さくして調べます。「入力半径を超えて上限も自動で探す」がOFFのときは、入力値を超えません。

結合した薄壁のような形状では、大きすぎる半径で形状エンジンが異常終了する場合があります。小さい半径から全対象の確認済み結果を確保します。その後に時間切れやエンジン異常が起きた場合は、作成・妥当性検査が完了した結果だけを返します。エンジン異常時は「上限は未確認」と表示し、最大半径を確定した扱いにはしません。異常終了したワーカーは破棄し、次の計算には再利用しません。

結果はプレビューです。「実行」するまでは元のモデルを変更しません。全対象の確認済み結果がない場合は成功扱いにせず、元のモデルを保持します。
