# 連結リブサポート

モデルの下面をベッドや下側のモデルから支える、取り外し用サポートを作る機能です。ベッド上には広い円形の足、モデル上には細い接点を作ります。支柱間の斜め補強を追加でき、背の高い支柱を支えます。造形物とは別のCADボディとして保存します。実機での剥がれにくさは未検証です。

## 平らな天井を支える薄壁型と3MF出力

新規作成では「リブ型（薄壁・平らな天井向け）」を選びます。従来の柱型は点でしか天井を支えず、モデル上に浮かせた下端も通常形状としてスライサーに認識されるため、連結リブサポートの周囲に自動サポートが追加される場合がありました。薄壁型は次の仕様です。

- 壁の間隔は2〜15 mm（初期値4 mm）、厚みは初期値0.8 mmで、水平な天井の下に平行な薄壁を配置します。外周からの余白は0.1〜2 mm（初期値0.5 mm）で指定し、穴の輪郭からは0.5 mm離します。輪郭の穴は埋めません。
- 「上面を薄皮でつなぐ」をオンにすると、リブの上端同士を水平な薄皮でつなぎます。新規作成ではオンです。保存済みデータに設定がない場合は従来のオフを維持します。「薄皮の層数」は1〜6層、初期値2層。厚さは層数×積層ピッチで、0.3 mm・2層なら0.6 mmです。上面の位置と本体とのすき間を保ち、薄皮は下向きに厚くします。
- 薄皮は両端のリブの間だけに配置し、外側への張り出しを作りません。元の下面の穴・外周のすき間を保ち、本体・別ボディとの干渉や、両側をリブで支えられない薄皮は確定しません。リブが1枚だけの面には薄皮を追加しません。窓抜きを併用しても薄皮は保護します。薄皮を含むサポートは本体と別ボディで、プレビュー・3MF・STL・保存・再編集に対応します。
- 薄皮の最初の層はリブ間のブリッジです。仕上がり・剥がしやすさ・たわみは材料と印刷設定にも左右されます。まず小さい形状で試してください。テストでは、間隔12 mm・積層ピッチ0.3 mmの2層／3層の薄皮がBambu Studioの印刷経路に含まれ、二重の自動サポートが出ないことを確認しています。実物の印刷試験は未実施です。

薄皮の検証は `tests/print-support-wall-roof.mjs`、`tests/print-support-wall-roof-browser.mjs`、`tests/print-support-wall-roof-slicer.mjs`。既存のサポート用合成モデルとスライサー検証用プロファイルを使います。

上面の「分割線」をオンにすると、薄皮を指定間隔（10〜60 mm）で区切ります。幅は0.4〜1.2 mm。リブと横つなぎは切らず、各区画を支えられない切れ目は見送ります。タブの作成・配置操作は削除しました。旧データに保存されたタブは既存形状と履歴の再計算用にのみ読み込みます。再編集して確定したサポートにはタブを付けません。

- モデルを土台にするときは薄壁の下端を接触させます。空中から印刷が始まらないよう、下側のすき間を設けません。印刷後は薄壁を折り取ります。
- ベッド上では「足同士をつなぐ」がオンの場合、薄壁の下に接続した広い足を作ります。
- 「一定の高さごとに薄壁を横につなぐ」をオンにすると、隣の薄壁同士を短い横板でつなぎます。新規作成ではオン、高さ間隔の初期値は20 mm（8〜60 mmで調整可）です。旧保存ファイルに設定がない場合は、再計算・再編集とも横つなぎなしを維持します。
- 横板は壁の長さ方向の2箇所に置き、短い壁では中央の1箇所に置きます。各壁の下端から高さ間隔ごとに配置し、積層ピッチ単位に切り上げます。厚みは2層分なので、積層ピッチ0.3 mmでは厚み0.6 mmです。天井との接点付近には入れません。
- 横板の中央より壁との接続部を細くし、取り外す際に切り離す位置を設けます。本体に入り込む位置・輪郭の穴・両側の壁に接続できない位置には置きません。大きな穴をまたいで空中に破片を作らないよう、横板全体と接続先をCAD上で確認します。画面には追加した箇所数を表示します。
- 「中央を窓抜きして節約」をオンにすると、薄壁の中央にひし形の窓を作ります。初期値はオフで、旧保存データも窓抜きなしを維持します。根元と上端は3 mm以上、外周と縦の骨は2 mm以上を残し、横つなぎの高さと接続位置にも帯を残します。穴の上端は山形で、斜面は水平から約56°以上です。壁厚と本体との上側のすき間は変えません。
- 窓は幅3〜8 mm、高さ8〜18 mmの範囲で自動配置します。窓の横方向2 mm以上・上下3 mm以上の周囲領域が元の薄壁内に収まらない位置、既存の穴・別のリブ・横つなぎに近い位置は抜きません。窓の数の上限は256個です。小さい形状では窓なしになる場合があり、追加できた数と窓抜き前後のサポートCAD体積の削減率を表示します。この率はスライサーの使用フィラメント削減率とは異なります。
- 窓抜きは保存・再編集・再計算・STL・3MF出力に対応します。検証用のコの字形では、サポートCAD体積が約22.3%減り、同一の本体を含むBambu Studioの使用フィラメント推定量は約32.6 gから約29.0 gへ約11%減りました（積層ピッチ0.3 mm、テスト用A1 mini / PLA設定）。追加の自動サポート経路はありませんでした。実機での強度・ベッド密着・取り外しやすさの同等性は未検証です。
- 積層ピッチの初期値は0.3 mm、上側のすき間も0.3 mmです。積層ピッチを変えると上側のすき間を同じ値に合わせます。上側のすき間は積層ピッチの1倍以上の整数倍で指定します。
- 水平な平面の下面専用です。斜めの下面には「柱型（従来）」を使ってください。計算量の上限は96枚で、超えた場合は途中の配置を出力せず間隔の変更を案内します。

薄壁のプレビューができたら「プレビューを3MF出力（本体＋薄壁）」を押し、Bambu Studioで**プロジェクトとして**開きます。本体・薄壁・必要な土台の相対位置、積層ピッチ、および対象範囲のサポートブロッカーを含みます。ブロッカーは印刷する形ではなく、スライサーの自動サポートを除外する領域です。自動サポート全体を無効にはしません。対象範囲外の自動サポート設定やプリンター・フィラメントの設定は上書きしません。G-codeは含みません。

3MFでは、本体・リブ・除外領域の各部品内で同一座標の頂点を共有し、面の境界が同じ頂点番号でつながるように出力します。旧出力では面ごとに頂点が分かれ、Bambu Studioに「非多様体エッジ」が表示される問題がありました。修正後は出力前に辺の接続数・面の向き・スライサー精度での閉鎖性を検査します。距離の許容値で近い頂点をまとめたり、別部品を結合したり、穴を埋めたりはしません。不正な形状が残る場合は部品名とともにエラーを表示し、保存を止めます。以前に出力済みの3MFは自動では変わらないため、元のFormaCADデータから再出力してください。

出力されるのは編集中のプレビューの時点の形です。履歴上で後続工程がある場合、その後の形状変更は含みません。「連結リブサポートを作成」で確定すると通常のFormaCADファイルへ保存でき、再編集時に3MFを再生成できます。大きなプレビュー用の出力データやブロッカーのメッシュは作業ファイルに保存しません。

通常のSTL出力にはサポートブロッカーの設定が含まれません。Bambu Studio以外や「形状のみ」として読み込んだ場合も除外設定が失われる可能性があります。二重生成を防ぐ場合は上記3MFの設定を保持して読み込んでください。未対応の面や遮られた配置がある場合は3MF出力を無効にします。薄壁の接触面・上側のすき間・天井のブリッジをスライス後に確認してください。

薄壁型の連結リブサポートが表示されているモデルで、右上の「STL出力」を押すと出力形式を案内します。「3MF出力画面へ」を選ぶと該当する連結リブサポートの編集画面を開き、プレビュー計算後に3MFボタンへ移動します。そこで出力し、Bambu Studioでプロジェクトとして開いてください。「STLを出力（形状のみ）」を選ぶと従来のSTLを出力します。キャンセルではモデルを変更しません。薄壁サポートが複数ある場合は対象工程を選べます。後続工程がある場合は、その加工を含まない工程時点の3MFになることを案内します。非表示・削除済みの薄壁サポートや、従来の柱型だけのモデルでは通常のSTL出力を続けます。

実装は[Bambu Studioの3MF入出力](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Format/bbs_3mf.cpp)と[サポートブロッカーの部品種別](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Model.cpp)に対応しています。

## 使い方

1. 印刷する向きとモデルの位置を決めます。ベッドはXY平面、高さは通常Z = 0 mmです。
2. ツールバーの「連結リブサポート」を押し、対象ボディを指定します。選択したボディがあれば引き継ぎます。
3. 「平面の下面を自動で探す」か「選んだ下面だけ（複数可）」を選びます。後者では「下面を選ぶ・追加する」を押して下面をクリックで追加・解除し、「選択を終了してプレビュー」を押します。モデルの下面を先に選択した場合は、左下の「この下面に連結リブサポート」から直接開始できます。
   「支え始める場所」の初期値は「ベッドとモデルの上面」です。コの字形のように下側にも板がある場合は、その板の上から支えます。「ベッドのみ」に切り替えると従来どおり、ベッドから直接届く場所だけに配置します。
4. 橙色のプレビューを見ながら寸法と本数を調整し、「連結リブサポートを作成」を押します。青色の半透明表示が対象本体です。
5. 履歴の「連結リブサポート」をクリックすると再編集できます。本体の前工程を変更するとサポートも再計算します。元に戻す・やり直しとFormaCADファイルへの保存に対応しています。

## 設定

| 設定 | 初期値 | 意味 |
| --- | --- | --- |
| 支柱の間隔の目安 | 25 mm | 下面の候補を探す間隔。輪郭内部の追加候補も使うため、すべての支柱が等間隔になるわけではありません。 |
| 支え始める場所 | ベッドとモデルの上面 | 各候補の直下にある平面の上面を探し、なければベッドを土台にします。 |
| 足の直径／厚み | 20 / 0.8 mm | ベッドに接する円形の足。 |
| 支柱の直径 | 4 mm | 足と先端の間の柱。根元には太さの移り変わりを付けます。 |
| 先端の直径 | 1.2 mm | 本体直下の細い接点。 |
| 上面との縦すき間 | 0.2 mm | 本体下面と先端とのZ方向の距離。傾斜面でも縦方向の値です。 |
| モデル上の接点の縦すき間 | 0.2 mm | モデルを土台にする場合の、土台上面と下側の細い接点とのZ方向の距離。ベッドから支える場合は使いません。 |
| 斜め補強の直径 | 2 mm | 近くの支柱同士をつなぐ45°の補強。高さが足りない場合は入りません。 |
| ベッド高さ | 0 mm | 足の底面のZ座標。 |
| 生成する本数の上限 | 16 本 | 最大36本。計算量を制限します。 |
| 足同士をつなぐ | オン | ベッド上の近い足から順に薄い帯でつなぎます。モデル上の細い接点は帯でつなぎません。 |
| 支柱間に斜め補強を入れる | オン | 高さと間隔に余裕がある支柱間に補強します。 |
| 本体・土台とまとめて移動する | オン | 本体とサポート、別ボディの土台があればその土台も別ボディのまま固定し、移動・回転・コピーで一緒に動かします。 |

曲面の下面・土台と、水平から60°を超える傾斜面には対応していません。本体や他ボディを通り抜ける支柱や補強は省きます。土台の穴・凹んだ輪郭はCAD上で判定し、穴の上に接点を浮かせて配置しません。自動配置は下面全体の造形可能性を保証するものではありません。本数の上限、見送った候補、干渉で省いた補強を画面に表示します。モデル上に作る場合は、上下両方のすき間をスライス後に確認してください。

以前の保存ファイルで作成方法が記録されていないサポートは、再計算・再編集とも「ベッドのみ」を引き継ぎます。モデル上からも支えたい場合は明示的に切り替えてください。

## 出力と印刷

この機能で作る形はスライサーのサポート属性ではなく、通常のモデル形状です。本体と必要なサポートを同じ配置のままSTLに含めて出力してください。スライサーが別部品をベッドへ落としたり、自動配置で相対位置を変えたりしないよう確認します。

柱型の従来の先端すき間0.2 mmは調整の出発点です。積層高さと合わせてスライスし、先端の上の空白層・本体下面の最初の層・スライサーが追加するサポートとの重なりをプレビューで確認してください。すき間が小さすぎると本体に固着し、大きすぎると下面を支えられません。薄壁型は上の専用設定を使用します。

足の直径を大きくしても、ベッドの状態や印刷条件による剥がれは起こり得ます。また足がプレート外にはみ出さないか、通常の印刷前チェックで確認してください。

固定を解除する場合は「位置合わせ・固定」の一覧から「連結リブサポート」の固定を解除できます。固定した部品を別々に自動配置する操作は防いでいます。印刷方向を変えたい場合は、サポート作成前の本体の向きを変えてサポートを再生成してください。作成後に全体を傾けると足がベッドに乗らなくなります。

### 薄皮の区画表示とタブの位置指定

「上面を薄皮でつなぐ」をオンにすると、プレビューの薄皮を区画ごとに色分けして番号を表示します。剥がすタブはピンク色と同じ区画番号で表示します。この色は設定中の案内で、印刷用の色指定ではありません。

「取り外しの補助」を開き「剥がし始めるタブを付ける」をオンにします。「タブを置く区画」または画面の番号で区画を選び、「付ける側」のA（青）／B（赤）で側を指定できます。長さ方向の位置も変える場合は「画面でタブ位置を選ぶ」を押して色付きの薄皮をクリックします。クリック位置に近い側と、その位置に沿ってタブを作ります。1区画につき1個です。位置指定中は確定・3MF出力を止め、指定を終えるか同じボタンで解除すると再開します。

指定位置の足場不足・穴や本体への干渉・高さ不足があれば理由を表示し、確定と3MF出力を無効にします。自動で別の側へ移しません。位置を変えるか「この区画を自動に戻す」で再配置できます。自動配置の区画は従来通り干渉する候補を見送ります。

指定した側と位置は保存・再編集・履歴の再計算で引き継ぎます。薄壁や分割の間隔など、区画が変わる設定を編集すると、通知して全区画を自動配置に戻します。外部で変更されたファイルなどで元の区画を見つけられない場合も確定せず、選び直しを求めます。薄皮の層数・縦すき間の変更では区画の参照を維持して位置を再検査します。

### 線幅に合わせた厚み・リブの向き・個別除外

「印刷の線幅」にスライサーで使う線幅を入力すると、薄壁の厚みを線幅で割った本数の目安を表示します。「線幅×線数で薄壁の厚みを決める」をオンにすると、指定した線数との積を厚みに反映します。線幅0.45 mm・2本なら厚み0.9 mmです。薄壁の厚みは従来通り0.4〜2 mmの範囲で、間隔より小さくしてください。薄皮とタブ上面の厚みは層数×積層ピッチです。線幅より薄い場合や線幅の整数倍ではない場合は注意を表示します。線数はスライサーの処理で変わるため目安です。3MFでは積層ピッチの設定を引き継ぎますが、線幅の印刷プロファイルは変更しません。使用するスライサー側の線幅を合わせてください。

「薄壁を伸ばす向き」で自動／横方向（X）／縦方向（Y）を選択できます。「向きを90°切り替える」は、プレビューの向きから直交する方向へ切り替えます。複数の下面がある場合、自動では面ごとに判断し、横・縦を指定すると全対象面でその方向を使います。

「不要なリブを除外する」を開いて「画面でリブを除外／復帰」を押すと、リブの面または番号のクリックで生成対象を切り替えられます。一覧のチェックでも操作できます。除外したリブは赤い半透明で表示し、同じ操作で戻せます。選択モード中は確定・3MF出力を止めるため、「リブの選択を終了」で終了してください。「除外をすべて解除」で一括復帰します。

除外により薄皮を支えるリブが2枚未満になる、両端のリブがなくなり片持ちになる、または残るリブの間隔が設定値を超える場合は、理由を表示して確定と3MF出力を止めます。リブを戻すか、薄皮をオフにしてください。全リブを除外した場合も確定できませんが、プレビューと一覧から復帰できます。これは配置上の検査で、実際の印刷強度を保証するものではありません。

3MFでは除外したリブの担当範囲を、重なる別の下面のものも含めて、自動サポート禁止領域から切り取ります。したがってスライサーがその範囲に追加サポートを生成する場合があります。残すリブの横つなぎ・足・窓抜きは残した配置に合わせて再生成します。

線幅・線数・厚みの連動・向き・除外指定は保存と再編集、履歴の再計算に対応します。向き・間隔・厚み・対象面など配置が変わる操作では、通知して除外指定と手動タブ位置をリセットします。古いファイルで配置に一致しない除外指定が見つかった場合は確定せず、解除して選び直す案内を出します。これらの設定がない旧ファイルは、厚みの連動オフ・向き自動・除外なしで従来の形状を維持します。

### 回転したモデルの3MF出力

スケッチから押し出したモデルを辺や軸の周りに90°回転すると、同じCAD頂点を複数の面から計算した座標の末尾に数値差が出る場合があります。STLの出力経路で行っていた共有CAD頂点の正規化を、連結リブサポートの3MFにも適用します。本体・土台・サポート・自動サポート禁止領域のすべてが対象です。

距離が近いだけの別頂点は結合しません。CADの辺に対応するポリゴンの端点で、同一のCAD頂点と確認できた箇所だけを揃え、CAD面積・体積との整合と3MFの接続を再検査します。元のCAD形状・寸法・履歴や表示用メッシュを修正する処理ではありません。回復できないメッシュは従来の出力検査で停止し、プレビューと再編集は維持します。

### サポートの失敗記録とプリセット

プレビューの計算・確定・3MF出力で例外が起きた場合、失敗時の元モデル、計算に使った履歴、入力欄の値、対象面、リブ除外、手動タブ位置、エラーとアプリのビルド番号を記録します。上部の「失敗時の記録」に他のCAD操作と合わせて直近最大3件を保存します。入力途中の不正な数値やユーザーによる保存キャンセルは、自動記録の対象ではありません。

サポートの画面に表示される「失敗時のモデルと設定を保存」または上部の記録一覧から、再現用の `.forma.json` をダウンロードできます。設定を後で変更しても、そのファイルは失敗した時点の内容です。元モデルと入力・エラーを一緒に調べられます。容量制限などでブラウザー内に自動保存できない場合も、その画面を閉じる前ならファイル保存できます。モデルやエラーを外部へ自動送信する機能ではありません。

記録一覧の「モデルとサポート設定を復元」を押すと元モデルと入力欄を復元します。復元だけでは失敗した計算・確定・出力を自動実行しません。数値を変更するか「この設定でプレビュー」で計算を再開できます。復元したモデルは「元に戻す」で戻せます。

ダウンロードした失敗記録の `.forma.json` を通常の「開く」で選ぶと、読み込み確認画面に「失敗時のサポート設定も復元する」が表示されます。チェックを外すとモデルだけ開きます。チェックした場合も、計算・確定・出力は明示操作まで始めません。記録の形式、対象ボディ、編集工程、計算に使った履歴とモデルの一致を検査し、不整合があれば理由を表示してモデルだけ読み込める形にします。通常の作業ファイルや他の操作の失敗記録には、この選択肢を表示しません。

「サポート設定プリセット」を開くと、現在の線幅・線数・積層ピッチ・薄壁の間隔・向き・薄皮・タブ・分割線・窓抜き・横つなぎや従来の柱型の寸法を、名前付きでこのブラウザーに保存できます。名前は1〜60文字、最大50件です。同名保存で更新し、一覧から呼び出し・削除できます。

プリセットを呼び出すと、現在の対象ボディ・選択面・ベッド高さを使ってプレビューを再計算します。モデルのID、選択した面、個別のリブ除外、手動タブ位置はプリセットに含めず、除外と手動タブ位置はリセットします。モデルへの確定は通常の作成・適用ボタンで行います。保存できない場合は名前と入力欄を維持して理由を表示します。プリセットはブラウザー・サイトごとの保存領域にあり、作業ファイルには含めません。

「プリセットを書き出す」で保存済み設定をまとめて `forma-support-presets.json` に出力できます。別のブラウザーや公開版では「プリセットを読み込む」で追加してください。同名は「(2)」などを付けて追加し、既存の設定を上書きしません。読み込みだけでは現在の入力欄やモデルを変更せず、「呼び出す」で適用します。最大1 MB・合計50件で、全件の形式と数値を検査してから保存します。不正なファイル、未対応バージョン、件数超過、保存領域のエラーでは、既存の設定を維持します。

### 高さに応じた補強と色分け

薄壁型で横つなぎをオンにすると、「高さ・壁厚に応じて横つなぎを増やす」を選べます。手動の高さ間隔を上限にし、隣り合うリブの高さが40／80／120 mmを超えるにつれて間隔を狭めます。壁厚も考慮し、目安は8 mm以上・指定間隔以下の範囲で、実際の高さは積層ピッチに合わせます。手動設定の数値は書き換えず、自動をオフにすると元の間隔に戻ります。初期状態は手動で、設定のない旧ファイル・旧プリセットも元の形状を保ちます。

実際に本体や穴に干渉せず作れた横つなぎから、各リブの補強のない高さを調べます。壁厚との比が30を超える箇所は黄、60を超える箇所は紫で表示し、リブ番号と理由を一覧で確認できます。これは幾何形状からの目安です。材料特性・積層方向の強度・ノズル接触・ベッドへの接着を計算する強度解析ではありません。干渉して省いた補強を、作成済みとして数えることはありません。形状上の注意だけで確定・出力を禁止することもありません。

### 取り外し方向の確認

プレビュー後に「取り外し方向を確認」を開き、X±・Y±・Z±から抜く方向を選んで「この方向を調べる」を押します。現在のサポート全体を、その向きへ変形させず直線移動する場合の最初の接触位置を検査します。移動の途中の薄い障害物も調べ、当たるボディを赤色、移動するサポートを橙色で表示します。本体名と接触までの距離を表示し、スライダーや「再生」で最初の接触まで、または本体から抜ける位置までの移動を確認できます。

これは表示メッシュを使った確認で、CAD形状を移動するコマンドではありません。土台の面を横へ滑る接触は障害と扱わず、土台へ入り込む方向は検出します。根元を切り離した想定で、たわみ、工具の空間、実物の接着、薄皮や横つなぎを切断して分割する取り外し方は評価しません。「直線では取り外せません」と表示されても、分割すれば外せる場合があります。曲面の結果にはメッシュの近似が含まれます。

確認中は確定と3MF出力を止めます。「元のプレビューに戻す」で通常の編集に戻り、モデル・履歴・STL・3MFの形状は変わりません。設定変更、キャンセル、閉じる操作でも移動表示と色分けを消します。合計20万三角形・200万組の候補を上限とし、検査を完了できない場合は「未確認」と表示します。未確認を合格扱いしません。

### フィラメント量の概算

「フィラメント量の概算」を開くと、サポートのCAD体積、フィラメントの長さと重量を表示します。フィラメント径と材料の密度を入力でき、窓抜きがオンの場合は同じ配置の窓抜き前後と削減量を比較できます。薄皮・タブ・足・横つなぎを含むサポート部分だけの体積を使い、本体や土台を加算しません。重複した形状は結合後の体積で数えます。

長さは体積÷フィラメント断面積、重量は体積×密度で、全充填のCAD体積から換算します。初期値は径1.75 mm・密度1.24 g/cm³です。材料の仕様に合わせて変更してください。インフィル、壁数、流量、パージなどによって実際の使用量は変わるため、最終的な使用量と時間はスライサーで確認してください。自動補強・径・密度は保存・再編集・プリセット・失敗記録の復元に対応し、確認用の移動距離やアニメーションは作業履歴に保存しません。

### 必要な下面を複数選択する

「配置する範囲」を「選んだ下面だけ（複数可）」にすると、同じ対象ボディ内の下面を最大32面選択できます。「下面を選ぶ・追加する」を押し、画面の下面をクリックして追加・解除してください。選択した面は緑色と「下面1」などの番号で表示します。画面を回転しながら選べます。選び終えたら「選択を終了してプレビュー」を押すと、選んだ面だけにサポートをまとめて作成します。

### 開口側の端へのリブ配置

「開口側の端までリブを配置」をオンにすると、最初と最後のリブを、指定した外周の余白の位置まで寄せます。残りのリブは指定間隔以下になるように均等配置します。従来の、端に半間隔分の張り出しが残る配置を減らし、上面の薄皮も両端のリブまで広げます。外周・穴とのすき間は維持し、隙間を埋めるためにモデルの寸法を変える処理ではありません。向きは「薄壁を伸ばす向き」で切り替えられます。

新規作成ではオンです。旧ファイル・旧プリセットで設定がない場合は従来の配置を保持するためオフになります。既存のサポートも再編集してオンにできます。配置を切り替えるとリブの参照と薄皮の区画が変わるため、通知してリブ除外と手動タブ位置を解除します。端のリブを除外して薄皮が片持ちになる場合は、従来通り確定と3MF出力を止めます。端寄せした形状の結合では各入力形状を独立したCADデータとして検査し、穴と薄皮の境界が一致する場合も閉じたメッシュを確認します。

### 底面の薄皮

「底面も薄皮でつなぐ」で、リブの根元を薄い板でまとめられます。「底面の薄皮の層数」は上面と独立した1〜6層で、厚みは層数×積層ピッチです。積層ピッチ0.3 mmなら1層で0.3 mm、2層で0.6 mmです。水平な土台ごとに配置し、下側のモデルの板の上から支える場合も、ベッド高さではなく実際に接する高さに作ります。穴と輪郭を保ち、窓抜きで底面薄皮を削らないように保護します。

底面薄皮は従来の足の代わりになるため、オンの間は「足の厚み」と「足同士をつなぐ」を変更できません。オフにすると元の足の設定に戻ります。土台との接触は維持し、空中に浮かせるすき間は作りません。根元をまとめて外すための形状ですが、接触面積も変わるため、剥がしやすさ・仕上がりは試し刷りで確認してください。厚みを置く高さが足りない場合やモデルに入り込む場合は理由を表示して中止します。設定のない旧ファイルは底面薄皮オフです。

端寄せ、底面薄皮、層数、間隔15 mmは、複数面の選択・保存・再編集・プリセット・失敗記録の復元・STL・3MFに対応します。材料量の概算には底面薄皮も含めます。15 mmは指定できる上限で、実際のリブ間隔は端への配置に合わせて狭くなることがあります。印刷のブリッジ性能を保証する値ではありません。

- `node tests/print-support-edge-ribs.mjs`: 両端位置、間隔、足と除外範囲、薄皮の端、穴を持つ形状の閉じた結合、複数面、保存と再計算、旧設定互換。
- `node tests/print-support-bottom-skin.mjs`: 実際の土台高さとベッド、独立した層数、モデル非重複、窓抜き保護、材料体積、15 mmの範囲、複数面と保存、STL・3MF。
- `node tests/print-support-edge-bottom-browser.mjs`: 端寄せ・底面薄皮・15 mmの画面操作、設定のガード、プリセット、面の維持、保存・再編集と3面の3MF。

## 底面の分割線と簡易プレビュー

新規作成では上面・底面の薄皮を両方オンにします。既存ファイルのオフ設定は維持します。底面は実際の土台の上面から積層ピッチ×層数の厚さで作り、空中に浮かせません。「底面の分割線」で底面の薄皮だけを区切れます。分割間隔10〜60 mm・幅0.4〜1.2 mmを上面とは別に指定します。リブ・横つなぎを残し、区切った薄皮がリブにつながらない切れ目は見送ります。リブとの重なりでは分割線が途切れます。窓抜きからも底面薄皮を保護します。

設定変更直後は表示メッシュから配置の目安を半透明で表示します。穴や障害物との厳密な接触、窓抜き、横つなぎ、分割線は精密計算後に更新されます。操作停止後450 msで精密計算を開始し、計算中に入力が続いた場合は最後の設定だけを次に計算します。入力ごとのCADエンジンの再起動を避けます。簡易表示は保存・確定・3MF出力・使用量換算には使いません。精密計算と面の接続検査が済むまで確定・出力できず、古い設定の計算結果も採用しません。複雑なメッシュには簡易表示を省き精密計算だけを行います。

## 外周からの余白

薄壁型の「外周からの余白」で、モデルの外周からリブ・上面薄皮・底面薄皮を離す距離を0.1〜2 mmで指定できます。初期値は0.5 mmです。「開口側の端までリブを配置」をオンにすると最初と最後のリブの外側も指定余白にそろいます。オフではリブ間隔に応じた端の余りも残ります。穴の周囲の余白は従来の0.5 mmで固定し、上面との縦すき間は変更しません。余白を小さくするとモデルの縁の下まで支えを近づけられますが、実際の端の仕上がりと取り外しやすさは試し刷りで確認してください。

設定は簡易表示と精密プレビュー、複数面、3MF・STL、保存・再編集・履歴再計算、プリセット、失敗時の記録に反映されます。値がない旧ファイル・旧プリセットは0.5 mmを引き継ぎます。余白を変更するとリブの参照位置が変わるため、リブ除外を解除して通知します。0.1 mm未満・2 mm超などの不正な入力では確定・出力を止めます。

検証：`tests/print-support-edge-margin.mjs`（外周寸法・穴の余白・両方向・旧形状・履歴再計算・簡易表示・閉じたメッシュ）、`tests/print-support-edge-margin-browser.mjs`（数値変更・範囲ガード・プリセット・再編集・除外リセット）。

## 本体側を線状にする接触層

Bambu Studioのサポート接触層（線幅と線の隙間・本体との縦距離）を参考に、本体に近い薄皮1層へ平行な溝を入れる機能です。新規作成で上下の薄皮と一緒にオンにします。旧ファイルや旧プリセットに指定がなければオフを維持し、既存サポートも再編集から有効にできます。

「接触線の幅」は0.4〜1.5 mm、初期値0.6 mm。「接触層の線の隙間」は0.1〜1.5 mm、初期値0.5 mm。接触線幅は画面に指定した印刷線幅以上にしてください。CAD形状としてスライスするため、Bambu Studioのサポート専用の線幅と印刷経路をそのまま再現する機能ではありません。0.4 mmのCAD壁は検証プロファイルで一部省略されたため、初期値0.6 mmを採用しています。

上面は本体との縦すき間を維持し、最上側の1層だけを線状にします。底面は、下側の本体に乗る場所で最下側1層だけを線状にし、広い面による接触を減らします。底面に空中の隙間は設けません。ベッドに直接乗る底面は広い形状を保持します。内側の薄皮、リブ、横つなぎは接触層の範囲外を残します。薄皮2層なら本体側1層が線状で、その内側1層が保持用の板になります。

分割線・窓抜き・複数面・方向変更・外周余白と併用できます。溝で新しい独立した破片が生じる場合は確定せず、薄皮を2層以上にするか線の隙間を狭くする案内を出します。溝の総数は1024本まで。保存・再編集・履歴再計算・プリセット・失敗記録・STL・3MFに対応し、使用量概算にも溝を反映します。簡易表示では配置の目安を示し、精密表示で実際の線と隙間に更新します。

検証では積層ピッチ0.3 mm・接触線幅0.6 mm・隙間0.5 mmで、Bambu Studioが上下の接触線を印刷し、線間の空隙も残すG-codeになることを確認しています。実機での剥がしやすさと印刷中の密着維持は未検証です。材料・スライサーの線幅や流量によって調整が必要です。

参考：[Bambu StudioのTreeSupportCommon](https://github.com/bambulab/BambuStudio/blob/master/src/libslic3r/Support/TreeSupportCommon.hpp)。検証：`tests/print-support-contact-lines.mjs`、`tests/print-support-contact-lines-browser.mjs`、`tests/print-support-contact-lines-slicer.mjs`、`tests/print-support-contact-lines-gcode.mjs`。

## 上下別の接触層・比較試験片・強調表示

接触層をオンにすると「上面を線状にする」「底面を線状にする」を別々に選べます。各側の線幅（0.4〜1.5 mm）と線の隙間（0.1〜1.5 mm）を独立して指定できます。側をオフにしたり薄皮をオフにしたりしても数値は保存し、オンに戻すと再利用します。従来の共通設定しかないファイル・プリセットは、その線幅・隙間を上下両方へ引き継ぎます。ベッド上の底面は従来どおり広い形状を保持します。

「接触層の確認・試験片」を開き、「接触層を色分けして強調」で本体側1層を確認できます。上面はピンク、底面は青で、周囲を薄くし、内部の接触層も透視表示します。「上面1を拡大」「底面1を拡大」などで選んだ層の側から少し斜めに拡大し、「すべて表示・元の視点に戻す」で元のカメラと表示へ戻します。数値変更・キャンセル・終了時にも一時表示と拡大視点を解除します。強調表示は形状・履歴・出力データに保存しません。

「比較試験片3種類を3MF出力」は小さなコの字3個を1つの3MFへまとめます。現在の線幅、上下のオン・オフ、積層ピッチ、薄皮の層数、上面の縦すき間を使い、上下の薄皮を設けた標準形状・リブ間隔8 mmで比較します。窓抜き・分割線・手動タブ・リブ除外は試験片に持ち込みません。線の隙間は現在値の前後0.2 mmを基本に小・中・大の3種類です。上限・下限付近は範囲内で3段階にずらします（0.1なら0.1／0.3／0.5、1.5なら1.1／1.3／1.5）。

A／B／Cは本体前側の1／2／3本の溝で区別します。各部品名に上下の隙間を含みます。配置全体は104×28 mmで、高さは積層ピッチと薄皮の設定から決めます。元モデルを変更・追加せず、履歴や保存ファイルにも試験片を挿入しません。生成中のキャンセルやモデルの変更後にはダウンロードしません。Bambu Studioでプロジェクトとして開き、実際に使うフィラメントとプロファイルで比較してください。実機での剥がしやすさや印刷時間は未検証です。

検証：`tests/print-support-contact-tools.mjs`（上下別形状、旧設定、カメラ・材質の復帰、試験片、3MF閉鎖性）、`tests/print-support-contact-tools-browser.mjs`（画面操作・試験片出力・キャンセル・保存）、`tests/print-support-contact-tools-slicer.mjs`と`tests/print-support-contact-trials-gcode.mjs`（3種類の試験片が追加サポートなしでスライスされ、上下の線と空隙が印刷経路に残ること）。
