# 疑似サポート

モデルの下面からベッドへ、広い円形の足・太い支柱・細い先端を持つ取り外し用のサポートを作る機能です。足の接続と支柱間の斜め補強を追加でき、背の高い支柱を支えます。造形物とは別のCADボディとして保存します。実機での剥がれにくさは未検証です。

## 使い方

1. 印刷する向きとモデルの位置を決めます。ベッドはXY平面、高さは通常Z = 0 mmです。
2. ツールバーの「疑似サポート」を押し、対象ボディを指定します。選択したボディがあれば引き継ぎます。
3. 「平面の下面を自動で探す」か「選んだ下面だけ」を選びます。後者では「下面を選ぶ」を押して下向きの平面をクリックします。モデルの下面を先に選択した場合は、左下の「この下面に疑似サポート」から直接開始できます。
4. 橙色のプレビューを見ながら寸法と本数を調整し、「疑似サポートを作成」を押します。青色の半透明表示が対象本体です。
5. 履歴の「疑似サポート」をクリックすると再編集できます。本体の前工程を変更するとサポートも再計算します。元に戻す・やり直しとFormaCADファイルへの保存に対応しています。

## 設定

| 設定 | 初期値 | 意味 |
| --- | --- | --- |
| 支柱の間隔の目安 | 25 mm | 下面の候補を探す間隔。輪郭内部の追加候補も使うため、すべての支柱が等間隔になるわけではありません。 |
| 足の直径／厚み | 20 / 0.8 mm | ベッドに接する円形の足。 |
| 支柱の直径 | 4 mm | 足と先端の間の柱。根元には太さの移り変わりを付けます。 |
| 先端の直径 | 1.2 mm | 本体直下の細い接点。 |
| 上面との縦すき間 | 0.2 mm | 本体下面と先端とのZ方向の距離。傾斜面でも縦方向の値です。 |
| 斜め補強の直径 | 2 mm | 近くの支柱同士をつなぐ45°の補強。高さが足りない場合は入りません。 |
| ベッド高さ | 0 mm | 足の底面のZ座標。 |
| 生成する本数の上限 | 16 本 | 最大36本。計算量を制限します。 |
| 足同士をつなぐ | オン | 近い足から順に薄い帯でつなぎます。 |
| 支柱間に斜め補強を入れる | オン | 高さと間隔に余裕がある支柱間に補強します。 |
| 本体とまとめて移動する | オン | 本体とサポートを別ボディのまま固定し、移動・回転・コピーで一緒に動かします。 |

曲面の下面と、水平から60°を超える傾斜面には対応していません。本体や他ボディを通り抜ける支柱や補強は省きます。自動配置は下面全体の造形可能性を保証するものではありません。本数の上限、見送った候補、干渉で省いた補強を画面に表示します。

## 出力と印刷

この機能で作る形はスライサーのサポート属性ではなく、通常のモデル形状です。本体と必要なサポートを同じ配置のままSTLに含めて出力してください。スライサーが別部品をベッドへ落としたり、自動配置で相対位置を変えたりしないよう確認します。

先端のすき間0.2 mmは調整の出発点です。積層高さと合わせてスライスし、先端の上の空白層・本体下面の最初の層・スライサーが追加するサポートとの重なりをプレビューで確認してください。すき間が小さすぎると本体に固着し、大きすぎると下面を支えられません。

足の直径を大きくしても、ベッドの状態や印刷条件による剥がれは起こり得ます。また足がプレート外にはみ出さないか、通常の印刷前チェックで確認してください。

固定を解除する場合は「位置合わせ・固定」の一覧から「疑似サポート」の固定を解除できます。固定した部品を別々に自動配置する操作は防いでいます。印刷方向を変えたい場合は、サポート作成前の本体の向きを変えてサポートを再生成してください。作成後に全体を傾けると足がベッドに乗らなくなります。

## 検証

- `node tests/print-support.mjs`: CADの正常性、平面・傾斜面での接点距離、干渉回避、穴のある下面、足と補強、STLの閉鎖性、本体保持、連動移動・コピー・解除、保存と再計算。
- `node tests/print-support-browser.mjs`: プレビュー、パラメーター変更、下面の選択、確定・キャンセル、保存・再編集、元に戻す・やり直し。

実際のプリンターでの印刷・取り外しは未検証です。
