# 選択面から90°の作図面

ソリッドの平面を1つ選び、左下の「この面から90°の面でスケッチ」を押す。プレビューを見ながら位置・向きを決め、「この面でスケッチ」または矢印内の「＋決定」で作図を始める。

- 選択面の中心を通り、その面と直交する面を作る。中心は選択面のローカル輪郭の外接矩形の中心とする。
- 「面の横方向を軸に90°」「面の縦方向を軸に90°」を切り替えられる。「反対側から作図する」は面の位置を保って作図する側を反転する。
- 「面の中心からの移動」で新しい作図面の法線方向に平行移動する。数値は±10000 mmまで。矢印ドラッグでも調整でき、グリッド吸着ONでは表示中のグリッド間隔を使う。基準は面の中心からの距離。Shiftで吸着を解除して微調整する。「中心に戻す」は0 mm。
- 作図面は紫でプレビューし、設定パネルはモデル領域の外側に配置する。面が真横にしか見えない視点では少し斜めにする。キャンセルでこの視点変更も戻す。
- ドラッグ中のEscは移動前の位置に戻す。通常のEsc／キャンセルはプレビューを終了する。空欄・範囲外の数値では確定できない。
- プレビューと作図開始だけではソリッドや履歴を変更しない。実際に描いたスケッチが作図面のフレームと位置を保持し、保存・再読み込み・押し出しでも同じ平面を使う。元ソリッドのCAD面参照は引き継がない。
- 対象は1つの平面。曲面と複数面の選択ではボタンを出さない。元モデル・選択・コマンドが変わった場合は古いプレビューを閉じる。

検証：`tests/perpendicular-sketch-plane.test.js`でXY・XZ・YZ・傾斜面の直交関係、面中心、正負の移動、反対側、入力検証、ゼロを含む吸着を検査する。`tests/perpendicular-sketch-browser.mjs`は面選択から数値入力・ドラッグ・キャンセル・作図・保存・Undo/Redo・押し出しまで実行する。`tests/perpendicular-sketch-native.mjs`はその出力の位置、寸法、体積、元ボディの保持、閉じたSTLメッシュをCADエンジンで確認する。
