# 選択面を傾けた紫グリッド

ソリッドの平面を1つ選び、左下の「角度を変えた紫グリッドでスケッチ」を押す。紫のプレビューで角度と位置を決め、「この面でスケッチ」または矢印内の「＋決定」で作図を始める。

- 初期角度は90°、回転軸は「面の縦方向」。「回転軸」は選択面の横方向・縦方向から選ぶ。角度は−180〜180°の数値入力、スライダー、0°・45°・90°ボタンで調整する。
- 初期位置は選択面の中心を通る。中心は選択面のローカル輪郭の外接矩形の中心とする。
- 「頂点・辺の中点で位置合わせ」を押して、画面のソリッドの頂点または直線の辺の中点をクリックすると、その点を通る面に配置する。候補は緑の点と名前で表示する。隠れた奥の点や曲線を分割しただけの点は採用しない。
- 位置合わせ後は、その点を基準に角度を変える。「選択した頂点／辺の中点からの移動」は新しい作図面の法線方向の距離で、0 mmなら点を通る。「面の中心に戻す」は点の指定と移動を解除する。
- 矢印ドラッグでも平行移動できる。グリッド吸着ONでは表示中のグリッド間隔を使う。Shiftで吸着を解除して微調整する。距離は±10000 mmまで。
- 「反対側から作図する」は面の位置を保って見る側を反転する。
- 基準平面のXY・XZ・YZは変更しない。角度を変えた面は紫の作業グリッドとして扱い、構築平面を履歴に追加しない。0°で基準平面と重なる場合も紫グリッドで作図する。
- この紫グリッドで作図を始めると、同じ面で自動的に断面表示する。視点に近い側を隠して奥側を表示し、視点を反対側へ回すと表示側も追従する。断面の設定パネルは開かず、下部の「作図断面」で解除できる。
- 自動断面は表示だけの変更で、ソリッドの分離・切り取りや工程追加は行わない。通常の「スケッチを終了」で以前の断面設定へ戻し、以前の断面がなければ全体表示に戻す。Escの全操作終了でも全体表示へ戻る。
- パネルはモデル領域の外側に配置する。面が真横にしか見えない視点では少し斜めにし、キャンセルで視点も戻す。
- Escは、ドラッグ中なら移動前に戻す。点を選択中なら点選択を終了する。それ以外はプレビューを閉じる。空欄・範囲外の数値では確定できない。
- プレビューと作図開始だけでは元ソリッドや履歴を変更しない。実際に描いたスケッチがフレームと位置を保持し、保存・再読み込み・押し出しでも同じ平面を使う。元ソリッドのCAD面参照は引き継がない。
- 対象は1つの平面。曲面と複数面の選択ではボタンを出さない。元モデル・選択・コマンドが変わった場合は古いプレビューを閉じる。

検証：

- tests/perpendicular-sketch-plane.test.js：XY・XZ・YZ・傾斜面、任意角度、中心・指定点を通る関係、移動・反転・入力検証・吸着。
- tests/sketch-plane-reference-pick.test.js：頂点と中点、変換後の座標、遮蔽・非表示・範囲外の除外。
- tests/perpendicular-sketch-browser.mjs：従来の90°操作、ドラッグ・取消・保存・Undo/Redo・押し出し。
- tests/angled-sketch-grid-browser.mjs：任意角度、頂点・中点指定、点を基準に回転、基準平面XZを保持した紫グリッド作図、保存・再読込・実際の押し出し。
- tests/perpendicular-sketch-native.mjs と tests/angled-sketch-grid-native.mjs：実画面で生成した形状の寸法・体積、元ボディの保持、閉じたSTLメッシュをCADエンジンで確認。

- tests/sketch-section-side.test.js と tests/sketch-auto-section-browser.mjs：手前側の非表示、視点追従、紫グリッドでの作図、手動解除、終了時の復元、既存の手動断面表示との併用。
