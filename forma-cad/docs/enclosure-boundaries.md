# 囲み形成の円弧境界

円弧と短い直線が接続した押し出し形状では、CADカーネルの3Dオフセットが形状検査を通っても、面の境界と表示用三角形が一致しない場合があります。その囲みに面押し出しを行うと、表示形状の完全性検査で失敗していました。

## 作成時の検査と代替処理

通常の囲み形成の結果を、CADの有効性・体積・内側との非重複に加えて、`solidMeshComplete` で検査します。不完全な結果を確定しません。

通常経路が失敗した場合、穴のない一定断面の直線押し出し形状に限り、元のCAD端面から囲みを組み立てます。対向端面の法線・面積・距離と体積を調べ、再押し出しと元ソリッドの双方向の差分がゼロであることも検査します。断面をポリゴンに近似したり、円弧を推測したりする処理ではありません。

断面の2Dオフセットを押し出し、指定されたすき間と厚さを確保します。角丸の場合は端部にも丸みを付けます。開口面は、元ソリッドを削らない支持平面であることを確認してから、その面の位置で外側を切りそろえます。曲面の開口や凹形状の内部を横切る開口はこの代替経路では扱いません。従来の通常経路が利用できる場合は、その結果を使います。BOX・ヒンジの処理は変更しません。

## 保存済みの囲み

後続の加工で履歴からCADボディを取得するとき、モデルに沿う囲みの保存済みBREPが不完全なら、残っている元ボディと囲みの設定からその工程だけを再生成します。正常なBREPはそのまま使います。復旧に必要な履歴がない場合は、元のBREPを維持します。

元の入力ソリッドやプロジェクト履歴を書き換えません。復旧結果は元BREP・設定・元ボディをキーにキャッシュします。修復した囲みをファイルにも保持したい場合は、履歴の「囲み形成」を開いて確定し、保存してください。

## 検証

- `node tests/enclose-arc-boundaries.mjs`：円弧と短い直線を含む断面、開口の有無、角丸、すき間、回転、分割、保存済み不完全BREPの復旧、後続の押し出しプレビュー・確定、STLの閉鎖性、元形状の保持。
- `node tests/enclose-arc-boundaries-browser.mjs`：上のテストが生成する合成モデルを、独立した一時サーバーとブラウザーで確認。プレビュー、確定、取消、Undo/Redo、保存・読み直し、角丸とすき間の再編集。
- 既存の囲み形成・角丸・複数開口・分割・囲みへの押し出し結合の回帰テスト。

面の欠落を許容したり、検査の誤差を拡大したりする修正ではありません。
