# 回転切り取りの同一高さの境界

回転する円柱と対象ボディが同じ高さでも、面の座標に微小な差があると、厳密なブール差分はその差を薄い実体として残します。例えば高さ10 mmの板に対して円柱全体が−0.0000005 mmずれている場合、以前の処理では上面に薄皮が残ります。

`cutRevolvedSolid` は、境界ボックスが重なる平面同士の平行性と面間距離を確認します。ツール共通の接触許容差 `MODEL_PRECISION.contact`（0.000001 mm）以内で一致する境界がある場合に限り、その許容差でネイティブの切り取りを実行します。それ以外は厳密な差分です。カッターの拡大・オフセットや、角度・高さの変更はしません。ボディの回転形成とスケッチ断面の回転に共通で適用します。

入力のCAD形状と面のキャッシュを変更しないよう、独立したコピーを使います。結果は無条件に面や辺を統合せず、CADの妥当性・実体の存在・体積の上限・全ての面のメッシュ生成を検査します。失敗時には元のボディを維持します。全体を消す切り取りと、重なりのない切り取りは理由を示して中止します。

接触許容差を超える意図的な底厚は保持します。既に保存された薄皮付きの加工結果は、ファイルを開くだけでは書き換えません。修正後の版で回転切り取りをやり直すか、その工程以降を再計算してください。

## 検証

- `tests/revolved-cut.mjs`: 同一高さの上下の微小ずれで旧動作の薄皮を再現。片側・逆方向・対称、ボディ・断面の回転、斜めに剛体変換した形状、意図的な底厚0.0001 mm／0.2 mm、入力保持、履歴再計算、精密STLを確認。
- `tests/revolved-cut-browser.mjs`: 画面で同じ円柱を90°回転して別の板から切り取り、プレビュー・確定・保存読込・Undo/Redo・キャンセル・STL出力を確認。表示メッシュへの貫通レイで、穴を塞ぐ三角形がないことも確認。
