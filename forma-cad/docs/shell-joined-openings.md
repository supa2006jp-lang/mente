# 結合後の分割上面を開口にするシェル

複数回の結合で同じ平面に残った面の継ぎ目が、オフセット計算の失敗原因になる場合があります。通常のシェルと既存の復旧処理が失敗した場合に限り、同一平面・同一曲面の継ぎ目を整理した形状で再計算します。

元の形状は安全モードで保持します。整理後の形状の妥当性、体積・表面積・外接寸法の一致、面または辺の削減を確認します。再選択した開口の合計面積も確認し、未選択の面まで開口が広がる場合は中止して、同じ平面の面をすべて選択するよう案内します。指定壁厚を小さくする処理は行いません。

成功結果には既存の形状・体積検査を適用し、使用した一時形状と面を解放します。元の履歴や寸法は変更しません。

## 検証

```powershell
npm test
npm run build
node tests/shell-joined-openings.mjs
node tests/shell-joined-openings-browser.mjs
```

ネイティブ試験は上面が3分割された旧形式の結合を生成し、0.4・1・2 mmで開口、壁厚、底厚、単一ソリッド、外形保持、閉じたSTLを検査します。新しい結合後の自動整理に依存しないため、保存済みの古い形状への復旧処理も検査できます。一部だけの開口選択と過大な壁厚の拒否も確認します。ブラウザー試験はこの生成データを使い、実際の面選択からプレビュー・確定・STL出力・Undo/Redoまで確認します。任意の試験URLは `FORMA_TEST_URL` で指定できます。

既存の箱、短い円弧と平面の接合、円形ロフト、回転形状、SVG装飾付き形状のシェル試験も実行しました。添付された個別モデルも別途検証済みですが、ユーザーのモデルとその画像は公開ファイルに含めません。
