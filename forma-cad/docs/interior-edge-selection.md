# 入れ物の内側の辺をまとめて選択

1. 上面が開いた入れ物のボディ、またはその面・辺をクリックします。複数ボディはCtrl＋クリックで選べます。
2. 左下の選択情報の「内側の辺をまとめて選択」を押します。
3. 選ばれた辺が橙色になります。「この辺をフィレット」または「面取り」で加工できます。Ctrl＋クリックで個別に選択を解除・追加できます。

対象は、上方向（ワールド座標の＋Z）に開口があり、底と周囲の壁を持つ空間の、角のあるCAD辺です。外周・開口のふち・滑らかな面の継ぎ目は含めません。四角い箱では通常、底の4辺と縦の4辺、円筒では内底の円周が対象です。区画が複数あれば、それぞれの内側を選択します。内側の小さな張り出しの下も、同じ空間に開口があれば対象です。

外部へ側面が開いた切り欠き、閉じた空洞、底のない貫通穴は対象外です。上面とは現在のカメラ方向ではなく＋Zを指します。

検査はCADの辺と隣接面を使い、精密メッシュの水平断面が閉じた内側空間を作るか、開口と底があるかを確認します。不完全な断面は推測して選びません。曲線の表示点列とCADへの加工参照は分離し、円周が多数の直線としてフィレットに渡らないようにしています。

この操作は選択だけを変更し、形状や履歴を変更しません。対象がない場合は元の選択を保持します。検査中に別の選択へ切り替えたり、モデルを変更した場合は古い結果を破棄します。検査中のボタンまたはEscで中止できます。
