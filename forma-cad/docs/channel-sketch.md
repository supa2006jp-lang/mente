# コの字の線分作図

スケッチのツールバーで「コの字」を選び、外形の対角となる2点をクリックします。3本の線分がつながった、片側の開いた図形を作成します。厚みや面は付きません。

作図中の「コの字の開く向き」で左・右・上・下を選べます。作業画面で右クリックすると「左→上→右→下→左」の順に切り替わり、プレビューも更新します。始点を置く前も変更でき、右クリックでは作図を終了・確定しません。右ボタンを押したままドラッグした場合は切り替えません。幅・高さは通常の長方形と同じ画面上の寸法欄で指定でき、Tabで入力欄を切り替え、Enterで確定します。確定後は続けて次のコの字を描けます。Escで作図を終了し、確定済みの線は残ります。

保存データは通常の開いたポリライン（4頂点・3辺）です。線分の選択・削除、つながる線の移動やミラー、オフセットを利用できます。単独では閉じた領域を作りません。端を結ぶ線を追加するか、オフセットの「端をつないで閉じる」を使うと押し出せる輪郭になります。

## 作成後の再編集

左側のスケッチ一覧の「コの字を再編集」を押すと、右側の幅・高さ・開く向きを変更できます。同じスケッチに複数ある場合は、隣の選択欄で対象のコの字を選びます。スケッチの各図形を選択した場合も同じ設定を表示します。再編集中も、作業画面の右クリックで開口方向を切り替えられます。中心位置と作図面を固定して変更し、「変更を適用」または「スケッチを終了」で確定します。確定前は元のデータを保持し、キャンセル・Escで変更を取り消せます。確定した変更は元に戻す・やり直すに対応します。

以前の保存データや、移動・回転・ミラーしたコの字も、実際の4頂点から寸法と開口方向を読み取ります。線を個別に編集してコの字でなくなった場合は、通常の線として扱います。閉じた図形や文字の輪郭は再編集の対象にしません。後続のパイプなどは再計算し、輪郭の接続が壊れるなど再計算に失敗した場合は元のモデルを保持します。

## 開口方向の矢印

作図プレビューと再編集中は、開いている側に紫色の矢印と「開口 ↻」を表示します。矢印または「開口 ↻」をクリックすると「左→上→右→下→左」の順で90°ずつ切り替えます。Tabで矢印にフォーカスしてEnter・Spaceでも切り替えられます。右クリックや選択欄による操作も引き続き利用できます。矢印を押しただけでスケッチを確定したり、線を追加したりすることはありません。ドラッグでは向きを変更しません。

矢印はビューキューブをドラッグして斜めから見た場合も現在の向きに追従します。作図を確定・中止した場合や、寸法が不正な場合は矢印を消します。

## 画面上で寸法をドラッグ調整

「コの字を再編集」で、幅の両側に青い↔、高さの両側に青い↕のハンドルを表示します。ドラッグすると中心を固定したまま、その方向の寸法だけを変更します。斜めからの表示、回転したコの字、XY・XZ・YZ・任意平面に対応します。開口矢印はハンドルより外側に配置します。

グリッド吸着がオンの場合は表示中のグリッド間隔に吸着します。ハンドルの移動線上にある近くのスケッチの頂点・点や、ソリッドの頂点にも吸着し、その間はハンドルと距離表示を緑色にします。異なる高さの頂点や、移動線から外れていて一致できない頂点には吸着しません。Shiftを押しながらドラッグすると1/10の速さで微調整でき、吸着を一時解除します。吸着なしの寸法は小数4桁までに整理します。

ドラッグを離すとプレビューに反映し、「変更を適用」または「スケッチを終了」で確定します。ドラッグ中のEsc・ポインターの中断・ウィンドウのフォーカス喪失ではそのドラッグだけを取り消します。ドラッグしていない状態のEsc・キャンセルでは再編集を終了し、元のデータを保持します。

操作の検証：`node tests/channel-resize.mjs`（平面・回転・寸法・中心固定・グリッド間隔・頂点吸着・別平面の除外）、`node tests/channel-resize-browser.mjs`（4方向のハンドル・吸着表示・微調整・取消・矢印クリックとキー操作・確定・保存・元に戻す）。

検証：`node tests/channel-sketch.mjs`（線の接続・開口方向・寸法・平面と回転・保存・通常の線編集・オフセット）、`node tests/channel-sketch-browser.mjs`（ツールバー・4方向・幅と高さ・連続作図・取消・元に戻す／やり直す・保存と再読み込み）。

再編集の検証：`node tests/channel-edit.mjs`（既存データ・平面と回転・逆向きの頂点順・移動／ミラー・形状からの寸法復元・矢印）、`node tests/channel-edit-native.mjs`（後続パイプの再計算・形状と体積・接続が壊れる変更の拒否）、`node tests/channel-edit-browser.mjs`（寸法と方向の再編集・プレビュー・開口矢印・斜め視点・保存と再読み込み・取消・元に戻す／やり直す・後続工程の失敗時の保護）。
