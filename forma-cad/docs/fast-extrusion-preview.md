# 押し出しプレビューの応答改善

通常の押し出し・切り取りでは、ブラウザー側で押し出す範囲の簡易形状を先に表示し、その後に加工済みの正確なCAD形状へ置き換える。水色は押し出す範囲、赤は切り取る範囲を示す。簡易表示中の形状は確定結果ではなく、CAD計算が成功するまで確定できない。

直線的な押し出しは輪郭のメッシュをキャッシュし、距離だけ変えた場合は変換行列で更新する。負方向、対称、任意平面、穴、薄い壁にも対応する。テーパーは現在の距離で簡易形状を作成する。ソリッドへの接触やバリア・輪郭による切り分けなどは、既存の専用プレビューを維持する。

CAD用エンジンはユーザー操作後に準備し、寸法を変えても実行中のエンジンを破棄しない。古い未実行の要求を取り消して最新の入力だけを残す。実行済みの古い結果はモデル・入力・表示リビジョンの照合で無視する。ドラッグ中は簡易表示を追従させ、離した後にCAD計算を開始する。ツールを終了すると進行中の専用計算を取り消す。

新規の押し出しプレビュー要求では元履歴の描画専用データを転送しない。確定と同じ処理が出力した検証済みメッシュをそのまま使い、再構築と再メッシュを省く。後続履歴を伴う再編集では全体の再計算・描画データを維持する。通常のテーパーも、専用ツールの計算を挟まず同じCAD確定処理へ進む。

検証：`tests/fast-extrusion-preview.mjs` と `tests/fast-extrusion-preview-browser.mjs`。簡易表示の形状、輪郭メッシュの再利用、CAD計算を停止させた状態での先行表示、連続入力の集約、古い結果の無視、ドラッグ中のCAD要求抑制、CAD結果による確定を確認する。形状一致・再編集は `tests/exact-extrusion-preview.mjs` と既存のブラウザーテストでも確認する。表示時間は実行環境と形状に依存する。
