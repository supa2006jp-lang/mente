# 三面図の用紙と自動配置

新規図面の初期値はA4横向きです。最初に三面図を生成した際、正面図・平面図・右側面図・俯瞰図を共通縮尺で大きく配置します。保存済み図面の用紙・向き・配置は優先し、A3縦などの既存設定もそのまま復元します。

「図面設定」で設定欄を開閉できます。1366×768の画面では初めから用紙を大きく表示し、通常表示でも最大化しても、上部の「PDFをプレビュー」「PDF保存」「SVG保存」を使えます。

ボディを選択していないときは「表示中の全ボディ」で編集できます。「選択したボディ」へ切り替えても、対象が同じなら寸法・穴位置表・配置はそのままです。対象が異なる場合は穴の参照先を照合し、対応を確定できない寸法や穴を「要確認」として残します。対象の切り替えは「元に戻す」「やり直す」に対応します。

「選択した面を正面に」や「標準の向きに戻す」で、元と同じ方向から見る図へ寸法・寸法点・中心表示・矢印付き注記を引き継ぎます。投影方向の入れ替えに合わせて水平・垂直寸法の向きが変わる場合も、元の実測値を保ちます。切断面が同じ断面図、詳細図の倍率と寸法位置、穴番号、PDFのページ割り当ても引き継ぎます。俯瞰図の寸法は同じ2頂点が見える場合に引き継ぎます。

新しい向きで移せる位置を特定できない項目は「参照先を要確認」に残ります。項目を選び、図面上で参照先や位置を選び直せます。未配置の項目はPDFの出力前チェックにも表示されます。正面変更と再指定は、図面の「元に戻す」「やり直す」に対応します。

用紙設定の「大きく自動配置」を押すと、各図の上下・左右の位置関係を自由に組み替え、用紙に収まる共通縮尺を探索します。図そのものは回転せず、断面図・詳細図の倍率を保持します。縮尺は通常の選択肢に限らず連続値を使用し、「自動」の選択肢として表示します。自動サイズの用紙を選んでいた場合はA4へ切り替えて配置します。

図のラベル、寸法、中心マーク・中心線、断面の切断線、詳細図のマーク、コメント、図枠・表題欄の範囲を考慮します。寸法の測定点と値は変えず、縮尺の変更時は図から寸法線までの用紙上の距離を保つよう位置を補正します。基本図など6項目以内では縦横に分ける組合せを探索し、それを超える図では複数の並べ順で矩形配置を比較します。

自由配置では通常の第三角法の位置関係を保たないため、図枠の表記を AUTO LAYOUT に変えます。「配置をリセット」で通常の第三角法の配置へ戻せます。「用紙に収める」は従来の配置と定型縮尺から用紙に入る縮尺を選びます。

自由配置中に用紙・向き・図枠を変更した場合や、断面・詳細図・自動寸法を追加した場合も再配置します。コメントや手動寸法の追加・移動後は「大きく自動配置」で再計算できます。文字・コメントだけで用紙に入らない場合は理由を表示します。

自動配置の縮尺・位置・寸法位置・配置方式を作業ファイルに保存し、元に戻す・やり直すに対応します。SVGとPDFは画面上の用紙寸法・縮尺・配置を使って保存します。

「穴位置表を作成」で投影図の基準点と穴を選ぶと、中心のX・Y、穴径、穴深さ、座ぐり径、座ぐり深さをmmで表示します。貫通穴の穴深さは「貫通」、止まり穴は入口から底までの値です。座ぐりは同じ穴番号の1行にまとまります。穴の形状から特定できない値は「—」で表示します。

作成済みの表では「この表に穴を追加」を押し、同じ図上で穴を選んで「選んだ穴を追加」を押します。元の基準点、表の位置、既存の穴番号を保ち、新しい行を末尾に追加します。例えば左右の穴がH1・H2なら、間の穴を追加しても右はH2のままで、間の穴がH3になります。

モデルの穴を移動したり径を変えたりすると、穴位置表は基準点と穴番号を保って該当行を更新します。削除された穴や対応を特定できない穴は、図面・SVG・PDFの表に「要確認」として残ります。三面図の「要確認の穴」から番号を選び、「図上で穴を再指定」でその行を別の円に結び直せます。「この行を削除」では残りの穴番号を維持します。

断面線をドラッグするか切断位置を入力すると、同じ辺や穴を参照する寸法が新しい実測値に追従します。断面の向きを反転すると寸法と注記も向きに合わせて移ります。対応する形状がなくなった寸法は「要確認」に残るので、寸法の編集から参照先を指定できます。

「第三角法の配置をロック」で、正面図に対して上面図・底面図を上下に、側面図を左右に動かせます。正面図をドラッグすると投影図が一緒に動きます。「配置をリセット」ではロックが付き、「大きく自動配置」では自由配置になります。ロックの設定と位置は作業ファイルに保存されます。

ドラッグ中は用紙の表示位置と倍率を保ち、はみ出した項目を赤枠で示します。はみ出し一覧はドラッグを終えると更新されます。

コメントをクリックすると右端につまみが現れます。つまみを左右にドラッグするか、「折り返し幅 (mm)」に数値を入力すると、書き始めの位置と手動改行を保って、そのコメントの幅を指定できます。「自動幅に戻す」で余白に合わせた折り返しに戻ります。指定した幅は作業ファイル、SVG、PDFにも反映されます。

穴位置表の行、図上の穴、またはH番号をクリックすると、同じ番号の行と穴が強調されます。「要確認」の行を選ぶと再指定する行も切り替わります。余白をクリックすると強調が消えます。強調は編集画面で表示します。

表題欄に部品名と改訂番号を入力すると、例えば「連結プレート」「02」は `連結プレート_Rev02.pdf` または `連結プレート_Rev02.svg` で保存されます。改訂番号だけを省くと部品名で、両方を省くと `three-views` の名前で保存されます。

「図・コメントの整列」では、一覧のチェックボックス、または用紙上のCtrl＋クリックで図やコメントを複数選択できます。左端・中央・右端、上端・中央・下端をそろえられ、3項目以上では左右または上下の空きを等間隔にできます。図は見出しと寸法を含めて整列します。図枠・表題欄の外へは移動せず、等間隔にする余地がない場合は両端を離すよう案内します。変更は元に戻す・やり直すと作業ファイルへの保存に対応します。

PDFのページ構成で「ページを指定」を選ぶと、「PDFのページ割り当て」で1〜32ページを設定できます。各ビュー・断面図・詳細図・コメント・穴位置表を任意のページへ割り当てます。複数ページの初期設定は「編集した配置と縮尺を保持」です。例えば、正面図・上面図・右側面図を整列したまま1ページ目に出力し、断面図と穴位置表を2ページ目に出力できます。各ページで余白に合わせたい場合は「ページごとに自動配置」を選べます。ページ割り当てと配置設定は作業ファイルに保存され、コメントだけのページや空白ページも出力できます。

「PDFをプレビュー」で、出力する全ページの配置、寸法の重なり、参照先を要確認の寸法と穴を確認できます。問題があれば「PDF保存」からもこのプレビューが開きます。寸法や穴の警告を押すと図面上の該当箇所へ移動します。はみ出しや表題欄との重なりは配置を調整してから保存し、寸法と参照先の警告は確認のうえ「この内容でPDF保存」を選べます。

複数ページで出力する設定では、編集画面の用紙の上に案内が出ます。ここでは図面全体を1枚で表示し、各ページは「PDFをプレビュー」で確認できます。「ページを指定」では共通コメントと追加コメントの掲載先をそれぞれ選べます。「全体図と補助図を分ける」ではコメントは1ページ目に載ります。矢印付き注記や寸法、切断線は、付けた図と一緒に移ります。

「図面プリセット」を開くと、標準の「加工用（三面を共通縮尺）」「説明用（正面大・俯瞰小）」を呼び出せます。現在の用紙・向き・図枠・隠れ線・図の優先・俯瞰図を名前付きで30件まで保存でき、同名更新・削除にも対応します。保存場所はこのブラウザーの同じサイトのローカルストレージで、別の作業ファイルでも呼び出せます。

呼び出すと対象モデルに合わせて用紙内へ自動配置します。部品名・材質・日付・コメント本文・寸法・切断線・詳細図はプリセットの保存対象にせず、現在の図面の内容を維持します。モデルごとの図の位置と縮尺は呼び出し時に求め直し、寸法の実測値と寸法線の用紙上の余白を保ちます。呼び出しは文書のUndo/Redoに対応し、プリセットの保存・削除はモデルを変更しません。壊れた保存データやストレージの保存失敗では設定を上書きせず、標準プリセットと通常の図面操作は継続できます。`tests/drawing-presets.mjs` と `tests/drawing-auto-layout-browser.mjs` で検証します。

「図の優先」で「正面図を優先（1.4倍）」を選ぶと、基準縮尺に対して正面図を1.4倍にして用紙内へ再配置します。「共通縮尺」に戻すこともできます。「俯瞰図」は通常・小さく（半分）・非表示から選べます。非表示の俯瞰図は用紙の配置領域を消費しません。各設定の変更時に自動配置し、寸法の実測値と用紙上の寸法線の余白を保持します。

ページ上のすべての図が同じ縮尺なら、用紙上部に実際の縮尺を1つ表示します。縮尺が混在するページは、用紙上部に「縮尺は各図に記載」、各ビューの見出しにその図の縮尺を表示します。詳細図の倍率も独立して保持します。設定は作業ファイルへ保存し、Undo/Redo・再読み込み・SVG/PDF出力に対応します。旧ファイルは共通縮尺・俯瞰図通常として扱います。`tests/drawing-view-preferences.mjs` と `tests/drawing-auto-layout-browser.mjs`で縮尺、寸法値、余白、保存・取消・出力を検証します。

検証：tests/drawing-auto-layout.mjs（A4/A3・縦横・28形状、自由配置の拡大率、注釈の領域、詳細倍率、非変更性、保存形式）と tests/drawing-auto-layout-browser.mjs（A4横の初期値、寸法・コメント、詳細図、Undo/Redo、再読み込み、既存A3縦の復元、SVG/PDFの用紙サイズ）を使用します。

## 自動寸法の種類とまとめ表記

「自動入力する種類」で、全図共通の外形寸法・円／穴径・R寸法・中心位置／間隔を選べます。「ビュー別の自動寸法」と併用し、両方で有効な種類だけを追加します。共通設定は断面・詳細図にも適用します。設定の変更は、既に描いた寸法を削除しません。

「外形寸法を幅・奥行き・高さに各1つ」をオンにすると、「寸法を自動入力」で各方向を有効な図に1回ずつ記載します。設定は加工用プリセットでも有効になります。既存の自動外形寸法に重複があれば非表示にし、手動で設定した寸法や、位置を固定した寸法、公差・注記のある寸法は維持します。非表示の寸法は「寸法一覧・一括編集」から再表示でき、自動入力全体を「元に戻す」で取り消せます。

「同じR・穴径をまとめる」は初期状態でオンです。同じ図の同じ実半径の角を「4×R2」、同径の円を「6×Ø5」のようにまとめます。表示桁を丸めて同じ文字になるだけの異なる実寸法はまとめません。既存寸法は「同じR・穴径をまとめる」ボタンでまとめられます。図・種類・実半径・公差・注記・色・サイズ・表示／固定状態などの書式が同じものだけが対象です。手動寸法と自動寸法、参照先が要確認の寸法は区別します。まとめた寸法は各円・円弧の中心を保存し、モデル変更で参照先を確認できなくなった場合は古い数量を有効な寸法として表示しません。

まとめチェックを外してから自動入力すると、各R・穴径を個別に追加できます。過密化を避けるため従来どおり追加数には上限があります。既存のまとめ表記を、このチェックの変更だけで分解することはありません。

## 寸法一覧・一括編集

「寸法一覧・一括編集」を開くと、表示／非表示を含む全寸法を確認できます。図で絞るか、R2・直径・TOPなどで検索し、チェックした寸法だけの文字サイズ・寸法線色・文字色・表示をまとめて変更できます。「絞り込み結果を選択」は現在の検索結果を選び、「選択を解除」で選択を空にします。実測値と参照する形状は変更しません。

寸法名を押すと図中の寸法へ移動して強調します。非表示の寸法は薄く仮表示し、位置を確認できますが、SVG・PDFには含めません。非表示の寸法も作業ファイルに保存し、一覧から再表示できます。サイズ変更・再表示時は自動寸法の重なりを再調整し、位置が固定された寸法は維持します。まとめ・一括変更・種類設定は保存／再読込と元に戻す／やり直すに対応します。

検証：`tests/drawing-dimension-management.mjs` はまとめの条件、種類の絞り込み、対象だけの書式変更、非表示、保存データの検証、参照先の追従を確認します。`tests/drawing-dimension-management-browser.mjs` は実際のR付き穴あき部品で、各操作・Undo/Redo・SVG/PDF・保存／再読込・モデル形状を変更しないことを確認します。
