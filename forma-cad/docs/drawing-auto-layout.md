# 三面図の用紙と自動配置

新規図面の初期値はA4横向きです。最初に三面図を生成した際、正面図・平面図・右側面図・俯瞰図を共通縮尺で大きく配置します。保存済み図面の用紙・向き・配置は優先し、A3縦などの既存設定もそのまま復元します。

用紙設定の「大きく自動配置」を押すと、各図の上下・左右の位置関係を自由に組み替え、用紙に収まる共通縮尺を探索します。図そのものは回転せず、断面図・詳細図の倍率を保持します。縮尺は通常の選択肢に限らず連続値を使用し、「自動」の選択肢として表示します。自動サイズの用紙を選んでいた場合はA4へ切り替えて配置します。

図のラベル、寸法、中心マーク・中心線、断面の切断線、詳細図のマーク、コメント、図枠・表題欄の範囲を考慮します。寸法の測定点と値は変えず、縮尺の変更時は図から寸法線までの用紙上の距離を保つよう位置を補正します。基本図など6項目以内では縦横に分ける組合せを探索し、それを超える図では複数の並べ順で矩形配置を比較します。

自由配置では通常の第三角法の位置関係を保たないため、図枠の表記を AUTO LAYOUT に変えます。「配置をリセット」で通常の第三角法の配置へ戻せます。「用紙に収める」は従来の配置と定型縮尺から用紙に入る縮尺を選びます。

自由配置中に用紙・向き・図枠を変更した場合や、断面・詳細図・自動寸法を追加した場合も再配置します。コメントや手動寸法の追加・移動後は「大きく自動配置」で再計算できます。文字・コメントだけで用紙に入らない場合は理由を表示します。

自動配置の縮尺・位置・寸法位置・配置方式を作業ファイルに保存し、元に戻す・やり直すに対応します。SVGとPDFは画面上の用紙寸法・縮尺・配置を使って保存します。

「図面プリセット」を開くと、標準の「加工用（三面を共通縮尺）」「説明用（正面大・俯瞰小）」を呼び出せます。現在の用紙・向き・図枠・隠れ線・図の優先・俯瞰図を名前付きで30件まで保存でき、同名更新・削除にも対応します。保存場所はこのブラウザーの同じサイトのローカルストレージで、別の作業ファイルでも呼び出せます。

呼び出すと対象モデルに合わせて用紙内へ自動配置します。部品名・材質・日付・コメント本文・寸法・切断線・詳細図はプリセットの保存対象にせず、現在の図面の内容を維持します。モデルごとの図の位置と縮尺は呼び出し時に求め直し、寸法の実測値と寸法線の用紙上の余白を保ちます。呼び出しは文書のUndo/Redoに対応し、プリセットの保存・削除はモデルを変更しません。壊れた保存データやストレージの保存失敗では設定を上書きせず、標準プリセットと通常の図面操作は継続できます。`tests/drawing-presets.mjs` と `tests/drawing-auto-layout-browser.mjs` で検証します。

「図の優先」で「正面図を優先（1.4倍）」を選ぶと、基準縮尺に対して正面図を1.4倍にして用紙内へ再配置します。「共通縮尺」に戻すこともできます。「俯瞰図」は通常・小さく（半分）・非表示から選べます。非表示の俯瞰図は用紙の配置領域を消費しません。各設定の変更時に自動配置し、寸法の実測値と用紙上の寸法線の余白を保持します。

基準縮尺と異なる正面図・俯瞰図にはラベルへ SCALE を付記します。詳細図の倍率も独立して保持します。設定は作業ファイルへ保存し、Undo/Redo・再読み込み・SVG/PDF出力に対応します。旧ファイルは共通縮尺・俯瞰図通常として扱います。`tests/drawing-view-preferences.mjs` と `tests/drawing-auto-layout-browser.mjs`で縮尺、寸法値、余白、保存・取消・出力を検証します。

検証：tests/drawing-auto-layout.mjs（A4/A3・縦横・28形状、自由配置の拡大率、注釈の領域、詳細倍率、非変更性、保存形式）と tests/drawing-auto-layout-browser.mjs（A4横の初期値、寸法・コメント、詳細図、Undo/Redo、再読み込み、既存A3縦の復元、SVG/PDFの用紙サイズ）を使用します。
