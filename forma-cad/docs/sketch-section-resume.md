# 断面スケッチの再編集

角度を変えた紫グリッドや「この断面でスケッチ」で描いたスケッチは、同じスケッチ番号・一覧・履歴から再編集すると断面表示も再開します。手前側を隠す方向は現在の視点に合わせます。断面操作のパネルは開きません。

作図中に確定した各スケッチ要素に `sketchSection: true` を保存します。通常保存・再読み込み後も有効です。断面位置は保存した別の座標ではなく、スケッチの現在の作図平面・位置から復元します。スケッチグループに線を追加するときも引き継ぎます。

「作図断面」をクリックすると、その編集セッション中は通常表示にできます。スケッチを終了して再び入ると断面を再開します。終了時は以前の断面表示を復元し、以前の断面がなければ全体を表示します。通常のスケッチには断面を自動適用しません。CAD形状・寸法・モデリング履歴は変更しません。

以前のバージョンで作成したファイルにはこのフラグがありません。既存の任意平面スケッチをすべて断面扱いにする推測はしません。

検証:

- `node --test tests/sketch-section-state.test.js`: XYZ・任意平面、保存復元、位置更新、セッションの識別、不正データ。
- `node tests/sketch-section-resume-browser.mjs`: 実際に描いた160 mm²のスケッチ、番号・一覧での再編集、通常スケッチとの切替、保存再読み込み、手動断面、表示オフ・終了時の復元。
- `node tests/sketch-auto-section-browser.mjs`: 視点に応じた非表示側、既存断面の復元、紫グリッドなどの回帰検証。
- `node tests/angled-sketch-grid-browser.mjs`: 角度付きスケッチから実際の押し出しまでの回帰検証。
