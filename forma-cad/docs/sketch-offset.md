# スケッチのオフセット

「片側」で開いた線をオフセットすると、初期状態では元の線とコピーの両端を直線でつなぎ、閉じた輪郭を作ります。幅は指定したオフセット距離の絶対値です。「開いた端を元の線につないで閉じる」を外すと、従来どおり開いた線だけを作成できます。

つながった複数の選択線は一つの経路としてオフセットし、経路の両端だけを閉じます。別々の経路や異なる平面の線はそれぞれ独立して処理します。分岐した線は接続先を判断できないため、分岐のない経路に選択を絞る案内を表示します。閉じた図形と「全周囲」の動作は従来どおりです。

追加する端の線と塗りつぶされた領域をプレビューで確認できます。「作成後に押し出す」は初期状態でオンです。元の線は残す／置き換えるを選べます。置き換える場合も、閉じた輪郭の境界には元の経路を含めます。キャンセルでは元データを変更せず、作成は一回の元に戻す操作で取り消せます。押し出しの確定は別の履歴です。

検証: `node tests/sketch-offset-closure.mjs`、`node tests/sketch-offset-closure-browser.mjs`。
