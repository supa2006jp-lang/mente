# 穴の内壁の正方向プル

穴の円筒面を正方向へプルすると、穴の空間に材料を追加し、内径が小さくなります。負方向は材料を削り、内径が大きくなります。例えば半径5 mmの穴を＋0.2 mmプルした結果は半径4.8 mmです。

以前は、内壁から作った追加用の環状ソリッドと元のボディを通常の `fuse` で結合していました。両者が同じ周期的な円筒面を共有すると、結合・面整理の処理が空の形状を返し、プルできませんでした。オフセット自体の方向は正しいため、距離の符号を反転してはいけません。

`pullFaces` は、追加用ソリッドの向きを正の体積にそろえ、既存の検証付き `fuseSolids` で元のボディと一括結合します。CADの妥当性・体積・連続性・面ごとのメッシュ生成を確認する共通処理を使用します。入力は独立したCADコピーにして、選択面・追加形状・中間結果を解放し、元の形状と表示キャッシュを維持します。

負方向の切り取りと、履歴に基づくねじ面のプル方法は変更しません。円筒以外の曲面は、元のオフセット処理が対応できる形状・距離の範囲で動作します。
