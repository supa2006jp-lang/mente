# スケッチ番号で切替

作業画面左上の視点名・作業モード表示の右側に、既存スケッチの①②③などの番号を表示します。押すと、そのスケッチのグループを編集対象にして線分の作図を開始します。元の作図平面・平面の位置を引き継ぎ、任意平面も含めてその平面に正対します。非表示のスケッチも切替先として選べます。編集中の番号は青緑、非表示の番号は破線で示します。

作図途中で別番号へ切り替えると、未確定の線やプレビューは解除し、確定済みの線・形状は保持します。作図中に同じ番号を押した場合は、現在の始点を維持します。新しい線は選択した番号のグループへ追加します。まだ線や図形を確定していない新規スケッチの番号は、編集中の表示だけを行います。

番号は左側のスケッチ一覧と一致し、削除や読み込みで欠番があっても詰め直しません。多数ある場合は横スクロールできます。Tabで番号にフォーカスし、左右矢印・Home・Endで番号を移動、EnterまたはSpaceで切り替えることもできます。スケッチがない場合は表示しません。

押し出し・移動・回転などの別操作、計算中、保存中、ダイアログ表示中は切替を無効にします。切替のための新しい履歴工程は追加せず、既存のスケッチ編集と同じグループ・表示管理を使います。

検証：`tests/sketch-number-tabs-browser.mjs`で、番号表示、非表示からの切替、XY・XZ・任意平面と位置の引継ぎ、追加線の所属、既存形状の保持、未確定作図の解除、同じ番号の再クリック、保存再読込、ダイアログ中の無効化、配置と横スクロール・キーボード操作、欠番と全削除を確認しています。
