# グリッド線とソリッド境界の交点吸着

スケッチの作図中に「グリッド吸着」がONなら、表示中のグリッド線とソリッド境界が交わる点にも吸着する。両方の座標がグリッド間隔の倍数である必要はない。斜めの辺で、片方の座標だけがグリッド線に一致する交点も選べる。

- 吸着時は緑の「×」と「グリッドとソリッドの交点」を表示する。
- XY・XZ・YZ、選択面の紫グリッド、傾けた紫グリッドと自動断面に対応する。
- 実際に描画している有限のグリッド線を使う。拡大縮小による表示密度、間隔の変更、面の輪郭・穴・拡張範囲を反映する。
- ソリッドは作図面と交わる輪郭を使う。別の高さのシルエット、非表示ボディ、他のソリッドの陰にある点は候補にしない。自動断面で取り除かれた手前側の面は遮蔽物として扱わない。
- 真の端点・中心・中点など既存の点候補を保ち、交点は通常の辺上・角度吸着より優先する。円周を描画用に分割しただけの節点を頂点・中点として扱わない。
- 数値で指定した角度に合わない交点へは吸着しない。長さ指定中には新しい交点吸着を加えない。
- グリッド吸着OFFでは交点吸着もOFF。通常のソリッド境界吸着は継続する。判定距離は画面上の8ピクセル以内。
- 表示用のFloat32座標で丸められたグリッド端点は、微小な表示誤差の範囲だけ許容する。採用する点はソリッド境界上に保つ。

検証：`tests/grid-boundary-snap.test.js` は有限線分、平行・別平面の除外、数値方向、面の穴、傾斜面、遮蔽・断面クリップ、表示端点の丸めを検査する。`tests/grid-boundary-snap-browser.mjs` はXY・XZ・YZ、斜めの辺、ON/OFF、ズーム・間隔変更、保存と再読み込み、傾けた紫グリッドの自動断面、曲線の境界を実画面で検証する。
