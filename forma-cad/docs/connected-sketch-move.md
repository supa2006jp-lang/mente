# つながるスケッチの移動

スケッチの線を選択し、左下の「移動（つながる線）」、または上部の「移動／回転」を押します。直線・曲線が混在していても、同じスケッチグループ・同じ作図面で端点や角がつながる図形をまとめて移動します。矩形・ポリラインは輪郭全体、独立した円は円全体が対象です。見た目だけの交差、実際に隙間がある線、別グループ・別平面・非表示の図形は自動で含めません。

矢印またはキャンバスを左ドラッグして、作図面内で移動します。「吸着させる基準点」で端点・角・円の中心を選び、表示中のグリッド交点や同じ面の別スケッチの端点・中心に合わせます。吸着時は緑色、通常移動は水色、移動前は薄い線で表示します。Shiftを押している間は吸着を解除します。横・縦の移動量を数値入力することもできます。数値入力は入力した距離をそのまま使用し、勝手にグリッドへ丸めません。初期移動量は常に0です。

ドラッグを離しても未確定です。矢印内の「＋決定」、パネルの「確定」、Enterで適用します。Esc、キャンセル、他の編集の開始は元の表示に戻します。ホイールでズームでき、移動に合わせてカメラを勝手に動かしません。

形・長さ・曲線の制御点や接線は変えず、配置だけを変えます。作図面の法線方向には移動しません。図形IDと名前を保つため、既存の押し出し領域やパイプ経路の参照を更新できます。後続の立体がある場合は確定時にまとめて再計算し、失敗・中止・モデル変更時は適用しません。移動全体は1回の取り消し・やり直しに対応します。キャンセル可能な再計算中は入力を固定します。

- `tests/connected-sketch-move.mjs`: 分岐・曲線・グループ・作図面・配置・形状保持・吸着・参照更新
- `tests/connected-sketch-move-native.mjs`: CAD本体での後続の押し出し・混合経路パイプの更新、体積維持
- `tests/connected-sketch-move-browser.mjs`: ボタン・ドラッグ・基準点変更・数値・吸着表示・キャンセル・確定・取り消し・保存再読込
