# ソリッドの面に写真を配置

ソリッドの平らな面を選択し、左下の「この面に写真を貼る」を押して画像を読み込みます。写真は面の中央に収まる大きさで配置します。面は配置平面の基準とし、写真をその輪郭で切りません。実寸調整や移動・回転で面からはみ出しても、同じ平面上に写真全体を続けて表示します。すでに保存した写真にも適用します。表示範囲を絞る場合は写真のトリミングを使用してください。曲面への巻き付けは対象外です。

下絵パネルでは横幅、横位置、縦位置、透明度を調整できます。「写真をトリミング」では四隅をドラッグして範囲を変えられます。枠の内側のドラッグは範囲の移動、外側のドラッグは新しい範囲の指定です。上下左右を削る割合も数値で入力できます。

元画像を保持するため、「写真全体に戻す」で範囲を復元できます。トリミングのキャンセルはモデルを変更しません。範囲が不正な場合は適用できません。保存ファイルには画像、範囲、配置平面、角度を記録します。

回転は数値入力と−0.1°／＋0.1°、90°、0°のボタンで調整します。他の項目を変更しても位置・大きさの端数を丸めません。「2点を指定して実寸に合わせる」も利用できます。

「この平面でスケッチ」で、写真を表示した面と視点を引き継いで線を描けます。「輪郭をスケッチ化」はトリミング後の範囲を解析します。面情報は配置時の平面・輪郭の記録であり、後からソリッドを移動・加工した際の追従拘束ではありません。画像はSTLには含まれません。

## ボタンなどを個別にスケッチ化

写真を貼ったソリッドの面を選択すると、左下に「写真を非表示」「写真を外す」を表示します。非表示後は同じ場所の「写真を再表示」で戻せます。複数の写真がある面では一覧から操作する写真を選びます。写真の操作は貼り付け先のボディ・平面・面の重なりで判断し、裏側や別ボディの写真は対象にしません。写真を外してもソリッドや作成済みスケッチは残り、元に戻す／やり直しに対応します。

下絵パネルの「写真の部分をクリックして輪郭を取得」を押し、写真上のボタンなどの内側をクリックします。クリックした色に近い、つながった範囲だけを抽出し、解析画面で緑色の輪郭を表示します。同じ色でも離れたボタンは別の対象として扱います。文字・マーク・反射を避けた部分をクリックしてください。

「クリックした色の許容差」を上げると取得範囲が広がり、下げると色が近い範囲に絞ります。初期値は30です。写真・解析範囲の端まで広がった候補は確定できません。値を下げるか内側を選び直してください。必要に応じて既存の範囲指定、塗り補正、頂点編集、直線・円弧への整理も使えます。

「この部分をスケッチに追加」で独立したスケッチ番号に取り込み、そのまま次の部分をクリックできます。追加済みの輪郭は青い破線で表示し、同じ解析画面内で同一の輪郭を再追加する操作は止めます。「完了」で閉じます。追加前の閉じる／Escはモデルを変更しません。すでに追加した分は閉じても残り、モデルの「元に戻す」で1回の追加ごとに取り消せます。

輪郭は写真の実寸・トリミング・回転・配置面を引き継ぎます。画像そのものやソリッドは変更しません。これは色に基づく部分抽出で、写真内のボタンを意味から認識する処理ではありません。色が連続したり強い陰影がある部分は条件調整や手直しが必要です。画像の解析は端末内で行います。

通常の「輪郭をスケッチ化」から開いた場合も、検出方法を「クリックした部分を検出」に切り替えると同じ操作ができます。クリック位置は輪郭解析の途中保存にも含まれます。追加済みスケッチは通常のモデル保存で保存してください。

### 本体と似た色のボタン

「似た色は溝・影の境界で補完」は初期状態でONです。色の検出が本体側まで広がったとき、クリック部分を囲む溝・影の境界で小さな閉じた範囲を作れる場合は、そちらを採用します。採用時は「溝・影の境界で補完」と表示します。OFFにすると色だけの方式へ戻ります。

個別に調整するには、検出方法の「溝・影の境界で部分を検出」を選びます。「境界の強さ」は初期値12で、下げると薄い影も検出し、上げると強い境界に絞ります。文字や反射を避けてボタンの内側をクリックしてください。境界が途切れて範囲の端まで広がった場合は、確定を止めます。検出条件や塗り補正で修正してください。写真上の微妙な境界を必ず検出できるものではありません。

### 規則的な形に整える

輪郭を取得後、「規則的な形に整える」をONにし、「整理の許容誤差」を指定します。「整理する形」では自動判定のほか、円・楕円・長方形・角丸長方形・長穴（両端が半円）・片側が半円の形を指定できます。自動判定が意図と違う場合は種類を指定してください。

緑は元の輪郭、青は整理後です。形を変える前にプレビューと変換した形の個数を確認できます。許容誤差内で合わない輪郭は元の形で残します。規則的な形への整理と「直線・円弧へ整理する」は切り替えて使用します。

判定には写真の横・縦の実寸を使用し、中心・傾きを含めて近似します。円は通常の円スケッチとして保存します。楕円は楕円上の点からなる閉じたポリラインで、曲線の分割誤差の目標を0.005 mm以下として保存します。入力の画素や撮影による遠近を含む実物との精度を保証するものではありません。外周と穴の交差・接触が生じる候補は確定できません。OFFに戻すと元の輪郭を使用します。

長方形は4辺の閉じた線、角丸・半円を含む形は直線とCADの円弧を組み合わせて保存します。寸法や回転は写真の配置を引き継ぎます。

### 乱れた区間を直線に補正

プレビューの操作を「区間を直線に補正」にし、同じ輪郭の線上で区間の両端をクリックします。短い側の区間を1本の直線に置き換えて青で表示します。「反対側の区間」で、閉じた輪郭のもう一方の経路に切り替えられます。「この区間を直線に」で補正し、合わなければ「選び直す」またはEscで中止します。

区間外の線や穴は変更しません。交差やつぶれが生じる候補は適用できません。直線化すると自動の形状整理をOFFにし、補正した線を保ちます。「補正を戻す／やり直す」に対応し、スケッチへの追加まではモデルを変更しません。選択途中の区間は途中保存の対象外で、その間は保存を無効にします。補正を適用した後の頂点は途中保存に含まれます。

### 許容誤差の自動調整

「規則的な形に整える」をONにし、対象の輪郭を選んで「許容誤差を自動調整」を押します。円・楕円・長方形・角丸長方形・長穴・片側半円の候補を比較し、少ない誤差で整理できる形と許容誤差を提案します。「整理する形」で種類を指定した場合は、その形だけを候補にします。

紫色の候補（オフセット前）と誤差の値を見て「この誤差で整理」を押します。選んだ輪郭だけに個別の形・許容誤差を保存し、共通値と他の輪郭は変えません。「共通の整理条件に戻す」で個別指定を解除できます。元に戻す／やり直しと途中保存にも対応します。実測寸法を調整中の輪郭は、寸法のチェックを解除してから自動調整してください。

探索の上限は初期値3 mm、0.01〜10 mmで変更できます。輪郭の短辺相当の12%以内に制限し、面積変化25%超、交差・接触・穴のはみ出しを起こす候補を除外します。数値は0.01 mm単位の目安です。候補がなければ形と誤差は変更せず、検出の見直しを案内します。輪郭の内側のロゴや影を拾った場合、許容誤差だけで本来のボタン外周に復元できるとは限りません。候補の「中止」またはEscで元の表示へ戻せます。探索中・候補確認中はスケッチ追加と途中保存を無効にし、設定変更・閉じる・別の輪郭選択で古い結果を破棄します。

### 輪郭ごとの寸法とオフセット

「輪郭ごとの調整」で対象を選びます。「プレビューで輪郭を選ぶ」を押して輪郭の線をクリックしても選べます。選択した輪郭は紫色と番号で表示し、外周・穴の区別を一覧に表示します。複数のボタンは従来どおり部分ごとに選択・追加できます。

「規則的な形に整える」で一致した輪郭では、「実測寸法で調整」をONにすると幅・高さを直接指定できます。円は直径、角丸長方形は角丸半径も指定できます。中心と向きを固定し、他の輪郭の寸法・位置を変更しません。寸法は0.1〜10,000 mm、角丸半径は0.05 mm以上で幅・高さの半分以下です。長穴の幅は高さ以上、片側半円の幅は高さの半分より大きくします。輪郭同士の交差や穴のはみ出しは確定を止めます。

オフセットをONにして「この輪郭だけのオフセット量」をチェックすると、選んだ輪郭だけ別の距離を使えます。チェックを外すと共通の距離に戻ります。穴では＋で小さく、−で大きくなります。個別指定した輪郭の消滅・分離や他の輪郭との接触は、確定せず距離の修正を求めます。個別の寸法・距離は補正のUndo/Redoと途中保存に含まれます。検出条件や元の輪郭を変えると別の輪郭として扱う場合があります。

### 抽出設定の初期値・プリセット

標準の初期値は、検出方法「溝・影の境界で部分を検出」、境界の強さ12、ノイズ除去「強」、線分の細かさ0.31 mm、規則的な形に整えるON・自動判定、整理誤差0.51 mm、比較ON、オフセットON・1 mm、元の輪郭を残すOFF、穴の取り込みOFFです。対象の内側をクリックして解析します。

右側上部の「抽出設定のプリセット」を開き、名前を付けて「設定を保存」を押します。32件まで保存でき、同名は更新します。一覧から「呼び出す」で反映し、補正を戻すと呼び出す前に戻せます。「この設定を初期値にする」は次に輪郭取得を開くときから使用し、「標準の初期値に戻す」で上記の設定に戻せます。プリセットの一覧は残ります。

保存対象は検出・整理・比較・共通オフセット設定と自動調整の上限です。クリック位置・解析範囲・塗り補正・輪郭ごとの寸法や距離は含めません（それらは途中保存を使用）。プリセットはブラウザー内に保存し、ファイルの書き出し・読み込みで他の環境へ移せます。同名は更新し、異なる名前は追加します。不正なファイルや32件を超える読み込みでは保存済み設定を変更しません。

### 自動オフセット

「オフセット線を追加」をONにし、距離をmmで指定します。初期値は1 mm、範囲は±0.001〜100 mmです。＋は外側、−は内側で、0は指定できません。写真の横・縦の実寸に基づき、形の整理や手直しの後の輪郭から計算します。橙色がオフセット線です。

「元の輪郭も残す」は初期状態でOFFです。オフセット線だけを取り込み、ONなら元の輪郭も残します。元の輪郭とオフセットは別のスケッチ番号で作り、1回の追加をまとめて元に戻せます。穴は外側へのオフセットで小さくなり、内側へのオフセットで大きくなります。全体が消滅する結果や過度に複雑な結果は確定しません。細い穴や隙間は距離によって消えたりつながる場合があるため、プレビューを確認してください。長方形の角はマイターでつなぎ、円・角丸長方形・長穴・片側半円は、可能な場合は正確な円・CAD円弧を保ってオフセットします。「直線・円弧へ整理する」の円弧も同心円弧と平行線で処理します。輪郭の消滅・合流・分裂などで接続関係が変わる場合や楕円では、検査したポリライン結果を使用します。維持できた輪郭数は結果欄に表示します。

オフセットは写真の外側にも作成できます。写真のプレビュー枠より外の線は表示が切れることがありますが、取り込みデータは切り詰めません。設定は途中保存で復元できます。元の輪郭をすでに追加済みの場合は「元の輪郭も残す」をOFFにして別距離のオフセットだけを追加してください。

## 写真にソリッドを合わせる

面に貼った写真のパネルから「写真のサイズにソリッドを合わせる」を押します。現在の表示範囲（トリミング後）の幅・高さ・中心・角度に合わせ、厚みを維持したソリッドを水色でプレビューします。「このサイズに変更」で確定します。キャンセルはモデルを変更しません。確定後も元に戻す・やり直しができます。

同じ断面が厚み方向に続く板・角柱・円柱が対象です。穴と輪郭は横・縦の倍率で変形するため、円が楕円になることがあります。写真の輪郭を自動抽出して切り抜く機能とは別の操作です。厚み方向に断面が変わるポケットやテーパーなどは、元のモデルを変えずに中止します。ソリッドを移動・加工して写真の配置面と一致しなくなった場合は、面に写真を貼り直してください。

変更後の形状と設定は履歴に保存します。写真はそのまま保持し、スケッチ用の面情報を変更後の位置に更新します。再度同じサイズ合わせを実行しても二重に拡大・回転しません。

### 抽出輪郭を押し出すときの負荷対策

完全な楕円上に等間隔で並んだ64点以上の閉じた輪郭は、CADで一本の楕円として扱います。元のスケッチ座標は変更せず、編集された輪郭・一部分だけの楕円・自由形状には適用しません。曲線に分割数の分だけ側面ができる負荷を抑えます。

距離だけを変える簡易プレビューでは、32種類までの輪郭メッシュを16 MB以内で再利用します。256頂点を超える輪郭では入力の間に280 ms待ってから正確なCAD計算を始め、古いプレビューに最新の距離が1.5秒以上待たされたら、古い計算を中止して最新の距離を計算します。確定処理は中止せず、正確な形状の確認後に確定します。実行中のドラッグは従来どおり簡易表示で追従します。

- `node --test tests/reference-trace-auto-tolerance.test.js tests/trace-extrusion-performance.test.js`：自動誤差・形の変形制限・キャンセル、楕円の検証、古いプレビューの置換・確定の保護を確認します。
- `node tests/reference-trace-auto-extrusion-browser.mjs`：自動調整の候補確認・取消・Undo・途中保存、1,924頂点の輪郭での連続距離変更、古い計算の置換と最新距離の確定を確認します。

### 一括整理・外周候補・押し出し前の確認

「複数の輪郭を一括自動調整」を開き、「画面で部分を続けて選ぶ」でボタンなどを一覧に追加します。選択した各部分に合う形と許容誤差を提案し、紫のプレビューと一覧を確認してから一括追加できます。失敗した部分は元のまま一覧に残します。32部分・合計12,000頂点までで、追加は一度のUndoで取り消せます。一覧は途中保存に含み、再開後は候補を再計算します。

内部のロゴ・文字を拾った場合は「ひと回り外の輪郭を探す」を使います。クリック位置を囲む、解析範囲の端に達していない外周を最大6件提示します。「元の輪郭」に戻せます。候補は内側の文字を含まず、クリック位置を囲む外形だけを採用します。遠近補正や実寸の推定は行いません。

押し出し中の「輪郭の計算負荷」は、円・円弧・楕円の復元後のCAD辺数を目安に表示します。80辺以上の領域では橙色の強調と「押し出し輪郭を整理…」を利用できます。外周・穴を一つずつ整理し、緑の元形状と紫の候補を比較してから、この押し出しに反映します。元のスケッチは変更しません。候補が合わない、または交差する場合は反映しません。

距離変更時の自動切り取り判定と、複雑な輪郭の押し出し方向判定はWorkerで実行します。写真やCAD履歴を判定用Workerへ送らず、変更前の距離の判定は中止します。判定が終わるまでは確定を無効にし、手動で操作を選べば自動判定を解除できます。隣接する空領域の共有辺は穴同士を合成して整理し、重複する穴の境界をCAD面へ渡さないようにしています。

対象ボディの直前のCAD結果だけを取り出す最適化でも、押し出し元の円・円弧スケッチを保持します。履歴を短くしたために曲線が多数の平面へ戻ることを防ぎます。

- `node --test tests/trace-batch-probe.test.js`：一括調整・中止・部分失敗・個別オフセット、外周候補、共有境界、判定の座標と古い結果の破棄を確認します。
- `node tests/reference-trace-batch-browser.mjs`：一覧・途中保存・一括追加・Undo、負荷表示・整理候補の取消と適用、元スケッチ保持を確認します。
- `node tests/trace63-extrusion-browser.mjs`：添付再現モデルの連続距離変更・CADプレビュー・確定・保存を確認します。入力は `FORMA_TRACE63_INPUT` で指定できます。
