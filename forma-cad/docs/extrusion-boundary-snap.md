# 押し出しのソリッド境界吸着

「グリッド吸着」がONのとき、押し出し矢印のドラッグで、押し出す範囲に重なる・接するソリッドの境界位置にも吸着します。スケッチの押し出しと、ソリッド面からの押し出しの両方に対応します。

境界に吸着している間は、相手の辺と矢印をエメラルド色で強調します。矢印の説明にはボディ名と距離を表示します。マウスを離しても距離は保持され、「＋決定」でその距離を確定します。境界から離す、操作を終了する、モデルを更新する際に強調を消します。

- 表示中の実際のボディ境界を作図面へ投影し、押し出し開始範囲の輪郭と交差・接触する位置を候補にします。穴の中にある無関係な辺、離れたボディ、非表示のボディは除きます。
- 斜めの辺が範囲をまたぐ場合も、範囲と交わる位置から停止距離を求めます。XYZ・任意平面、負方向・対称、複数領域を扱います。
- 8ピクセル以内の境界を候補にし、グリッドにも吸着できる場合はドラッグ位置に近い方を使います。正確なグリッド位置に合わせる操作も残します。
- 数値を丸めたグリッド距離ではなく、境界の座標から求めた距離を保持します。精密CAD座標の復元中のボディは候補にせず、復元後、操作が続いていれば候補を更新します。
- 候補の検索は実際にドラッグを始めてから行い、ドラッグ中は再利用します。「＋決定」をクリックするだけでは境界検索を行いません。
- この操作は距離の吸着です。相手ボディの変更に追従する拘束や到達面指定は追加しません。大きなテーパーで広がった先端全体を接触判定する機能ではありません。

検証:

- `node --test tests/extrusion-boundary-snap.test.js`: 隣接・交差・穴・非表示・遠方・変換・精密座標・負方向・対称・グリッド競合。
- `node tests/extrusion-boundary-snap-browser.mjs`: 水平／垂直スケッチと実際のソリッド面から、18.25 mmの境界へドラッグ、表示切替、吸着OFF、20 mmグリッド、離した後の保持、矢印で確定、保存値。
- `node tests/extrusion-boundary-snap-native.mjs`: 上記ブラウザーで確定したモデルをCADカーネルで再構築し、寸法18.25 mm、体積4380 mm³、相手ボディ不変、閉じた形状を確認。

既存の `face-extrude-drag-browser.mjs` は、正面視点でドラッグしても視点を変えないという古い前提があり、公開済みビルドでも同じ距離比較に失敗します。今回の機能の検証には、現在の自動斜め視点に対応した上記ブラウザーテストを使います。
