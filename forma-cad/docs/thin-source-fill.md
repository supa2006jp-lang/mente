# 薄い押し出しの根元を補完

新しく薄い押し出しを開始すると「根元を補完（元厚20 mm以下）」が標準でONになります。プロパティ欄と画面内の薄い押し出しパネルの両方から切り替えられます。OFFにすると従来の押し出し形状に戻ります。

片側・外側の新規ボディ／結合で、参照している元ソリッドの厚みが20 mm以下なら、壁の開始側を元ソリッドの裏面まで延長します。外側の壁が元ソリッドに辺だけで接し、厚みの分だけ浮く状態を解消します。押し出し距離で指定した終端や、既存のテーパーは変えません。切り取り・対称押し出し・バリア押し出しには適用しません。

元ソリッド全体の高さではなく、輪郭のすぐ内側にある、開始面につながった材料の厚みを調べます。中央の長い支柱や、空間を隔てた下側の板は厚みの測定に含めません。20 mmを超える場合や元ソリッドの参照がない場合は補完しません。

保存データには `thinSourceFill` を記録します。設定のない既存の薄い押し出しは、読み込み・再計算で形状が変わらないよう従来の動作を保ちます。再編集でONにすると補完を追加できます。

## 検証

- `node tests/thin-source-fill.mjs`：厚み5 mm・20 mm・20.001 mm、ON/OFF、旧データ、正逆・横向きの面、境界の線分、局所的な板厚、テーパー、表面までの押し出し、結合・保存・閉じたSTLを検証します。
- 上記実行後の `node tests/thin-source-fill-browser.mjs`：新規で標準ON、プロパティと画面内パネルの同期、OFFの保存、再編集でON、結合、Undo/Redo、再読込、STL出力を検証します。
- 既存の薄い押し出しの壁厚・方向・寸法表示・穴周囲の加工も回帰検証します。
