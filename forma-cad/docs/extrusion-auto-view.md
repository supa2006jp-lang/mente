# 押し出しスライダー操作時の視点調整

押し出し方向を正面または裏面からほぼまっすぐ見ている場合、押し出し矢印を押した時点で25°の斜め視点へ切り替える。法線方向と視線のずれが8°以内の場合だけ適用し、すでに斜めから見ている場合は変更しない。スケッチ・選択面の任意平面に対応する。

選択した輪郭の中心を画面上の同じ位置に保ち、ズーム倍率を保持する。視点の変更だけでは押し出し距離やモデルを変更しない。ドラッグ軸は切り替え後の投影から計算するため、表示と距離調整が一致する。既存のクリックによる確定操作は維持する。

検証：`tests/extrusion-auto-view.mjs` と `tests/extrusion-auto-view-browser.mjs`。正面・裏面・任意平面、画面上の基準点と倍率の保持、斜め視点での再回転防止、押した直後の距離保持、ドラッグ、キャンセルと確定を確認する。
