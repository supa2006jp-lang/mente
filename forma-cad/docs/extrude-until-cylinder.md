# 円柱の表面までの押し出し

円柱の側面へ「ソリッドの表面まで」で押し出す際は、円筒面を接線となる位置で分け、手前側の正確な曲面から到達範囲を計算します。円筒面の表裏が同じ面に含まれるために、多数の三角形の掃引形状を重ねて差し引く処理へ進むことを避けます。

従来の三角形による処理では、円柱を横切る広い輪郭で、到達位置や残す体積が誤る場合もありました。改良後は円筒面を保持し、円弧の積分から求めた体積と一致すること、円柱へ食い込まないことを検証します。

円筒の外側・穴の内側、任意の押し出し方向、軸に対する斜め方向、「接触する部分だけ」のON/OFFに対応します。球面・円錐面などの既存の接触計算は維持します。計算中は「押し出し先の表面を計算しています」と進捗を表示します。

## 検証

- `node tests/extrude-until-cylinder.mjs`：円柱の全周面と部分面、内側・外側、斜めの押し出し、接触のみ、正確な体積・到達距離・食い込みなし、プレビュー・結合・保存・閉じたSTLを検証します。各接触計算に8秒の回帰上限を設けます。
- 上記実行後の `node tests/extrude-until-cylinder-browser.mjs`：生成した試験片を独立したブラウザーに読み込み、プレビューの完了（15秒以内）、確定、保存、STL出力、Undo/Redo、再読込と接触のみへの切り替えを検証します。
- 計算時間の実測値は `.sites-runtime/extrude-until-cylinder` の検証記録に保存します。実際のモデルすべての計算時間を保証する値ではありません。
