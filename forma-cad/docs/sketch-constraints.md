# スケッチ拘束

画面上部のグリッド設定の横にある「拘束 ON/OFF」で、文書全体の拘束機能を切り替えます。OFFでは設定を残したまま、拘束の計算・位置固定を一時停止し、辺や頂点をクリックしても番号・拘束マーク・拘束の詳細表示を出しません。ONへ戻すと保存していた条件に合わせて補正します。元の位置を固定していた点も元の固定位置に戻るため、自由に動かした形を維持したい場合は、先に該当する拘束を個別にOFFにしてください。矛盾する条件で復帰できない場合は、OFFと元の形を保ち、エラーを表示します。

「スケッチ拘束」の一覧でも、各拘束を個別にON/OFFできます。OFFの印は灰色になります。個別設定の一括切替も可能です。設定画面内ではプレビューとして切り替え、「変更を確定」で反映します。画面上部の切替も設定画面を開いている間はプレビューです。全体・個別のON/OFFは文書への保存とUndo/Redoに対応し、OFF中に追加したスケッチも全体のOFFを引き継ぎます。OFFでも参照や保存データの形式は検証します。

ON/OFFの検証は `tests/sketch-constraints-toggle.mjs` と `tests/sketch-constraints-toggle-browser.mjs` を使用します。OFF中の移動と回転、固定位置の復帰、設定保持、圧縮保存、個別切替、画面の非表示、文書Undo/Redo、別ファイル読み込み、後続ソリッドの再計算と閉じたSTL出力を確認します。

スケッチの直線をクリック、または範囲選択すると、左下に「スケッチ拘束」が表示されます。作図中はEscで線の作図を止めてから選択してください。スケッチ番号の編集を終了する必要はありません。直線、長方形、直線で構成されたポリラインの各辺が対象です。円・円弧・スプライン・文字の輪郭は対象外です。

「線1」を基準として選びます。二つの要素の関係には、同じスケッチ番号・同じ平面から「線2」を選びます。Ctrlで複数の線を選んでから開いた場合は、その選択を優先します。

- **水平**：線1を作図面の横方向に保ちます。
- **垂直**：線1を作図面の縦方向に保ちます。
- **同じ長さ**：線1と線2の長さを同じに保ちます。追加時は線1の長さを基準にします。
- **端点一致**：線1と線2の始点A／終点Bを選び、一致させた状態を保ちます。追加時は線1の指定端点を基準にします。
- **長さ固定**：線1を指定した長さ（0.1〜10000 mm）に保ちます。同じ辺の値を更新できます。
- **位置固定**：線1の指定頂点を現在の位置に固定します。端点一致でつながる頂点も固定位置を保ちます。

線を選ぶと画面にも「図1・辺1」「図1・頂点1」の番号を表示します。設定欄の図形・辺・頂点と同じ番号です。辺の設定欄には両端の頂点番号も表示します。線1は青、線2は橙で区別し、設定一覧や画面の印に触れると対応する線・点を強調します。「画面で線1を選ぶ」「画面で線2を選ぶ」でも指定できます。番号と拘束の印は個別に非表示にできます。

番号付きの頂点は直接ドラッグできます。拘束を維持した形をプレビューし、グリッドや他のスケッチの端点に近づけると吸着します。Shiftを押す間は吸着を解除します。固定長さなどで指定位置へ動かせない場合は、可能な位置に沿って動きます。位置固定した頂点は移動できません。斜めの作図面でも、その面上で編集します。

拘束の印をクリックすると解除のプレビューになり、「変更を確定」で反映します。設定パネルは見出しをドラッグして移動でき、開いたまま視点を回せます。ドラッグ中のEscはそのドラッグだけを取り消し、もう一度Escを押すと設定を閉じます。位置固定した点を含む「つながる線の移動」も、固定を解除するまで適用できません。

水平・垂直は画面の向きではなく、作図平面のU/V方向を使います。XY・XZ・YZ・斜めの作図面で利用できます。既存のグリッドや角度の吸着とは別で、吸着しただけでは拘束を自動追加しません。

緑色の線が変更後のプレビューです。「線1の指定端点を移動」の横・縦座標で端点を動かせます。可能なら同じ要素の他の頂点を保ち、必要な場合は拘束を満たすよう周囲の頂点も調整します。動かした端点の座標を優先するため、未拘束の位置や長さは変わる場合があります。通常の寸法入力による再編集、つながる線の移動でも拘束を維持します。

「補正を戻す」「やり直す」はこの画面内の30操作を対象にします。設定済みの拘束は一覧の「解除」で外せます。「変更を確定」でモデルと後続の押し出しなどを更新し、文書全体の取り消しでは1回で元に戻ります。キャンセル・×・Escではモデルを変更しません。

矛盾する指定、線がつぶれる指定、閉じた枠の交差・接触、計算が収束しない指定は適用せず、関係する拘束の解除を案内します。水平・垂直を保ったまま枠全体を斜めに回す操作も拒否します。全体を回す場合は対応する水平・垂直の拘束を先に解除してください。自由度や寸法をすべて固定するフル拘束ソルバーではありません。

長方形の一部を独立して変更し、長方形として表現できなくなった場合は、同じIDと辺の順序の閉じたポリラインへ変換します。線の長さと位置の通常の再編集では、直線の表現を維持します。

拘束は各スケッチ要素の `sketchConstraints` に記録し、通常保存・軽量保存・読み込み・Undo/Redoで維持します。拘束対象の要素・線を削除した場合は関係する拘束を外します。複製した要素が元の要素の拘束を参照することを防ぐため、コピー先の拘束は設定し直してください。選択部品として保存する場合も、部品の形状を保存し、拘束設定は含めません。

上限は文書内200拘束・拘束対象の頂点合計256個です。参照、同一平面、同じスケッチ番号、数値、拘束の残差を検証します。端点一致では微小な隙間を残さないよう共有位置へ合わせます。無効な拘束を含むファイルは黙って形を変えず、読み込みを拒否します。

検証：`tests/sketch-constraints.mjs`（基本4種の拘束・端点編集・平行移動・回転拒否・4平面・不正データ・削除とコピー・圧縮保存）、`tests/sketch-constraints-browser.mjs`（追加・解除・プレビュー・矛盾時の保持・画面内／文書Undo/Redo・寸法再編集・保存再読み込み・押し出し・後続ソリッド更新・閉じたSTL）。`tests/sketch-constraint-interaction.mjs`と`tests/sketch-constraint-interaction-browser.mjs`では、長さ・位置固定、拘束に沿う頂点ドラッグ、グリッド吸着、番号の対応、画面での辺選択、拘束の印からの解除、パネル移動、斜め平面、固定点を含む移動の拒否、保存・後続ソリッドへの反映を検証します。
