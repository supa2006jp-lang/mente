# コマンド横断検証（2026-10-31）

検証中に再現した製品の不具合を修正した。

## 修正した挙動

- **ボディの切り取り**：離れたツールや面に触れるだけのツールでも成功扱いになり、「削除」を選んでいるとツールだけが消えていた。削れた体積を確認し、変化がなければ履歴・ボディ削除を返す前にエラーにする。
- **パイプによる切り取り**：対象に当たらなくても成功扱いになっていた。同じ体積確認を適用した。浅い切り取りや、すき間指定によって実際に削れる切り取りは維持する。
- **押し出した文字の再編集**：文字数を増やした際、追加文字が先頭文字の保存済み形状を継承し、履歴更新で再計算を省略することがあった。追加文字は保存済み結果を持たない状態から計算する。通常の押し出し・刻印・結合を確認した。
- **穴のある面の薄い押し出し**：ネイティブの穴輪郭の向きによってオフセットが逆になり、十分な壁厚でも作成に失敗することがあった。囲む面積の増減でオフセット方向を確認し、穴の内壁を指定した側に生成する。内側・外側・中央、穴の壁の省略、正負の押し出しを解析体積で検証した。
- **同寸のオスねじとメスねじの嵌合**：オスねじの芯の半径をらせんの軌道にすると、メス側と断面の傾きが異なり、微小干渉が生じていた。両方で呼び径の半径の軌道を使う。呼び径を保ち、右ねじ・左ねじ・部分ねじ・プルによるすき間調整を確認する。

公開済みコードを使った再現ログは `.sites-runtime/command-audit/baseline-reproductions.json`。文字の例では、期待する体積68.198819 mm³に対して45.744154 mm³となっていた。修正後は期待値と一致する。

## テスト自体の修正

製品の挙動を変えずに、古くなっていたテストも修正した。

- 初期値に依存していたフィレット用の箱やジョイントは、検証する旧寸法を明示する。
- 円の解析体積と表示用多角形の近似体積を同一視しない。CADは解析値、表示は別の許容差で確認する。
- 微小重複を偶然のCSG誤差に頼らず、明示した小さな重複形状で検証する。
- キャッシュの確認を、一般の形状検査が追加で行う距離計算や表示メッシュの呼び出し数と分離する。
- 削除済みの拘束詳細画面を開く手順を、点のドラッグと小型の確定パネルへ置き換える。
- 読み込み確認画面、QR用canvasの追加、ドラッグ後の確定操作に追従する。
- フィレットの停止時間は、その試行の開始後のWorker終了と比較する。読み込み時の別Worker終了を混ぜない。
- CAD座標を持つ傾斜グリッドのテストは、表示座標だけを変更せず、実際のメッシュ変換で回転させる。
- 丸い接触部の増加率を平面の理想値1.500倍と同一視せず、実測1.497倍に対して1.49倍以上と形状寸法・干渉を確認する。
- ねじの嵌合検査は実ソリッドを使い、干渉体積に加えて面上の点が相手の内部に入らないことを確認する。接触面を持つ部分ねじで共通部分の演算が不安定な場合も、内部判定と意図的に位相をずらす対照試験で検証する。
- 複数形状を生成する長時間テストは、検証プロセス全体の制限と、アプリ内の1回の計算の制限を区別する。

## 継続して実行する方法

- `npm test`：従来の2ファイルだけでなく、すべての `*.test.js` を実行する。
- `npm run test:commands`：62ファイルの代表コマンド回帰検証。各ファイルを独立したNodeプロセスで実行する。
- `npm run test:commands -- --list`：実行するファイル一覧。
- `npm run test:commands:all`：既存の追加回帰検証も含む。生成済みの検証データが必要な旧テストも含まれる。外部Bambu Studio実行を必要とするテストは別扱いで除外理由を記録する。
