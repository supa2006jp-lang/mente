# 直角を保つグリッド線への吸着

スケッチ線の始点がグリッド交点上にない場合も、水平・垂直に引く線とグリッド線の交点へ終点を吸着させます。始点の横座標・縦座標をグリッドへ丸めて線を傾けることはありません。

- グリッド吸着がONで、角度吸着によって水平・垂直になった線に適用します。角度を数値で固定した線にも、固定した方向を保って適用します。
- 表示中のグリッドの有限線分を使用します。XY・XZ・YZ、任意方向の紫グリッド、断面連動の作図面に対応します。画面上8 px以内の候補だけを採用し、見えていない位置や線の延長上には吸着しません。
- 長さを数値固定した場合、Altによる角度吸着解除中、グリッド吸着OFFの場合はこの吸着を行いません。始点付近や反対方向への吸着も除外します。
- 既存の端点・交点・ソリッド境界への吸着と、X・Y軸やスケッチ線への垂直吸着を先に処理します。角度未固定の斜め線では従来のグリッド交点優先を維持します。
- 吸着中は「グリッド線」と表示し、対象のグリッド線をエメラルドグリーンで強調します。角度だけの数値固定中もこの表示を残します。

`tests/sketch-grid-line-snap.test.js` は非グリッド位置からの4方向、固定した斜め方向、有限線分、反対方向、画面距離・ズーム、入力保持を検査します。`tests/sketch-grid-line-snap-browser.mjs` はXY・XZ・YZと実際の紫グリッド／断面表示で、プレビューと保存後の終点・長さ、数値固定、間隔変更、吸着OFF・Alt、強調色を検査します。

既存の `sketch-angle-snap-browser.mjs`、`sketch-axis-snap-browser.mjs`、`sketch-perpendicular-snap-browser.mjs`、`grid-boundary-snap-browser.mjs` も実行し、既存の吸着との優先順位を確認します。CAD演算Workerとソリッド形状の計算は変更しません。
