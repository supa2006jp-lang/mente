# 下絵の輪郭をスケッチ化

「下絵」で写真を読み込み、下絵を選んで「輪郭をスケッチ化」を押します。プレビューの緑色の輪郭を確認し、「輪郭をスケッチとして確定」で通常の閉じたポリラインとして取り込みます。領域を選んで押し出せます。確定は1回の取り消しで戻せます。プレビューやキャンセルでは文書を変更しません。

- 「背景の色との差で検出」は、解析範囲の外周から背景色を見積もります。「背景との差」を大きくすると、背景に近い色の部分を除外します。背景に模様がある場合は「解析範囲を指定」で対象の周りに余白を残して囲んでください。
- 「暗い部分を検出」は線画や明暗差のある画像向けです。しきい値を大きくすると明るい部分も含みます。「反転」で検出する側を入れ替えられます。
- 「透明でない部分を検出」は背景が透過したPNGなどに使います。
- 候補が複数あれば、プレビューの対象をクリックするか「取り込む輪郭」で選びます。最初は最大の候補を選びます。
- 「線分の細かさ」は直線近似の許容距離です。小さいほど線分が増えます。「穴の輪郭も取り込む」で内側の穴も閉じた線分にします。初期状態は外周だけです。

下絵の平面・幅・高さ・位置・回転を引き継ぎます。実寸が必要な場合は、抽出前に下絵の2点間寸法を合わせてください。生成したスケッチは独立しており、後から下絵を動かしても追従しません。

## プレビューを拡大・移動する

画像上のホイールで、カーソルの位置を中心に100〜1,200%へ拡大・縮小できます。「＋」「−」と「全体表示」も使えます。中ボタンまたは右ボタンのドラッグ、「画像を移動（手のひら）」を選んで左ドラッグ、画像にフォーカスしてSpaceを押しながら左ドラッグすると表示位置を移動します。表示の拡大・移動は解析範囲、下絵の寸法、確定するスケッチの座標を変えません。補正を取り消しても拡大率と表示位置を維持します。

写真・塗り補正・輪郭・頂点を同じ画像座標で表示し、頂点の選択範囲と吸着距離は画面上の大きさを保ちます。ブラシ幅は画像上の画素単位なので、拡大するとブラシも大きく見えます。広い画像を縮小表示した状態でも、写真の全体をプレビュー内に収めます。

## 塗って補正する

「プレビューの操作」で「残す部分を塗る（緑）」か「除外する部分を塗る（赤）」を選び、画像内をドラッグします。「ブラシ幅」で太さを調整できます。塗った画素を、ノイズ除去後の抽出結果に直接反映します。背景と色が近くて見つからなかった部分も、緑で塗った範囲を輪郭に含められます。色から物体全体を推測して広げる方式ではないので、広い範囲はブラシ幅を広げて塗ってください。

「塗り補正を消す」は、なぞった部分の指定を消して自動検出に戻します。「塗り補正を全て消す」でも戻せます。複数の塗り指定が重なった場合は最後の指定を使います。解析範囲外の塗り指定は抽出に使いません。

## 囲んだ範囲をまとめて補正する

「囲んだ部分を残す」または「囲んだ部分を除外」を選び、画像を順にクリックして範囲を囲みます。「囲みを適用」、画像上でEnter、最後の点をダブルクリック、または始点をクリックすると反映します。途中で拡大・移動しても、先に指定した点は画像の同じ場所に残ります。

「最後の点を戻す」または画像上でBackspaceを押すと1点戻します。「囲みを中止」またはEscで未適用の囲みだけを破棄し、解析画面は開いたままにします。未適用の囲みがない状態のEscでは解析画面を閉じます。囲みは3〜256点です。交差・接触した囲みは反映せず、点を戻す・中止する操作で修正できます。囲みを適用するまではスケッチの確定を無効にします。

一括補正もブラシと同じ塗り指定です。囲み1回を1操作として、補正を戻す・やり直す操作に対応します。既存の指定に重ねると最後の指定を使い、画像・解析範囲の外へは抽出しません。

## 頂点を手直しする

- 「頂点を移動」: 白い頂点をドラッグします。
- 「頂点を追加」: 輪郭の線上をクリックします。
- 「頂点を削除」: 削除したい頂点をクリックします。閉じた輪郭に必要な3個の頂点は残します。
- 「この輪郭の手直しをリセット」: 選択中の輪郭を自動抽出の形に戻します。

「頂点を移動」には「頂点の水平・垂直吸着」があります。同じ輪郭候補内の他の頂点と水平・垂直に近づくと吸着し、青い補助線と状態表示を出します。画面上で約8pxの範囲を使い、拡大しても吸着範囲が過度に広がらないようにします。チェックを外すか、ドラッグ中にShiftを押すと吸着を解除できます。頂点そのものへ重ねると不正輪郭の検査で確定を止めます。

選択した候補ごとに頂点の手直しを保持します。線が交差・接触した場合や、穴が外周の外に出た場合、輪郭がつぶれた場合は赤い線と説明を表示し、確定を無効にします。位置の再調整や取り消しで修正できます。確定時に手直しした頂点を再び直線近似することはなく、その座標でスケッチを作ります。

「補正を戻す」「やり直す」で、塗り補正・頂点編集・検出条件・解析範囲を20操作まで戻せます。解析画面内のCtrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+Yも対応します。この操作は文書全体の履歴には影響しません。検出条件・解析範囲・塗り補正の変更では輪郭を再抽出するため頂点編集をリセットしますが、補正の取り消しで戻せます。閉じる・キャンセルでは未保存の補正を破棄し、文書を変更しません。通常のモデルファイルには確定したスケッチを保存します。

## 補正途中の保存・再開

「途中保存」で、この画像と配置に対する補正をブラウザー内へ保存します。下絵自体を含むモデルは通常の保存で別途残してください。同じ下絵で輪郭解析を開き、「続きから再開」で復元します。画面を閉じたりページを再読み込みしたりしても保存済みの補正を使えます。同じ画像・配置の保存は上書きです。自動保存ではないため、作業後にもう一度「途中保存」を押してください。

塗り補正、候補ごとの頂点編集、検出条件、解析範囲、選択候補、整理設定、拡大位置、操作ツール、ブラシ幅、吸着設定、未適用の囲みを復元します。交差などが残る修正途中の頂点も保存できますが、修正するまでスケッチ確定はできません。過去20操作の履歴は保存せず、再開自体を「補正を戻す」で取り消せます。

「途中データを書き出す」「途中データを読む」で別ブラウザーにも移せます。途中データには画像を含みません。同じ下絵のモデルを開いてから読み込んでください。画像の内容、寸法、位置、角度、配置平面の一致をハッシュで確認し、違う下絵への適用を拒否します。保存領域を使用できない場合はエラーを表示し、ファイル保存を利用できます。ブラウザーのサイトデータを消去するとブラウザー内の途中保存も消えます。

## 直線・円弧へ整理する

「直線・円弧へ整理する」をオンにすると、許容誤差内で輪郭を直線とCADの円弧へ置き換えます。初期状態はオフです。緑は整理前、青は整理後です。「元の輪郭と比較」を外すと整理後だけを表示します。直線・円弧の本数と誤差上限を表示し、確定には青色の輪郭を使います。チェックを外すと整理前の形で取り込めます。

「整理の許容誤差」は0.01〜10 mmで、現在の輪郭から離れてよい距離です。「線分の細かさ」による写真輪郭の直線近似とは別です。写真の遠近や抽出誤差を含む実物との誤差を保証する値ではありません。円弧を採用できない区間は直線で残します。横幅・高さの比率も含め実寸で判定し、近似のずれと円弧の弦のずれを合わせて検査します。穴と外周の交差・接触などが生じる場合は確定を止めるため、許容誤差を小さくするか整理をオフにしてください。

頂点操作では整理前の輪郭を編集し、操作後に整理を再計算します。円弧は通常の接線円弧と同じスケッチ情報を持ち、押し出しで曲面として扱います。同一スケッチ番号に属する線・円弧として保存し、モデル全体の150形状の上限を超える場合は確定を止めます。

これは写真に写った2Dの輪郭を抽出する機能です。斜め写真の遠近、隠れた部分、影と物体の区別、正確な3D形状や製造寸法を復元する機能ではありません。背景と対象の色が近い写真や反射・影が強い写真は、検出条件の調整や取り込み後の修正が必要です。

画像は端末内のCanvasで読み込み、長辺640画素以内に縮小して解析します。外部サービスへの画像送信や追加ライブラリのダウンロードは行いません。小さいノイズを除去し、候補16個・1候補の境界20,000辺・確定64輪郭／2,000線分までに制限します。複雑すぎる場合は解析範囲やノイズ除去・細かさの調整を案内します。文書が変更された場合は古い解析結果の確定を拒否します。
