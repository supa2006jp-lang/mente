# 円弧のつなぎ目がある形状のシェル

円が重なった領域など、円筒面の間に短い平面が残る形状では、通常の丸い接続によるオフセットが元のソリッドをそのまま返す場合がある。これを壁厚過大と断定せず、変更されていない結果として扱う。

通常のシェルを検証し、失敗した場合のみ同じ壁厚・開口面で交差接続のオフセットを試す。対象が既存の円形ロフト用の復旧処理に対応する場合は、多数の面の交差計算に入る前にその専用処理を使う。外周の作り直しや寸法の丸め、壁厚の自動変更は行わない。返されたCAD形状の妥当性、正の体積、内側シェルで実際に除去された体積を確認してから使用する。復旧できない場合はエラーとして扱う。

`tests/shell-short-arc-junctions.mjs` は2つの円の重なりから保存済みソリッドを作り、通常計算の無変化、壁厚0.4/1/2 mm、片側・両側の開口、壁・底の厚み、外形寸法、CADの妥当性、過大な壁厚の拒否、元形状の保持を確認する。
