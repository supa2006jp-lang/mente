# スケッチの接続点表示

グリッド吸着の横に「接続点」の表示切替を追加。初期状態はON。

- 緑の塗り丸：線が端点でつながっている場所。長方形・多角形など、1つの図形の角も含む。
- オレンジの輪：別の線につながっていない端点。
- 線の移動・編集・Undo/Redo・読み込み後は自動更新。
- 表示は線の座標から判定し、形状や拘束を追加・変更しない。

接続の許容距離は既存の接続スケッチ移動と同じ 0.000001 mm。画面上で近いだけの点は接続に数えない。同じスケッチの同じ平面にある通常線が対象。交差するだけの線、線の途中にある別の端点、別スケッチ、補助線は端点接続に数えない。

円と閉じたスプラインには端点マークを出さない。円弧・スプラインには本来の両端だけを表示し、曲線表示用の分割点は使わない。文字輪郭ではマークの密集を避けるため表示しない。

マークはクリックを取得しない。既存の端点選択やドラッグ操作を使える。ソリッドの奥に隠れた点は透視表示しない。形状の計算はモデルや線の表示状態が変わった時に限り、画面の毎フレームで接続を再計算しない。

検証：`node --test tests/sketch-connections.test.js` と `node tests/sketch-connections-browser.mjs`。後者はローカル5188番の検証サーバーか `FORMA_TEST_URL` に対して、隔離したEdgeで実行する。
