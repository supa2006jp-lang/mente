# フィレット後の平面を押し出し・切り取り

フィレットと平面が接する境界では、CAD上のどちらの面からもクリック位置までの距離が0になることがあります。距離だけで加工元の面を選び直すと、平面を選んだのに隣のフィレット曲面を拾い、「押し出す平面を選択し直してください」となる場合がありました。表示座標の丸めや、形状の回転・移動でも選択結果が変わっていました。

平面の押し出しでは、選択した面と同じ向きのCAD平面に候補を限定してから距離を比較します。フィレットを含むボディはそのまま保持し、平面の本来の輪郭・穴を使います。ミラー結合後の平面をまとめる既存処理や、離れた面を誤選択しない検査も継続します。

検証：

- `node tests/fillet-planar-extrusion.mjs`：全辺フィレット付き直方体の6面、接線境界、表示座標の丸め、回転・移動、穴、押し出し・切り取り・新規、CADの妥当性と体積、保存再読込、履歴再計算。
- `node tests/fillet-planar-extrusion-browser.mjs`：境界付近の平面を画面で選択し、押し出し・切り取りを確定。保存再読込と元に戻す・やり直す。
