# 選択した辺を軸に同じボディを回転形成

ソリッドの直線の辺を1本選ぶと、左下の選択情報に「この辺を軸に回転形成」を表示します。押すと既存の回転形成画面を開き、回転対象にその辺が属するボディ、軸に選択辺、操作に元のボディとの結合を設定します。初期角度は360°です。領域・面、ボディ、選択した辺を軸にした場合も同じ初期角度になります。同じ辺に別のボディが接していても、「上側のソリッドを90°回転」とは異なり、選択辺が属するボディを使います。辺を選んで上部の「回転」を開く場合も同じ設定を引き継ぎます。

角度を0°より大きく360°以下で指定し、片側・逆方向・対称を切り替えてプレビューを確認して実行します。単に原型の向きを変える操作ではなく、原型が回転して通る範囲を埋めます。初期の結合操作で確定すると元のボディIDを保ったまま一体化し、別のボディは変更しません。新規ボディや切り取りを明示的に選ぶ場合は既存の回転形成と同じ動作です。キャンセルで形状は変わらず、確定後のUndo・Redo、保存・再読込に対応します。

軸にできるのは直線の辺1本です。円周・円弧・曲線の辺や複数選択ではこのボタンを表示しません。形状計算は正確なボディ回転範囲生成を使用します。平面主体の形状と対応する円筒・円錐・球面が対象です。円錐の中心軸は回転軸に平行である必要があり、円筒面は平行な軸に加え、直交する軸での分割にも対応します。中心軸が平行な丸みの面は、進行方向が反転しない範囲で扱います。未対応の曲面・斜めの軸・自己交差やカーネルの結合失敗では、理由を表示して元形状を保持します。すべての曲面・軸・角度の組み合わせを保証するものではなく、軸から離れた直交円筒の全周回転などには引き続き制約があります。

円錐・丸みの軸取得には、同梱ランタイムで未公開の `gp_Cone` / `gp_Torus` の値を要求するAPIを使わず、厳密な円形等パラメータ曲線の3点から軸を得ます。向きが変わる平面で一括分割し、履歴情報から元の境界面だけを取り出します。進行側の面を独立したコピーとして回転させ、その通過範囲と原型を一括結合します。回転で生成された平面が特異な回転曲面として残る場合は、円・直線の解析的な条件を確認し、同じ境界線から平面として構築します。最後に同一面の継ぎ目を入力保持モード・線形/角度許容差 `1e-7` で整理し、CADの妥当性と体積保持を検証します。原型との結合は、回転範囲に原型が既に含まれているため再度ブール演算しません。

検証：`tests/edge-body-revolve.mjs`で選択辺の所有ボディ、軸の端点順、片側・逆方向・対称、45°・90°と360°、途中の回転位置に実体があること、同一IDと連続した1ソリッド、斜め・移動した軸、他ボディの保持、履歴再計算を検証します。`tests/edge-body-revolve-browser.mjs`では選択メニューと上部コマンドの引継ぎ、数値と方向のプレビュー、キャンセル、確定・保存再読込・Undo/Redo、閉じたSTL出力、無効な辺の除外と既存の断面モードを検証します。

`tests/body-revolve-curved.mjs` は円錐・直交する円筒の丸み・シェルの丸みを含む添付モデルを元の軸で90°回転形成し、0/22.5/45/67.5/90°の各姿勢で元形状全体が結果に含まれること、STLの閉鎖性、同一ボディへの結合、斜めに配置し直した場合の同じ体積・経路、元形状と履歴の保持を確認します。平行円筒の全周回転は解析的な体積とも比較します。`tests/body-revolve-curved-browser.mjs` は同じ辺を画面から選び、新規ボディのプレビュー・確定・単独STL出力・保存読込・Undo/Redo・キャンセルを確認します。
