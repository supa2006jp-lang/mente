# 選択した辺を軸に同じボディを回転形成

ソリッドの直線の辺を1本選ぶと、左下の選択情報に「この辺を軸に回転形成」を表示します。押すと既存の回転形成画面を開き、回転対象にその辺が属するボディ、軸に選択辺、操作に元のボディとの結合を設定します。初期角度は360°です。領域・面、ボディ、選択した辺を軸にした場合も同じ初期角度になります。同じ辺に別のボディが接していても、「上側のソリッドを90°回転」とは異なり、選択辺が属するボディを使います。辺を選んで上部の「回転」を開く場合も同じ設定を引き継ぎます。

角度を0°より大きく360°以下で指定し、片側・逆方向・対称を切り替えてプレビューを確認して実行します。単に原型の向きを変える操作ではなく、原型が回転して通る範囲を埋めます。初期の結合操作で確定すると元のボディIDを保ったまま一体化し、別のボディは変更しません。新規ボディや切り取りを明示的に選ぶ場合は既存の回転形成と同じ動作です。キャンセルで形状は変わらず、確定後のUndo・Redo、保存・再読込に対応します。

軸にできるのは直線の辺1本です。円周・円弧・曲線の辺や複数選択ではこのボタンを表示しません。形状計算は正確なボディ回転範囲生成を使用します。平面主体の形状と対応する円筒・円錐・球面が対象です。一般の回転処理では、円錐の中心軸は回転軸に平行である必要があり、円筒面は平行な軸に加え、直交する軸での分割にも対応します。直交する別軸での全周回転に対応する条件は後述します。中心軸が平行な丸みの面は、進行方向が反転しない範囲で扱います。未対応の曲面・斜めの軸・自己交差やカーネルの結合失敗では、理由を表示して元形状を保持します。すべての曲面・軸・角度の組み合わせを保証するものではなく、軸から離れた直交円筒の全周回転などには引き続き制約があります。

円錐・丸みの軸取得には、同梱ランタイムで未公開の `gp_Cone` / `gp_Torus` の値を要求するAPIを使わず、厳密な円形等パラメータ曲線の3点から軸を得ます。向きが変わる平面で一括分割し、履歴情報から元の境界面だけを取り出します。進行側の面を独立したコピーとして回転させ、その通過範囲と原型を一括結合します。回転で生成された平面が特異な回転曲面として残る場合は、円・直線の解析的な条件を確認し、同じ境界線から平面として構築します。最後に同一面の継ぎ目を入力保持モード・線形/角度許容差 `1e-7` で整理し、CADの妥当性と体積保持を検証します。原型との結合は、回転範囲に原型が既に含まれているため再度ブール演算しません。

検証：`tests/edge-body-revolve.mjs`で選択辺の所有ボディ、軸の端点順、片側・逆方向・対称、45°・90°と360°、途中の回転位置に実体があること、同一IDと連続した1ソリッド、斜め・移動した軸、他ボディの保持、履歴再計算を検証します。`tests/edge-body-revolve-browser.mjs`では選択メニューと上部コマンドの引継ぎ、数値と方向のプレビュー、キャンセル、確定・保存再読込・Undo/Redo、閉じたSTL出力、無効な辺の除外と既存の断面モードを検証します。

`tests/body-revolve-curved.mjs` は円錐・直交する円筒の丸み・シェルの丸みを含む添付モデルを元の軸で90°回転形成し、0/22.5/45/67.5/90°の各姿勢で元形状全体が結果に含まれること、STLの閉鎖性、同一ボディへの結合、斜めに配置し直した場合の同じ体積・経路、元形状と履歴の保持を確認します。平行円筒の全周回転は解析的な体積とも比較します。`tests/body-revolve-curved-browser.mjs` は同じ辺を画面から選び、新規ボディのプレビュー・確定・単独STL出力・保存読込・Undo/Redo・キャンセルを確認します。

## 同じ軸で続けて回転形成する場合

同じ回転軸で続けて回転形成するときは、履歴から連続する回転範囲を合算し、最初の形状から正確に作成します。90°の後に同方向へ90°なら合計180°、逆方向へ90°なら−90°から90°の範囲です。片側・逆方向・対称、同一直線上の異なる原点、軸の端点順の反転を扱います。全周を既に覆っている形状を同じ軸でさらに回転しても形状は変わりません。新規ボディ・元ボディへの結合のどちらにも対応し、同じIDへ結合した工程の入力は必ずその工程より前の履歴から取得します。

途中の移動・切り取り・フィレットなどの加工や、別軸の回転、別ボディを足した結合を飛び越えて履歴を合算することはありません。その場合は現在の形状を通常の回転処理へ渡します。別軸や未対応曲面の制約は引き続きあります。

面と辺の同時整理で継ぎ目が不正になる場合は、同じ許容差・入力保持モードで面のみを整理します。CADの妥当性・体積保持・全ての面のメッシュ生成を検査し、正常な結果だけを使います。整理前の形状を使う場合も同じ検査を必要とします。

`tests/body-revolve-history.mjs` は回転区間の合算と加工履歴の境界、`tests/body-revolve-repeated.mjs` は元の曲面モデルの90°→90°→全周回転、途中の各姿勢の包含、逆方向・対称・軸反転、同一IDへの結合・再計算・閉じたSTLを確認します。後者が作成する最初の回転結果を `tests/body-revolve-repeated-browser.mjs` で読み込み、再回転のプレビュー・確定・STL出力・Undo/Redo・保存読込・キャンセルを確認します。

## 直交する別軸での全周回転

線分だけの断面を360°回転して作ったソリッドは、その中心軸と交わる直交軸のまわりにも360°回転形成できます。例として、Y軸で作った円筒・円錐を含む回転体をX軸またはZ軸で全周回転する操作に対応します。元の断面が半径方向に詰まった形で、軸方向に折り返さず、新しい軸の片側に収まる場合が対象です。穴・円弧を含む断面、360°未満の回転、交わらない軸、途中に加工を挟んだ形状には、この処理を適用しません。通常の回転処理で対応する条件は従来どおりです。

元の断面から、新しい軸の周囲の断面回転体と、各頂点に対応する球面の帯を正確に作って結合します。形状を角度刻みで並べたり、曲面を多角形近似して生成したりはしません。微小な演算誤差で帯が欠落しないよう、構成は正規化した座標で行ってから指定軸へ剛体変換します。CADの妥当性、連続した1ソリッド、全ての面のメッシュ生成に加え、断面から解析的に求めた体積と高精度のCAD体積積分を比較します。保存・後続処理に渡すのは複合形状のラッパーではなく実ソリッドです。

`tests/body-revolve-cross-axis.mjs` は添付された失敗記録を使用し、同じY軸→X軸360°の条件、1200点の解析的内外判定、回転途中の各姿勢の包含、くぼみの保持、高精度体積、元形状・履歴の保持、同一ボディへの結合、軸反転・対称・Z軸・斜め配置、再計算・保存読込・さらに同じ軸で回す操作と閉じたSTLを検証します。包含検査のブール差分では共通の接触許容差1e-6 mmを使います。`tests/body-revolve-cross-axis-browser.mjs` は同じファイルを画面で開き、X軸360°のプレビュー・確定・単独STL出力・Undo/Redo・保存読込・キャンセルを確認します。
