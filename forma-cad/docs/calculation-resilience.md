# 計算停止とキャンセルの検証

通常形状の完了確認と、計算が戻らない場合の復帰確認は分けて行う。
成功例だけでは、タイムアウトやキャンセルの動作は確認できない。

## 検証範囲

- `npm test`: 待ち行列、制限時間、旧ワーカーの遅延応答の無視、実行処理の保護を含む自動テスト。
- `npm run test:commands`: 71本の代表的なコマンド・連続操作スイート。結合、切り取り、シェル、フィレット、移動、回転、ミラー、模様、ハニカム、収納トレー、リブサポートなどを実CAD形状で確認する。全入力・全組合せの網羅ではない。複数の模様を試すスイートの所要時間と、アプリの1操作の制限時間は異なる。
- `node tests/hang-resilience-browser.mjs`: 実ブラウザーで、輪郭抽出モデルの重なるボディと意図的に無限ループするワーカーを使う。画面の応答、時間切れ、キャンセル、次の計算の再起動、プレビュー時間切れ後の確定を検査する。事前に `node tests/trace63-cut-browser.mjs` で実モデルの検証用出力を作成する。モデルの元ファイルは変更しない。
- `tests/combine-preview-browser.mjs` と `tests/join-clearance-browser.mjs`: 通常の切り取り・交差表示、すき間指定、確定、保存・再読込、元に戻す／やり直すを確認する。最新の `dist` をポート5188で配信して実行する。

## 発見した経路と修正

結合コマンドの赤色プレビューが、画面のスレッドでメッシュ同士のブーリアン演算を行っていた。輪郭抽出後の4,636三角形のボディを少しずらして重ねる例では、8秒の試験上限まで演算が戻らなかった。この経路では画面自身のタイマーやキャンセル操作も止まる。

切り取り・交差のメッシュプレビューを専用ワーカーへ移し、5秒でワーカーを停止する。すき間付きの精密プレビューも独立したワーカーで実行し、15秒で停止する。入力変更、ツール変更、ダイアログを閉じる操作、確定時には古いプレビューを停止する。古い結果はリビジョンで除外する。

プレビューの時間切れは実際の加工を禁止しない。画面に中断を表示し、設定の変更または確定へ進める。確定用ワーカーと制限時間はプレビューと分離して維持する。形状検査や精密加工の計算自体は省略しない。

## 制限

通常のCAD操作は90秒、結合・プル・STEP読込・SVG巻き付けなどは5分、コイル接合などは10分の上限を持つ。自動押し出し判定は15秒。長時間処理が必ず成功するわけではなく、上限を超えた場合はエラーとして終了する。

表示用メッシュの構築など、画面側の処理も残る。今回の試験は、あらゆる入力に対して画面停止が発生しないことを保証するものではない。

## 背景解析・段階プレビュー・再試行

スケッチの線分相当数が128を超える場合、またはソリッドとの重なり解析に大きいメッシュが必要な場合は、専用の `sketch-analysis-worker.js` で閉領域探索・断面との重なり解析・領域の三角形化を行う。入力はスケッチと必要な表示メッシュのみで、写真や全履歴は渡さない。解析中は古い領域を選択させず、モデル変更・新しい解析で古いワーカーを停止する。文字の大量の輪郭も背景解析を利用し、押し出し方向が決まるまで文字ダイアログを閉じない。単純なスケッチは従来どおり即座に表示する。

自動プレビューでは、入力中は加工対象の範囲などの簡易表示を維持し、入力が止まってから精密形状を計算する。簡易表示を加工完了後の形状と誤認させない文言を付ける。既存のミラー・移動・配置・QRなど、軽量に結果の位置を表示できる処理はその表示を維持する。結合・シェル・フィレットなどと回転のプレビューには確定用とは別のワーカーを使い、数値変更・終了時に古い計算を止める。収納トレー、ハニカム、接合、蓋、リブサポートなどの自動CADプレビューにも同じ時間切れ抑制と再試行を適用する。

時間切れの自動プレビューは、ドキュメントと入力条件ごとにセッション内で記録する。同じ条件の自動再計算は開始せず、設定変更または「プレビューを再試行」で再開する。キャンセルや幾何エラーは時間切れとして記録しない。実際に時間切れになった処理だけを記録し、その後ろで待っていた別の条件は抑制しない。確定・保存・出力はこの抑制の対象外で、既存の計算上限を維持する。

`tests/preview-resilience.test.js` は入力条件・ドキュメント・明示的再試行・確定処理の区別と、背景解析の領域一致を検査する。`tests/preview-resilience-browser.mjs` は実モデルの17領域、解析中のモデル切替、連続入力の最終値、時間切れの抑制、明示的再試行、回転のプレビューと確定を実ブラウザーで検査する。`tests/preview-support-latest-browser.mjs` は古い応答を意図的に遅らせ、最新の設定が優先されることと独立したCAD計算との一致を検査する。

## 旧形式の読み込みと手動精密確認

CAD結果を持たない旧形式の結合・切り取り履歴は、読み込み時に専用の `model-rebuild-worker.js` で表示用メッシュを再構築する。表示キャッシュを使うために元の履歴へ架空のCAD工程を保存することはない。表示用の頂点座標は元の精度を保持する。古い読み込みは新しいファイルの読み込みで取り消し、元に戻す・履歴の再編集で不足する表示結果も背景で準備する。キャッシュは96MBを目安に制限し、足りない場合に画面側で重い演算へ戻すことはしない。

画面下の「自動精密プレビュー」をOFFにすると、加工後の精密形状の自動計算を止め、簡易表示を使う。「精密確認」を押した時点のドキュメントと設定だけを計算対象にする。設定を変更すると再び確認待ちになる。スケッチ領域解析、旧形式の読み込み、押し出し方向・接触位置の判定、実際の確定・保存・出力はこのスイッチの対象外。初期状態はONで、切替はブラウザー内に保存する。加工ダイアログ内にも同じ操作を表示する。

確認済み精密形状の再利用対象に面取りと回転を追加する。回転は新規・結合・切り取りの選択をそのまま計算し、同じドキュメント・対象・軸・角度・方向・操作の時だけ結果を確定へ渡す。プレビュー表示用の削除部品などは履歴へ保存しない。生成IDを置き換えても既存ボディのIDと検査情報は維持する。コイル接合のように確定時の追加検査が必要な処理は対象に含めない。

`tests/precision-preview-workflow.test.js` は手動確認の条件分離、確定処理の保護、旧形式の座標・履歴保持、キャッシュの無効化を検査する。`tests/precision-preview-workflow-browser.mjs` は旧形式の読み込み中のイベント応答、古い読み込みの除外、元に戻す・やり直す、手動確認、連結リブサポート、回転3操作の再計算省略を実画面で確認する。`tests/precision-preview-reuse-native.mjs` は再利用結果を通常計算と比較し、体積・立体数・位置・CAD形状の妥当性・STLの閉じ方・履歴を検査する。
