# 選択候補の開閉と配置

面や辺などの候補が複数ある場所をクリックした場合、最初は「▸ 選択候補（件数）」だけを表示する。クリックすると一覧を開き、再度クリックすると折り畳む。新しい場所をクリックした場合は折り畳んだ状態に戻る。

折り畳み中は情報欄や操作パネルから離れた空き領域に小さく表示する。開いた一覧もソリッドと左下の情報欄を避け、空き領域がない場合は右端に表示領域を確保する。情報欄の内容が遅れて増えた場合や画面サイズが変わった場合も位置を再計算する。右端に配置した場合は左下情報欄とナビゲーションの幅も調整して重ならないようにする。

一覧の固定、種類・ボディによる絞り込み、強調表示、「ここを見る」、元の視点への復帰は引き続き使える。折り畳むと固定・強調表示と右端の予約領域を解除する。作業画面からのTabによる候補切り替えは一覧を開いて行い、折り畳みボタン上のTabは通常のフォーカス移動として使う。Escで候補を閉じる。

検証：`tests/selection-picker-pinned.mjs`、`tests/selection-picker-collapse-browser.mjs`、`tests/selection-overview-browser.mjs`。
