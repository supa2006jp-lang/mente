# ハニカム格子

円柱・直方体を選び、上部の「ハニカム格子」または「作成・修正」→「ハニカム格子」を開きます。

- 六角穴の幅：向かい合う辺どうしの距離。
- 格子の幅：隣り合う穴の間に残す幅の目安。円柱は内周で隣の穴と接触しないよう配置数を調整します。
- 側壁の厚み：中空化する際に残す厚み。中空化をOFFにした場合は側面から加工する深さです。
- 角の枠幅：箱の縦の角に残す幅。
- 上側・下側の枠幅：側面に六角穴を開けずに残す高さ。別々に指定でき、側壁の厚み以上を確保します。上面・底面の板そのものの厚さは側壁厚で決まります。円柱でも使えます。
- 箱の高さ方向：指定軸に最も近い辺を高さ方向とします。円柱では円柱自身の軸を使います。
- 加工範囲：円柱一周／箱の4側面、または事前にクリックした箱の平面だけ。
- 上面・底面：両方残す／上面を開く／底面を開く／両方開く。高さ方向の＋側が上面です。開口時は中空化ONで使います。
- 穴の配置：「穴の幅で指定」に加え、「個数・段数から自動調整」を選べます。円柱の横個数は1周の個数（3個以上）、箱は各面の最大個数です。箱の交互の段は1個少なくなります。穴は正六角形を保ち、枠内で同じ幅になるよう自動計算します。形状によって穴どうしの間隔には余裕ができます。

初期値は六角穴10 mm、格子1.5 mm、側壁2 mm、上下・角の枠3 mm、中空化ON、上面・底面を残す設定です。以前のファイルは旧「端の枠幅」を上下へ引き継ぎ、同じ配置・開閉状態で復元します。既存の穴や空洞を埋める処理は行いません。

精密プレビューは「自動で計算」「手動・配置だけ表示」を切り替えられます。切替の選択はブラウザに記憶し、モデルの形状設定とは別に管理します。

- 自動：設定変更では先に水色の線で穴の配置を表示し、続いて精密な立体を更新します。
- 手動：対象の形と大きさだけを確認して配置線を表示します。数値を変更するたびの穴の精密計算は行いません。「精密確認」で立体を確認できます。配置表示から直接「作成」を押すと、その設定を1回だけ精密計算し、正常な結果が得られた場合に確定します。

すでに精密確認した同じ設定なら、作成時に結果を再利用します。キャンセルでは計算中も元のモデルを保持します。
設定変更のたびにエンジンを再起動せず、対象ボディの精密データを再利用します。最近計算した3種類の結果に戻す場合は再計算せず表示します。入力途中に古い計算が残っている場合は中止し、新しい設定だけを反映します。
履歴の「ハニカム格子」をクリックすると再編集できます。Undo／Redo、Formaファイルの保存・復元と後続工程の再計算に対応します。

1工程は六角穴合計240個までです。上限を超える場合や指定個数で穴を確保できない場合は、収まる横個数・段数を提案します。提案ボタンを押したときだけ設定を変更し、モデルの確定は「作成」で行います。穴を小さく切り欠いて端に並べる代わりに、完全な六角穴と枠を残します。フィレットなど曲面が混在する形状は先に格子加工を行ってください。
