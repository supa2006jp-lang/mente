# ハニカム格子

円柱・直方体を選び、上部の「ハニカム格子」または「作成・修正」→「ハニカム格子」を開きます。

- 六角穴の幅：向かい合う辺どうしの距離。
- 格子の幅：隣り合う穴の間に残す幅の目安。円柱は内周で隣の穴と接触しないよう配置数を調整します。
- 側壁の厚み：中空化する際に残す厚み。中空化をOFFにした場合は側面から加工する深さです。
- 端の枠幅：上下端・箱の角に残す幅。側壁の厚み以上の幅を確保します。
- 箱の高さ方向：指定軸に最も近い辺を高さ方向とします。円柱では円柱自身の軸を使います。
- 加工範囲：円柱一周／箱の4側面、または事前にクリックした箱の平面だけ。

初期値は六角穴10 mm、格子1.5 mm、側壁2 mm、端の枠3 mm、中空化ONです。中空化ONは上面・底面を残し、内部を削ります。既存の穴や空洞を埋める処理は行いません。

設定変更でプレビューを更新し、「作成」で確定します。プレビューと確定には同じCAD計算結果を使います。キャンセルでは元のモデルを保持します。
履歴の「ハニカム格子」をクリックすると再編集できます。Undo／Redo、Formaファイルの保存・復元と後続工程の再計算に対応します。

1工程は六角穴合計240個までです。上限を超える場合は穴・格子の幅を増やしてください。穴を小さく切り欠いて端に並べる代わりに、完全な六角穴と枠を残します。フィレットなど曲面が混在する形状は先に格子加工を行ってください。
