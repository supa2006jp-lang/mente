# スケッチの角度操作

## 線分の15度吸着

線分作図中は「15°方向に吸着」が初期状態で有効です。始点から15度刻みの方向に近づくと吸着し、角度を画面に表示します。連続線でも直前の終点を始点として働きます。

- 吸着範囲は方向差3度以内、画面上の補正距離8px以内です。
- Altを押している間は一時解除できます。チェックを外して無効にもできます。
- 端点・交点・輪郭などの形状への吸着と、数値で指定した角度を優先します。グリッド吸着も有効な場合、近くのグリッド交点（画面上6px以内）を15度吸着より優先します。グリッド交点のない場所では15度吸着が働きます。チェックや間隔の変更は現在のプレビューへ即時反映します。
- XY・XZ・YZおよび任意の作図平面内で働きます。

## 頂点を中心に枠全体を回転

作図を終了して閉じたスケッチ枠の頂点をクリックすると、左下に「角度変更（スケッチ全体）」を表示します。クリックした頂点を固定し、枠全体の向きを変えます。

1. 現在の向きから回転する角度を入力します。−15°・＋15°ボタンも使えます。
2. 回転プレビューを確認し、「角度を確定」を押します。
3. 「キャンセル」またはEscで元の形に戻せます。「0°に戻す」は今回の変更量を0に戻します。

角度は−360〜360度です。寸法と形を保って回転し、枠を構成する線分や内側の穴も一緒に動きます。別の枠は動かしません。開いた線・円単独・文字輪郭にはこの頂点操作を表示しません。

確定時に後続の押し出しなどを再計算します。計算に失敗した場合は元のモデルを保持します。確定後は通常の元に戻す・やり直し、保存・再読み込みに対応します。

## 検証

角度吸着・頂点回転・既存の端点と閉領域・形状処理の単体検証36件、輪郭吸着の回帰検証を実施。ブラウザーで吸着表示、Altとチェック切替、数値・端点優先、連続線、頂点選択、回転プレビュー、確定・キャンセル、Undo/Redo、保存再読込を検証しました。ネイティブCAD処理でXY・XZ・任意平面の後続押し出しについて体積維持、回転後の境界、閉じたSTLを検証しています。
