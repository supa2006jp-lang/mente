# スケッチの角度操作

## 線分の角度吸着

線分作図中は「角度吸着」が初期状態で有効です。刻みは5°・15°・30°・45°から選べます（初期値15°）。始点から指定の刻みの方向に近づくと吸着し、角度を画面に表示します。連続線でも直前の終点を始点として働きます。刻みの変更はその場でプレビューへ反映します。

- 吸着範囲は方向差3度以内（5°刻みでは1.25度以内）、画面上の補正距離8px以内です。
- Altを押している間は一時解除できます。チェックを外して無効にもできます。
- 端点・交点・輪郭などの形状への吸着と、数値で指定した角度を優先します。グリッド吸着も有効な場合、近くのグリッド交点（画面上6px以内）を15度吸着より優先します。グリッド交点のない場所では15度吸着が働きます。チェックや間隔の変更は現在のプレビューへ即時反映します。
- XY・XZ・YZおよび任意の作図平面内で働きます。

## 軸へ垂直に線をつなぐ

線分の終点を作図平面のX軸・Y軸に垂直に近づけると、始点から垂直に下ろした位置へ吸着します。グリッド交点以外でも始点側の座標を保つため、線が斜めになりません。吸着中は緑の「⊥」と「X軸へ垂直」「Y軸へ垂直」を表示します。XZ・YZ平面では対応する軸名を表示します。

方向差3度以内かつ吸着位置から画面上8px以内で働きます。通常の端点・交点・形状境界を優先し、垂直接続はグリッドや角度刻みへの吸着より優先します。グリッド・角度吸着のON/OFFに依存せず、Altで一時解除できます。数値の長さ指定中は軸吸着せず、角度指定中は指定した方向が軸に垂直な場合だけ働きます。始点がその軸上にある場合や斜めに近づく場合は吸着しません。

## 頂点を中心に枠全体を回転

作図を終了して閉じたスケッチ枠の頂点をクリックすると、左下に「角度変更（スケッチ全体）」と、画面に円弧の回転ハンドルを表示します。枠全体の形を保って向きを変えます。

1. 回転中心を「クリックした頂点」「図形の中心」「指定した点」から選びます。「図形の中心」は外形の作図平面上の範囲の中央です。「指定した点」は同じ作図平面上をクリックして選び、端点や有効なグリッドに吸着します。
2. 円弧または↻ハンドルをドラッグ、角度を入力、あるいは±刻みボタンで調整します。回転の吸着刻みも5°・15°・30°・45°から選べます。刻みの選択は線分作図と共有します。
3. ドラッグ中はAltで角度吸着を解除、Shiftで移動量を1/10にして微調整できます。吸着中は円弧とハンドルが緑色になります。数値入力は指定値をそのまま使用します。
4. 回転プレビューを確認し、矢印ボタン内の「＋決定」または左下の「角度を確定」を押します。矢印ボタンはドラッグで調整、クリックで確定します。ドラッグ終了では確定せず、クリック時の小さな手ぶれで入力した角度を変えません。フォーカスした矢印ではEnter・Spaceでも確定できます。中心を切り替えても毎回元の枠から再計算し、変更が累積しないようにしています。
5. 「キャンセル」またはEscで元の形に戻せます。「0°に戻す」は今回の変更量を0に戻します。点の選択中のEscは点選択だけを終了、ドラッグ中のEscやポインターの取消はドラッグ開始時の角度へ戻します。

角度は−360〜360度です。寸法と形を保って回転し、枠を構成する線分や内側の穴も一緒に動きます。別の枠は動かしません。開いた線・円単独・文字輪郭にはこの頂点操作を表示しません。

確定時に後続の押し出しなどを再計算します。計算に失敗した場合は元のモデルを保持します。確定後は通常の元に戻す・やり直し、保存・再読み込みに対応します。

## 検証

角度吸着・軸への垂直吸着・頂点回転・既存の端点と閉領域・形状処理の単体検証41件を実施。ブラウザーで各刻み、グリッド併用、両軸への垂直吸着と保存結果、数値指定・端点優先、ドラッグ、Alt・Shift、任意点の端点・グリッド吸着、中心切替、確定・取消・Undo、保存再読込を検証。ネイティブCAD処理ではXY・XZ・任意平面それぞれで3種類の回転中心から後続押し出しを再計算し、体積維持、回転後の境界、閉じたSTLを検証しています。
